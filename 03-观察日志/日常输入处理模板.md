# 日常输入处理模板

> 用途：把每天的语音/文字记录，按底层逻辑处理成可用的内容原料。  
> 输入：语音转文字 / 文字记录 / 随手笔记  
> 输出：新话题、可用表达、待跟进事项  
> 每次使用：把原始输入粘贴进来，按照这个框架逐层处理。

---

## 前置条件：采集和分析不在同一时间做

白天保持采集模式——在现场、在路上、在和人聊。感知打开，不评判不分析，只记录。晚上切换到处理模式——用本模板做深度处理。

这个分离是关键。同时做会互相干扰——分析打断感受的流动，感受干扰分析的清晰度。时间差让"什么重要"自己浮现。

保护这个节奏的关键不是保护晚上的分析时间，是保护白天的接收时间——确保每天有一段不受打扰的、可以观察和感受的时间。

---

## 使用说明

**处理逻辑顺序：**
```
原始输入
↓
第一步：分类（把混杂的内容归到对应的桶里）
↓
第二步：提炼（从每个桶里找最有力的东西）
↓
第三步：生成话题（按母线归类，打质量分）
↓
第四步：质量过滤（剔除初级的，保留有深度的）
↓
第五步：整理行动项
```

**质量过滤标准（上线前自问）：**
```
□ 这个话题说出了别人有但没说出口的东西吗？
□ 这个角度是从真实观察来的，还是概念推导来的？
□ 听完之后用户有"原来如此"或"这说的就是我"的感觉吗？
□ 这个话题只有我能说吗？还是任何人都能说？
□ 这个表达有我自己的气味吗？
```

5 条全过，进话题库。过不了 3 条，打回重做。

## 模板正文

```
==============================
日期：YYYY-MM-DD
来源：语音录音 / 微信输入 / 文字笔记
时长/字数：XX分钟 / XX字
==============================

【原始输入】
（粘贴原始内容）


【第一步：分类归桶】

▌ 空间 / 材料 / 工艺观察（母线1-3）
- 

▌ 案例 / 现场观察（母线4）
- 

▌ AI / 认知 / 工具判断（母线5）
- 

▌ 真实生活 / 身份 / 情绪（母线6）
- 

▌ 商业 / 行业 / 服务逻辑（母线7）
- 

▌ 意义 / 文明 / 哲学观察（母线8）
- 

▌ 系统 / 工具想法（不做内容，进系统规划）
- 

▌ 个人状态 / 感受（注入活人感用）
- 


【第二步：提炼最有力的表达】

今天最强的一句话（可直接做钩子）：
→ 

今天最反常识的判断：
→ 

今天最真实的观察（只有亲历才有的细节）：
→ 

今天最让自己不舒服但真实的想法：
→ 


【第三步：生成话题】

| 编号 | 话题标题 | 母线 | 来源（哪段观察） | 初步评分(1-5) |
|------|---------|------|-----------------|--------------|
|      |         |      |                 |              |


【第四步：质量过滤】

打分 ≥ 4 的话题，逐条过质量关：

话题：
□ 说出了别人有但没说出口的东西？
□ 角度来自真实观察，不是概念推导？
□ 用户有"原来如此"或"这说的是我"的感觉？
□ 只有我能说，不是通用内容？
□ 有我自己的气味？

结论：进库 / 打回修改 / 暂存


【第五步：行动项】

▌ 进话题库（本次新增话题）
- 话题编号 + 标题

▌ 进系统规划（工具/流程想法）
- 

▌ 商业跟进
- 

▌ 值得深挖但还没想清楚的
- 
==============================
```

## 注意事项

**关于活人感：**  
模板本身不能给你活人感。活人感来自"第二步：提炼最有力的表达"那四个问题。  
如果你跳过那四个问题直接生成话题，出来的东西就会是初级的。

**关于质量过滤：**  
不要为了凑数量跳过过滤。  
10 条话题里只有 2 条过关，是正常的。  
这 2 条比 10 条都过关更有价值。

**关于系统想法：**  
在录音里你经常同时说内容想法和工具想法。  
这两类要分开，工具想法进系统规划，不要和话题混在一起。

**关于更新频率：**  
不需要每天都处理。  
但每次处理要完整走一遍，不要跳步骤。
