# 话题库 V1｜平台适配与表达形式表

> 本文件是 `话题库-V1.md` 的配套决策表。  
> 基于：`05-内容生产体系/16-平台规则与发布调性表.md` + `05-内容生产体系/11-内容形式决策器.md`  
> 每条话题已确定：主形式、图文/视频类型、视觉风格、首发平台、可延伸平台、内容核心作用。

---

## 形式与平台代号说明

| 代号 | 含义 |
|------|------|
| **G1** | 图文·提问反转型（为什么X？其实是Y） |
| **G2** | 图文·场景拆解型（一个场景拆成多层） |
| **G3** | 图文·步骤流程型（怎么做/怎么选/判断路径） |
| **G4** | 图文·前后对比型（错误 vs 正确 / before vs after） |
| **口播** | 真人口播（个人观点、经历、判断） |
| **V1** | 视频·实拍原生型（需要真实现场素材） |
| **V2** | 视频·AI生成型（无需真实素材，适合抽象内容） |
| **V3** | 视频·混合增强型（真实素材 + AI字幕/旁白/结构图） |
| **S1** | 视觉·治愈系叙事插画风 |
| **S2** | 视觉·中性实用决策板风 |
| **S3** | 视觉·实景对比标注风 |
| **抖** | 抖音（快节奏、强钩子、情绪冲突） |
| **书** | 小红书（可收藏、有方法、有审美） |
| **号** | 视频号（克制、可信、适合熟人传播） |
| **B** | B站（深度拆解、系列化、逻辑完整） |

## 母线 1｜空间秩序

核心作用：帮用户从"感觉乱"找到"是哪里乱、怎么改"。  
整体特征：痛点强、可视化高、收藏价值大。

| T-1-01 | 收纳做完了，家为什么还是乱？ | G1 | G1 + S3 | 书 | 抖 | 共鸣→理解 |
| T-1-02 | 玄关没做好，出门的焦虑就解决不了 | G2 | G2 + S3 | 书 | 号 | 理解→方法 |
| T-1-03 | 厨房动线错了，做饭就是体力活 | G4 | G4 + S3 | 书 | 抖 | 对比→收藏 |
| T-1-04 | 沙发旁边为什么总是堆东西？ | G1 | G1 + S3 | 抖 | 书 | 共鸣 |
| T-1-05 | 衣柜塞满了，找衣服还是要翻半天 | G2 | G2 + S2 | 书 | 抖 | 方法→收藏 |
| T-1-06 | 为什么孩子的玩具会扩散到整个家？ | G1 | G1 + S1 | 书 | 抖 | 共鸣→方法 |
| T-1-07 | 洗手台台面总是放满东西 | G3 | G3 + S3 | 书 | — | 方法→收藏 |
| T-1-08 | 书桌越乱，工作效率越差 | G1 | G1 + S2 | 抖 | 书 | 共鸣→理解 |

**备注：**
- 这条母线几乎全线适合小红书，收藏转化率高。
- T-1-04 和 T-1-08 抖音首发，钩子强，能快速抓住停留。
- 所有图文以 S3 实景标注风为主，有真实空间图时效果更好。
- 暂无 B站 的适配需要，深度不够，除非做系列"空间秩序系统"合集。
