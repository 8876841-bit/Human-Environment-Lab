AI准备 = 结构 + 核心判断 + 共鸣点

**【问题-05】一个话题可以每个平台都放吗？**
`[已解决]`

你说的：
这个话题是可以每个平台都放吗？还是说只是针对这个平台，这个话题用这种形式比较适合呢？

分析：
同一个话题可以跨平台，但不是同一个版本。同一个核心观点，在不同平台需要不同的包装：
- 抖音：钩子要强，前3秒必须抓人，情绪浓度高
- 小红书：可收藏，有方法论，信息密度高
- 视频号：克制，可信，不要过度情绪化
- B站：逻辑完整，可以深

一个话题如果各平台都值得发，就做"主版本 + 各平台适配版本"。如果只值得在一个平台发，就只发那一个。

**结论：**
核心话题可跨平台，但每个平台单独适配。不是复制粘贴，是重新包装。

**【问题-09】活人感的第一性原理是什么，怎么操作？**
`[已解决]`

你说的：
所有东西按逻辑出来都是人机的，要把我的成分加入进去——喜怒哀乐、善恶、利弊、优缺点。活人感的第一性原理是什么？

分析：
活人感的第一性原理：**真实的人是不完整的、矛盾的、会犯错的。**

AI生成的内容之所以人机，是因为它没有矛盾——它的逻辑是一致的，它的立场是稳定的，它不会说"我不确定"，不会说"这件事我曾经做错过"，不会说"我有时候不够好"。

要注入活人感，不是加入"情绪词"，而是加入真实的不完整：
- 一个你做错过的判断
- 一个你还没想清楚的困惑
- 一个你有立场但知道对方可能不认同的观点
- 一个具体的、只有你亲历才会有的细节

**操作方法：**
每次生成内容之前，问一个问题：
"这件事，我自己经历过什么？我有什么真实的情绪或判断？"
把那个回答的一句话放进内容的开头或中间。哪怕只有一句，整条内容就活了。

**融入数字生命：**
内容生成前置步骤：调取对应话题的活人感随想 → 提取一个真实时刻 → 注入内容开头或关键节点。

**【问题-10】底层逻辑和第一性原理是什么关系？**
`[已解决]`

你说的：
我一直在说这两个词，他们之间到底是什么关系？

分析：
这是一个很值得想清楚的问题。

第一性原理：最不可再分的事实/公理。是普遍的，不依赖语境。比如"人需要意义"，"透明比不透明更公平"。

底层逻辑：在特定领域/情境里，从第一性原理出发推导出来的行为原则。是你的，有你的情境和经验在里面。比如"在建材行业，透明定价是可行的商业模式"。

关系：第一性原理是地基，底层逻辑是在这个地基上盖的房子。地基是普遍的，房子是你的。

**结论：**
当你说"我要从底层逻辑出发"，你是在说：先回到第一性原理检验这件事是否成立，再推导出适用于你的情境的具体行为准则。这两步都要做，不能只做其中一步。

**融入数字生命：**
内容价值观文件里加入这个区分：第一性原理（普遍）→ 底层逻辑（个人语境）→ 具体决策。

**【问题-16】"等两年就好了"——这是周期还是结构变化？**
`[已解决]`

你说的：
我听着很反感。我觉得这是泛性的变化，不会回到从前。

分析：
你的判断是正确的。区分周期变化和结构变化的方法：

周期变化：底层逻辑没变，只是暂时偏离了平均值，会回来。比如经济的景气周期。

结构变化：底层逻辑变了，不会回来。比如信息透明化（一旦信息可以被大量获取，信息不对称带来的利润就永久性减少）、AI对某些工作的替代（一旦AI能做，人就不需要再做这件事了）。

建材行业当前面对的是结构变化：消费者获取信息的能力提升了，信息不对称缩小了，这不会逆转。

**结论：**
等不来。要么推动它，要么在结构变化中找到新的位置。

**融入数字生命：**
行业判断框架：面对"等等就好了"的思维，问：底层逻辑变了吗？如果变了，这是结构变化，不是周期。

**【问题-18】讲故事对我来说是什么，重要吗？**
`[工作中]`

你说的：
对我来说所谓的讲故事是什么呢？对我来说重要吗？重要的话，我要怎么去讲故事？

分析：
"讲故事"这个词可能对你来说太宽了。你的内容不是叙事型的（从前从前有个人……），而是观察判断型的（我发现了一件事，背后的逻辑是……）。

但"故事"有一个核心你一定要有：**具体性**。故事之所以能打动人，不是因为有情节，是因为有具体的细节——一个真实的人，在一个真实的时刻，有一个真实的感受或发现。

你的内容里已经有这种具体性了：今天去牙防所、去供应商那里、做了全屋定制多少年。这些就是你的"故事"，不需要是叙事结构，只需要有那个具体的时刻。

**方向：**
不用学"讲故事"，学"说具体"。每条内容里找到一个最具体的细节，把它放进去。

**【问题-19】看到外网好设计，更高级的用法是什么？**
`[已解决]`

你说的：
不想单纯转发，想加入点评建议。一半视频一半建议感觉太低级，高级的是什么？

分析：
"高级"不在于形式复杂，在于判断密度高。

转发 = 你在说"这个好"  
加点评 = 你在说"这个好，好在这里，一般人看不到的是这一点"

"夸夸设计"就是你自己想出来的那个高级版本：不是转发，是解析。你拿一个好设计，说清楚它好在哪里——材料的选择、比例的关系、使用逻辑、情感传达。这不是评论，是知识输出。

真正高级的是：让看的人觉得，以后遇到好设计，他们也知道从哪里看了。这叫建立判断力。

**结论：**
高级版 = 夸夸设计 = 解析好在哪里 = 帮人建立审美判断力。形式可以简单（截图+口播），但判断密度要高。

分析：

- 话题库：通过了质量过滤的5条标准

不进入系统的：
- 重复的、之前说过的
- 过于具体的日常琐事（除非有内容价值）
- 发泄性的、不需要被记住的
