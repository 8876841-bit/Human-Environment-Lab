# 视频特效风格提示词库与使用指南

## 执行摘要

本报告把面向视频与短视频创作的高频视觉风格整理成可直接复制的中文提示词库，并给出跨工具适配、参数映射、组合范式与合规提醒，重点解决“选什么风格、怎么写、落到哪个工具里怎么做”的实际问题。

## 研究依据与使用方法

面向视频生成，最稳定的写法不是“堆砌形容词”，而是把提示词拆成**视觉描述**与**运动描述**两层：视觉层控制主体、环境、构图、光线、风格与材质；运动层控制主体动作、环境运动、镜头运动、速度与节奏。Runway 的官方文档明确把 Text-to-Video 提示拆成 visual 与 motion 两部分，而 Image-to-Video 则建议把提示重点放在“画面会发生什么运动”，因为输入图像已经定义了构图、主体、光线与风格。Stability 的官方提示指南也建议以“风格—主体—构图—光线/色彩”组织提示，Midjourney 的 Style Reference 则强调参考图主要传递颜色、介质、纹理和灯光而非复制对象本身。Kaiber 也把图像阶段与视频阶段拆开：先做静态风格图，再为视频补充动作与节奏。研究论文同样表明，把图像作为参考条件再生成视频，通常更利于维持首帧质量与时间一致性。 citeturn14search1turn14search0turn2search4turn15search4turn7search7turn0academia60turn0academia63

下面这条流程图，适合把任何“我想做一个某某感觉的视频”拆成可执行提示词：

```mermaid
flowchart LR
A[创作目标] --> B[选择风格类]
B --> C[拆解主体 场景 光线 色彩]
C --> D[拆解动作 镜头 节奏 转场]
D --> E[选择工具]
E --> F[写基础提示词]
F --> G[加参数与权重]
G --> H[生成首帧或关键帧]
H --> I[短片生成]
I --> J[剪辑 调色 字幕 音乐]
J --> K[导出与复用为模板]
```

实践上，最通用的中文提示结构可以写成下面这一句。支持自然语言的平台直接粘贴；支持权重的平台，把最重要的风格词和主体词加权；不支持权重的平台，就把重要词提前并重复一次即可。 citeturn14search1turn2search11turn7search5turn15search7

```text
[主体]，[动作/状态]，[场景]，[构图/镜头]，[光线]，[风格]，[材质/纹理]，[色彩]，[节奏/运动方式]，[质量限制/负面词]
```

为了让不同工具之间更容易迁移，本报告统一采用一套“跨工具归一化参数”。这不是某一家平台的官方参数表，而是把官方文档中常见的 LUT、Look、Stylize、Intensity、Motion Blur、FPS、Keyframe、Grain 等概念折算成可互相映射的创作语言。Adobe、Blackmagic、LumaFusion、CapCut 的官方文档都证明：即使这些工具不原生“读提示词”，也能通过 LUT、颜色面板、关键帧、效果栈、字幕动画、速度曲线和表达式来落实同一套风格意图。 citeturn1search1turn13search7turn13search3turn9search8turn21search5turn4search0turn6search0turn5search7

| 色温 | 冷 / 中 / 暖 | 蓝紫 / 中性 / 金橙 |
| 对比 | 低 / 中 / 高 | -20 ~ +30 |

### 模板使用原则

封面模板的重点是**主体、构图、主色和风格落点**；过渡模板的重点是**镜头动作、形变或错位**；整段视频模板的重点是**统一节奏、镜头语言与质感控制**。如果平台支持参考图，请优先先做一张“风格定帧”，再用它做 Image-to-Video 或 Style Reference，这通常比纯文本更稳。Runway 的 I2V 以图像负责风格和构图、文本负责动作；Midjourney 与 Kaiber 都支持用图像参考保持风格一致；VideoGen 和 Emu Video 的研究也支持“先图后动”的稳定性思路。 citeturn14search0turn15search4turn7search9turn7search10turn0academia60turn0academia63

## 合规与伦理说明

中国现行《生成式人工智能服务管理暂行办法》适用于面向公众提供生成文本、图片、音频、视频等内容的生成式人工智能服务，并强调服务提供者需要在安全、合法来源、个人信息与知识产权等方面承担责任。对于创作者个人来说，最实用的做法不是猜规则，而是把**素材来源、参考图来源、是否商用、是否涉及真人肖像/品牌/受保护角色**先核对清楚。 citeturn10search1turn10search0turn10search3

从版权常识看，很多法域通常把版权保护重点放在**具体表达**，而不是抽象概念、方法或一般“风格”。美国版权局的基础 FAQ 也明确，版权不保护 ideas、systems、methods 之类的抽象层；但一旦进入具体作品画面、角色造型、镜头排布、商标、受保护人物形象、可识别表演与声音，就可能触发更具体的版权、商标、肖像与不正当竞争风险。与此同时，美国版权局对 AI 的持续研究说明：AIGC 输出的版权性与人类作者贡献度密切相关，相关规则仍在发展中；WIPO 也把生成式 AI 与知识产权问题视为持续演化的国际议题。换成创作语境，最稳妥的策略是：**借鉴风格，不复刻具体作品；学习方法，不冒充作者；明确参考，不虚构原创链路。** citeturn11search2turn11search0turn11search4

实操上，建议你遵守四条底线。第一，不写“完全复制某在世艺术家某代表作”的提示，而改写成可描述的视觉语言，例如“高反差黑白、百叶窗阴影、潮湿街面、硬边光”。第二，商用前检查平台条款、订阅计划、素材授权与模型限制。第三，涉及真人肖像、他人品牌、影视角色、歌手面孔、主播声纹时，优先取得授权。第四，公开发布时，尤其是广告、新闻化表达或高度写实视频，建议适度标注 AI 参与，以免误导受众。Pika 等平台的服务条款与可接受使用政策也都把用户输入内容责任与使用规范放在用户侧。 citeturn16search6turn16search8

如果只保留一句最实用的合规原则，那就是：**把“像某种风格”写成可解释的视觉特征，把“像某个人/某作品”改成你自己可复述的镜头、光线、材质与色彩。**
