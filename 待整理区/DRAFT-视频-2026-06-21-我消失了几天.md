# DRAFT-视频｜我消失了几天，在造一个脑

状态：DRAFT
来源：2026-06-17至06-21 系统建设过程
主形式：V2 AI生成型视频
平台：小红书/视频号 50-70秒
所属母线：AI认知秩序 + 真实生活与身份转型（跨两条）

---

## 一、触发点

视频日记断更了好几天。不是因为停了——是在建一个系统，做到一半发现它不是"学工具"那种事。然后发现了一个更根本的问题：整个系统里，没有"时间有限性"。

表面上需要"补一期视频日记"，实际上在说的是：

```text
这些天不是在学AI，是在建一个会思考的系统。
而且发现了一个之前漏掉的东西——它应该是所有决定的底层约束。
```

更深一层：

```text
不是要汇报进度。是想记录一个真实的转折点——当把"人会死"这件事放回系统里之后，很多事情突然不需要纠结了。
```

---

## 二、第一性原理锚点

内部判断：

```text
时间有限性是一切决策的底层约束。之前建系统时只想了"怎么做得更好"，没想过"时间走到哪为止"。
```

进一步拆解：

```text
"向阳而生，向死而生"——
向阳是方向向量（朝向生长、创造、秩序），
向死是边界条件（知道终点在哪，不在中间绕路）。

两个必须同时成立。
没有边界的生长是无限扩张（散），
没有方向的边界是虚无主义（废）。
```

这个发现不是加了一条规则，是给所有已有规则加了一个边界条件：
- "不要等"从建议变成推论——时间不可逆，"等"不是中性行为，是消耗
- "先跑起来比想清楚重要"从经验变成推论——想到50%就动，后面50%的清晰度在行动中获得
- "AI省下来的时间用来做什么"从开放问题变成判断标准

所以这条内容的核心不是"汇报做了什么"，而是：

```text
当你把"时间有限"这四个字认真放回你正在做的事里，很多纠结会自动消失。
```


### 3. 我们要表达什么


```text

```

也不是"我建了一个很厉害的系统"——是**"我在建系统的过程中发现了一个连我自己都漏掉的东西"**。

### 0-5秒｜钩子

**画面**：空白的日历，连续几天被跳过，页面微微泛黄，自然光。

---

### 5-15秒｜揭晓：不是停了

**画面**：从日历切到一个逐渐亮起的结构图——像星系又像神经网络，黑暗中慢慢浮现。不是科幻感，是"有人在搭东西"的手工感。

**旁白**：
不是因为停了。是我在做一件事——做到一半发现，它不是"学一个工具"那种事。

我在做一个能帮我想问题的东西。

**屏幕文字**：`在做一件事 / 不是学工具`

---

### 15-28秒｜转折：漏了一样东西

**画面**：结构图中有一块是空的、暗的——周围都在亮，就那一块没点亮。镜头慢慢推近那块空缺。

**旁白**：
做到一半我发现——整个系统里，漏了一样最基本的东西。

时间有限性。

就是"人会死"这件事。

**屏幕文字**：`漏了一样东西 → 时间有限性`（"时间有限性"停留2秒）

---

### 28-42秒｜展开：为什么重要

**画面**：空缺处开始亮了——不是强光，是暖的、稳定的琥珀色。然后这束光开始连接到结构的其他部分。

**旁白**：
听起来很基本对不对？但我建系统的时候，想的全是怎么做得更好、怎么输出更多、怎么架构更完整——没有一个地方写着：时间有限。

我把这四个字加进去之后，之前很多纠结突然不需要纠结了。

**屏幕文字**：`没有一个地方写着 / 你的时间是有限的`

---

### 42-55秒｜金句：向阳向死

**画面**：一棵树，上半部分在阳光里向上长，下半部分在地下有同样庞大的根系。抽象、干净的画面。

**旁白**：
"向阳而生，向死而生。"

向阳是方向——朝向生长、朝向创造。
向死是边界——知道终点在哪，不在中间绕路。

两个都得有。

**屏幕文字**：`向阳而生，向死而生 / 方向 + 边界`

---

### 55-65秒｜落地：这支视频本身

**画面**：镜头拉远，刚才所有的画面缩成小光点，融入大的暗色背景。然后出现一行小字："这支视频，是AI全自动生产的。"

**旁白**：
然后呢，这支视频本身也是一个实验——从脚本到画面到声音，全部用AI来做。

你们现在看到的，就是这个实验的结果。

**屏幕文字**：`这支视频 = AI全自动生产实验`

### 65-70秒｜收束

**画面**：回到那个结构图，空缺已经被暖光填上了。画面安静停留。

**旁白**：
这几天我没有更新。但我也没有停。

## 八、字幕 / BGM / 制作注意

### 字幕规范

| 属性 | 值 |
|------|-----|
| 字体 | 思源黑体 Medium 或 PingFang SC Medium |
| 正文色 | `#D6D6D6`（浅灰） |
| 强调色 | `#E8B86D`（暖琥珀，对应画面的主色调） |
| 字号 | 36px（主字幕）、28px（副字幕） |
| 位置 | 中下 1/3 处 |
| 出现方式 | 淡入（0.3s），不弹跳 |

**每条字幕内容与时间码**：见第十节步骤5的SRT。

### BGM（可执行指令）

**来源**：Epidemic Sound / Artlist 等免版税音乐库。关键词搜索：

| 时间段 | 搜索关键词 | 说明 |
|--------|-----------|------|
| 0-14s | `minimal piano solo, sparse, introspective, calm` | 极简钢琴，稀疏的单音，像有人在想事情 |
| 14-24s | `low drone, subtle tension, ambient, darkness emerging` | 低频长音渐入，不抢旁白，制造"缺了什么"的感觉 |
| 24-52s | `warm piano and strings, hopeful but restrained, gradual build, cinematic ambient` | 钢琴+弦乐缓缓进入，暖但不煽情。注意：string只在 42s"向阳而生"处推到最高，然后收回 |
| 52-68s | `solo piano, return to simplicity, quiet resolution, fading` | 回到单钢琴，最后一个音符和"挖深了一点"同时落地，然后留1秒静默 |

**音量曲线**：BGM始终低于旁白 12-15dB。旁白优先，BGM是底色。

**备选方案**：如无可用的免版税音源，用 Suno AI / Udio 生成 instrumental ambient piano 背景音乐，关键词 `sparse contemplative piano ambient, warm but restrained, no drums, no climax,适合独白`。

### 制作注意

- 所有镜头加极慢 ken burns 效果（2-5% scale，全程），避免静态图呆滞感
- 镜头间过渡用 0.8s 淡入淡出（crossfade），不要硬切
- 画面色调全程统一：暗部偏深蓝 `#1a1a2e`，亮部偏暖琥珀 `#e8b86d`
- 字幕不压画面主体，避免放在 void 区域或光节点上
- 最后 1 秒黑屏，留给观众消化

### 步骤2：真实录音（用户本人）

> **不调TTS。用户本人录制。** 声音是活人感的核心，AI不能替代。

**录音文本**（= 脚本旁白，见第六节）：

```
我在做一个能帮我想问题的东西。

做到一半我发现，整个系统里，漏了一样最基本的东西。

时间有限性。

就是"人会死"这件事。

我把这四个字加进去之后，之前很多纠结突然不需要纠结了。

"向阳而生，向死而生。"

向阳是方向，朝向生长、朝向创造。向死是边界，知道终点在哪，不在中间绕路。

两个都得有。

然后呢，这支视频本身也是一个实验。从脚本到画面，全部用AI来做。

你们现在看到的，就是这个实验的结果。

这几天我没有更新。但我也没有停。
```

### 步骤4：剪辑组装（ffmpeg）

**时间轴**：

|------|------|---------|---------|------|

**ffmpeg 命令**（伪代码，Codex按实际路径调整）：

```bash
# 1. 将每张图转为对应时长的视频片段
ffmpeg -loop 1 -i shot_01_calendar.png -t 5 -vf "scale=1080:1920,setsar=1" -c:v libx264 -pix_fmt yuv420p clip_01.mp4
# ...（7个片段同理）

# 2. 拼接所有片段
# concat list → concat.txt

# 3. 叠加配音
ffmpeg -i concat.mp4 -i voiceover.mp3 -c:v copy -c:a aac -shortest final.mp4
```

**验收标准**：70秒视频，画面与配音时点对齐。每个镜头的关键情绪点和旁白同步（见脚本中的"剪辑"标注）。
