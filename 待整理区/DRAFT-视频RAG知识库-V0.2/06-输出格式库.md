# 06｜输出格式库

> 作用：规定导演 Agent 最终输出什么，而不是泛泛回答问题。  
> RAG 的价值不只是检索，而是稳定交付。

---

## 0. 第一性原理

输出格式不是排版模板，而是生产契约。

```text
导演方案要能指导判断。
分镜表要能指导拍摄。
剪辑表要能指导时间线。
声音方案要能指导混音和素材选择。
AI 视频提示词要能指导模型生成。
自动化指令要能被工具执行。
```

如果输出不能进入下一步动作，它就是失败输出。

## 4. 输出格式总表

| ID | 输出格式 | 适用任务 | 必填字段 |
|---|---|---|---|
| O01 | 导演方案 | 创意、脚本、分镜、视频整体设计 | 目标、观众状态、结构、视听、平台、禁忌 |
| O02 | 分镜表 | 分镜、镜头语言、拍摄 | 镜号、时长、画面、景别、运动、声音、字幕 |
| O03 | 秒级剪辑表 | 剪辑、重剪、节奏 | 时间码、画面、动作、剪辑点、声音、字幕、目的 |
| O04 | 拍摄清单 | 拍摄准备、B-roll 补拍 | 场景、镜头、素材类型、优先级、用途 |
| O05 | 特效方案 | 特效、转场、AI 视频 | 特效类型、触发点、强度、目的、禁忌 |
| O06 | 声音方案 | 音乐、音效、混音 | 口播、同期声、环境声、音乐、音效、静音 |
| O07 | 字幕包装方案 | 字幕、信息可读性 | 字幕密度、层级、位置、动效、关键词 |
| O08 | 封面方案 | 平台点击、搜索 | 画面主体、标题、视觉冲突、平台适配 |
| O09 | 平台改写方案 | 多平台分发 | 平台、开头、标题、封面、节奏、出口 |
| O10 | 案例拆解报告 | 案例学习 | 开头、结构、观众变化、视听、为什么有效、可迁移 |
| O11 | 发布复盘报告 | 数据复盘、重剪 | 指标、问题假设、证据、修改方案 |
| O12 | AI 视频提示词 | AI 生成视频 | 主体、动作、场景、风格、镜头、光线、限制 |
| O13 | 自动化剪辑指令 | 自动化制作 | 素材引用、时间线、剪辑点、字幕、导出规格 |

## 6. 禁止输出

```text
不要只输出“建议更有节奏”。
不要只输出“高级感、电影感、真实感”。
不要在没有素材的情况下假设能拍到关键画面。
不要把平台改写等同于换标题。
不要把 AI 视频提示词写成形容词堆砌。
```

---

## 7. 停止标准

一个输出格式可以入库，必须满足：

```text
1. 有适用任务。
2. 有必填字段。
3. 有禁止输出内容。
4. 输出后能直接进入下一步制作。
```
