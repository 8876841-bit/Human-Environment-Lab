# 09｜视听变量库

> 作用：把导演语言拆成可执行变量。  
> 没有变量库，“真实、高级、电影感”就只能停留在形容词。

---

## 0. 第一性原理

视听变量不是风格装饰，而是观众状态的控制杆。

```text
镜头控制距离和注意。
剪辑控制时间和理解。
声音控制身体感和情绪。
字幕控制无声理解和信息层级。
特效控制强调、解释和转场。
色彩和构图控制秩序、情绪和记忆。
```

每个变量入库时都必须回答：

```text
它改变观众什么？
它在哪个视频类型/平台中有效？
它在什么约束下会失败？
它如何和其他变量组合？
```

## 4. 变量作用矩阵

| 变量类型 | 主要控制 | 次要控制 | 典型失败 |
|---|---|---|---|
| 镜头 | 注意、距离、信任 | 情绪、记忆 | 主体不清、运动无动机 |
| 剪辑 | 注意、理解、节奏 | 情绪、行动 | 太快看不懂，太慢滑走 |
| 声音 | 情绪、信任、身体感 | 注意、记忆 | 音乐盖过信息，音效廉价 |
| 字幕 | 理解、无声观看 | 注意、记忆 | 字太多、层级乱、遮挡主体 |
| 特效 | 强调、解释、转场 | 注意、记忆 | 炫技、削弱真实 |
| 色彩 | 情绪、秩序、品牌 | 记忆 | 过度滤镜、与内容冲突 |
| 构图 | 识别、秩序、关系 | 情绪、信任 | 主体不明、信息拥挤 |

## 5. 镜头变量

| 变量组 | 可选值 | 观众感受 | 常用功能 |
|---|---|---|---|
| 景别 | 远景、全景、中景、近景、特写 | 空间、关系、情绪、细节 | 交代、证明、情绪、转场 |
| 机位 | 平视、俯视、仰视、主观视角 | 平等、掌控、力量、代入 | 态度、权力关系、代入 |
| 运动 | 推、拉、摇、移、跟、固定 | 接近、离开、观察、跟随、稳定 | 强调、揭示、陪伴、证明 |
| 稳定性 | 稳定、手持、轻微晃动 | 专业、真实、紧张 | 质感、现场感、危机感 |
| 距离感 | 亲近、客观、压迫、疏离 | 情绪距离 | 人物关系、品牌调性 |
| 功能 | 交代、证明、解释、情绪、对比、转场 | 信息或情绪目的 | 镜头选择依据 |

## 6. 剪辑变量

```text
镜头时长
切换频率
动作剪辑
反应剪辑
跳切
匹配剪辑
前后对比
留白
蒙太奇
节奏递进
```

判断：

```text
快切适合抓注意力，但容易牺牲信任。
慢切适合质感和情绪，但容易在信息流里被滑走。
留白不是空，而是让观众吸收证据或情绪。
```

---

## 7. 声音变量

```text
口播
同期声
环境声
动作音效
转场音
低频冲击
情绪音乐
静音留白
空间混响
品牌声标
```

组合示例：

```text
真实感：同期声 + 环境声 + 少量音乐 + 保留动作音。
高级感：低噪声环境 + 克制音乐 + 少量品牌声标 + 清晰人声。
冲击感：低频冲击 + 转场音 + 快切 + 大字重点。
纪录感：环境声 + 人物原声 + 少解释性配乐。
```

---

## 8. 字幕变量

```text
字幕密度
字幕位置
关键词高亮
信息层级
动效强度
字体重量
颜色对比
是否保留口语感
是否加入解释性标签
```

判断：

```text
短视频信息流需要更强可扫读性。
访谈和纪录片需要保留口语真实，但可删掉无意义重复。
品牌片字幕不宜喧宾夺主。
课程和教程字幕必须服务理解。
```

---

## 9. 特效变量

```text
转场特效
标注特效
对比特效
路径动画
数据可视化
物体追踪
绿幕合成
AI 生成画面
风格化滤镜
```

判断：

```text
特效的第一目的应是解释、证明、强调或转场。
不能为了“高级”而堆特效。
证据类视频慎用会削弱真实感的特效。
```

## 10. 色彩与构图变量

```text
色温：冷、暖、中性
饱和度：低、中、高
对比度：低、中、高
光线：自然光、硬光、柔光、逆光、侧光
构图：中心、三分、对称、留白、前景遮挡
背景：干净、生活化、工作现场、复杂环境
```

---

## 11. 变量组合规则

变量必须组合使用，不能孤立使用。

```text
信任组合：
真实过程镜头 + 同期声 + 低包装字幕 + 证据性特写

注意组合：
强结果画面 + 快速景别变化 + 明确标题字幕 + 声音提示

理解组合：
分段结构 + 解释性字幕 + 过程镜头 + 节奏留白

高级组合：
稳定构图 + 干净声音 + 少字 + 材质特写 + 克制转场
```

---

## 12. 主观词到变量示例

```text
更真实：
手持感 / 自然光 / 中景 / 近景 / 同期声 / 环境声 / 低包装字幕 / 少特效

更高级：
稳定构图 / 克制运动 / 留白 / 干净声音 / 少字 / 色彩统一 / 材质特写

更有冲击：
结果前置 / 快切 / 大景别变化 / 低频音效 / 高对比字幕 / 明确反差

更松弛：
慢一点的镜头 / 自然停顿 / 生活场景 / 少命令式文案 / 柔和声音
```

---

## 13. 停止标准

一条变量可以入库，必须满足：

```text
1. 写清变量本身是什么。
2. 写清它会给观众什么感受。
3. 写清适用和不适用场景。
4. 能和任务、风格、输出格式关联。
5. 写清影响的观众变量、约束、失败模式和验证方法。
```
