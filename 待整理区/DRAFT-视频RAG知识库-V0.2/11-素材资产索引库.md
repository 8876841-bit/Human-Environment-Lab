# 11｜素材资产索引库

> 作用：让导演 Agent 知道“有什么素材可用、适合什么任务、版权是否安全、存在哪里”。  
> 很多视频剪不出来，不是脚本差，而是没有可检索的素材资产。

---

## 0. 第一性原理

素材不是库存，而是导演判断的现实边界。

```text
能证明的素材，决定能建立多少信任。
能听见的现场，决定能产生多少真实感。
能找到的 B-roll，决定剪辑有没有呼吸和证据。
版权状态，决定方案能不能发布。
```

导演 Agent 不能假装素材存在。素材不足时，必须输出补拍清单、替代方案或 AI 概念画面边界。

---

## 1. 输入

```text
素材文件
项目名
素材类型
画面内容
版权状态
可用于的任务
关联案例或视频
```

---

## 2. 输出

```text
素材 ID
素材描述
适用视频类型
适用情绪
适用风格
可用于哪个任务
质量评分
是否可商用
存放位置
关联项目
关联案例
```

## 4. 素材类型

| 类型 | 用途 | 必填描述 |
|---|---|---|
| 原始视频素材 | 成片主体来源 | 场景、人物、动作、时长、声音 |
| 图片素材 | 封面、插图、证明、背景 | 内容、版权、清晰度、比例 |
| 录屏素材 | 教程、软件、流程证明 | 操作步骤、界面版本、清晰度 |
| 口播素材 | 人物表达、观点、课程 | 人物、主题、语气、收音质量 |
| B-roll 补充画面 | 证明、转场、情绪、细节 | 画面内容、可证明什么 |
| 音乐 | 情绪和节奏 | 风格、BPM、版权、可商用 |
| 音效 | 转场、动作、反馈 | 类型、强度、适用场景 |
| 字幕模板 | 信息可读性 | 字体、层级、平台、比例 |
| 封面模板 | 点击和识别 | 主体位置、标题区域、平台 |
| 剪辑模板 | 快速生产 | 节奏、比例、替换点 |
| AI 生成素材 | 概念、补充、奇观 | prompt、模型、限制、版权说明 |
| 项目文件 | 可复用工程 | 软件版本、素材依赖、导出设置 |

## 5. 命名规则

不要使用：

```text
IMG_3829.MOV
final_final_v3.mp4
素材1.png
```

建议使用：

```text
[项目]-[素材类型]-[内容]-[功能]-[版本]
```

示例：

```text
TP001-BROLL-手部操作-产品质感证明-V1.mov
TP001-COVER-大画幅留白-小红书-V2.png
TP001-AUDIO-环境声-真实现场-V1.wav
```

---

## 6. 素材质量评分

| 分数 | 标准 | 使用建议 |
|---|---|---|
| 5 | 清晰、稳定、声音好、版权明确、可直接商用 | 可作为主素材 |
| 4 | 质量好，轻微问题可修 | 可作为主素材或 B-roll |
| 3 | 可用但有明显限制 | 只用于补充或过渡 |
| 2 | 画面/声音问题明显 | 尽量不用，除非有特殊真实价值 |
| 1 | 技术或版权风险高 | 不入正式项目 |

---

## 7. B-roll 判断

B-roll 不只是“补画面”，它承担：

```text
证明
解释
转场
情绪
空间
节奏
细节
```

入库时要写清：

```text
它证明什么？
它适合放在哪个段落？
它能不能替代空泛旁白？
它是否有声音价值？
```

---

## 8. 版权与风险

必须标注：

```text
自有素材
客户授权
平台可商用素材
AI 生成素材
未知来源
不可商用
```

未知来源不能默认可用。

---

## 9. 调用规则

```text
拍摄清单、分镜、剪辑表、重剪方案、自动化剪辑指令必须调用本库。
当素材不足时，输出不能假装素材存在，必须生成补拍清单或 AI 生成替代方案。
```

---

## 10. 停止标准

一个素材条目可以入库，必须满足：

```text
1. 有素材 ID 和存放位置。
2. 写清画面内容或声音内容。
3. 写清可用于哪些任务。
4. 写清版权状态。
5. 有质量评分。
```
