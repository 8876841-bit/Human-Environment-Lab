# 10｜平台观看场景库

> 作用：把“平台差异”翻译成观看心态、观看速度、标题封面、字幕密度、节奏和转化路径。  
> 平台不是发布渠道，而是观众在某种环境下看视频。

---

## 0. 第一性原理

平台差异的本质不是 App 名称，而是接收条件不同。

```text
同一个人，在搜索、刷流、熟人转发、购买决策、学习、娱乐时，是不同的观众。
```

平台库不应写死为“某平台永远怎样”，而应拆成 6 个变量：

| 平台变量 | 导演问题 |
|---|---|
| 入口 | 观众是刷到、搜到、朋友转发，还是购买前主动查看？ |
| 速度 | 观众愿意给你几秒建立价值？ |
| 心态 | 观众是娱乐、学习、避坑、审美、购买、社交，还是信任判断？ |
| 上下文 | 观众看到视频前后，旁边是什么内容？ |
| 互动 | 平台更自然的动作是点赞、收藏、评论、私信、购买还是转发？ |
| 指标 | 这次内容更应该看点击、留存、完播、收藏、评论质量还是转化？ |

## 6. 平台判断细则

### 6.1 抖音 / TikTok / Reels

共同特点：

```text
推荐流强
开头试探成本低
画面和动作信号重要
节奏不能长期平铺
字幕承担无声观看理解
```

不同点：

```text
抖音更强调本地语境、转化链路和强互动。
TikTok 更重兴趣信号、创作者表达和短时间完成情绪或信息回报。
Reels 更依赖视觉审美、生活方式和社交关系延展。
```

### 6.2 小红书

判断：

```text
封面和标题承担第一层搜索/收藏判断。
内容要像“真实经验”和“可参考方案”，不能只像广告。
审美、生活方式、避坑、清单、对比很重要。
```

### 6.3 B站 / YouTube

判断：

```text
观众愿意看长，但必须兑现标题和封面承诺。
结构、信息密度、节奏变化、人格可信度很重要。
开头可以不极端快，但必须让观众知道为什么值得看完。
```

### 6.4 视频号

判断：

```text
熟人关系链和信任感重要。
过度网感、过度刺激、强卖货可能损害可信度。
适合观点、案例、品牌信任、企业主理人表达。
```

## 7. 动态改写规则

同一内容跨平台改写，不是换标题，而是重算接收条件。

示例：同一个“产品真实体验”视频：

```text
抖音：
结果或冲突前置，3 秒内证明和观众有关，字幕密度中高。

小红书：
封面标题先承诺具体使用场景或避坑价值，内容要可收藏，允许更多真实细节。

B站：
开头说明为什么值得看完整体验，结构更完整，保留过程和判断依据。

企业官网：
弱化网感，强化能力证明、流程、案例、团队和联系出口。
```

## 8. 复盘指标提示

平台数据不能只看播放量。

```text
开头问题：看 3 秒留存、点击率、滑走率。
中段问题：看平均观看时长、完播率、掉点。
标题封面问题：看曝光点击率。
信任问题：看评论质量、收藏、私信、转化。
平台匹配问题：看同内容跨平台表现差异。
```

## 9. 停止标准

一个平台条目可以入库，必须满足：

```text
1. 不只写平台名，要写观看心态。
2. 有开头、标题、封面、字幕、节奏判断。
3. 有适合和不适合内容。
4. 有转化路径。
5. 来源不明确的平台经验必须标可信度 B/C，不写成绝对规则。
6. 能拆成入口、速度、心态、上下文、互动和指标。
```
