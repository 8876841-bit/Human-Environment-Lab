# 03｜视频制作原则库

> 作用：提供导演 Agent 的制作判断底线。  
> 原则库不是审美口号，而是判断“为什么这样做有效，什么时候不能这样做”。

---

## 0. 第一性原理

视频制作原则不是“好看建议”，而是控制观众状态变化的约束。

本库只收三类原则：

```text
1. 感知原则：观众能不能看见、听见、识别。
2. 认知原则：观众能不能理解、相信、记住。
3. 行动原则：观众能不能知道下一步做什么。
```

不能影响这些变量的“原则”，不入库。

## 4. 七条导演公理

### 公理 1：观众只会响应自己能感知到的东西

```text
听不清、看不清、主体不明、字幕挡画面，都会让后面的创意失效。
```

影响变量：

```text
感知、注意、理解
```

### 公理 2：注意力来自相关性、差异或未完成感

```text
观众停下，不是因为你“认真制作”，而是因为 TA 感到这与自己有关，或出现了差异、冲突、悬念、结果。
```

影响变量：

```text
注意、情绪
```

### 公理 3：理解先于说服

```text
观众还没听懂时，强行煽情、强行销售、强行升华都会失败。
```

影响变量：

```text
理解、信任、行动
```

### 公理 4：信任来自可验证证据

```text
画面、过程、声音、数据、人物处境和限制说明，比形容词更能建立信任。
```

影响变量：

```text
信任、记忆、行动
```

### 公理 5：节奏是变化，不是速度

```text
快不等于有节奏，慢不等于高级。节奏来自信息密度、镜头长度、声音层次、情绪强弱和停顿的变化。
```

影响变量：

```text
注意、理解、情绪
```

### 公理 6：平台改变接收条件

```text
同一内容进入不同平台时，观众的心态、速度、上下文、互动方式都变了，导演方案必须重算。
```

影响变量：

```text
注意、行动、记忆
```

### 公理 7：素材约束高于想象方案

```text
不存在的素材不能假装存在。AI 生成可以补概念、氛围和想象，但不能自动替代事实证据。
```

影响变量：

```text
信任、可执行性、版权安全
```

## 5. 核心原则

### 5.1 注意力原则

```text
视频开头必须让观众知道：
这和我有关；
这里有一个值得继续看的问题；
继续看会得到某种回报。
```

执行方法：

```text
具体场景开头
冲突开头
反常识开头
结果先行
问题先行
人物处境先行
```

禁忌：

```text
空泛问候
先讲背景半天
先介绍自己
开头只有抽象价值观
```

### 5.2 证据原则

```text
观众不天然相信你。
能用画面证明，就不要只用文案宣称。
能用过程证明，就不要只放结果。
能用真实声音证明，就不要全靠配乐煽情。
```

执行方法：

```text
前后对比
现场过程
细节特写
真实反馈
数据截图
操作演示
失败或限制说明
```

### 5.3 状态变化原则

```text
每条视频都必须推动观众发生一个可描述的变化。
如果观众看完和看前没有区别，视频只是素材排列。
```

常见变化：

```text
无感 → 停下
不懂 → 明白
怀疑 → 愿意了解
焦虑 → 有办法
喜欢 → 收藏
观望 → 咨询
```

### 5.4 清晰优先原则

```text
好看不能牺牲理解。
包装不能压过信息。
镜头语言必须服务观众理解，而不是服务制作者炫技。
```

检查点：

```text
3 秒内能否知道主题
10 秒内能否知道看下去的理由
每个段落是否只有一个主任务
字幕是否帮理解而不是添乱
```

### 5.5 节奏变化原则

```text
节奏不是越快越好，而是有变化。
快用于抓取，慢用于相信，停顿用于让观众吸收。
```

变量：

```text
镜头时长
信息密度
声音层次
字幕密度
转场频率
情绪起伏
```

### 5.6 平台适配原则

```text
平台不是发布渠道，而是观看场景。
同一内容进入不同平台时，开头、标题、封面、字幕密度、节奏和出口都要重算。
```

检查点：

```text
用户是搜索来的还是刷到的
用户愿意看长还是只愿意试探
平台更奖励互动、收藏、完播还是转化
内容是否符合平台语感
```

### 5.7 真实约束原则

```text
不能用不存在的素材假装可执行。
不能让 AI 生成画面承担它不擅长的真实证明任务。
不能把没有事实来源的判断包装成权威结论。
```

---

## 6. 原则冲突处理

常见冲突：

| 冲突 | 优先级 |
|---|---|
| 好看 vs 看懂 | 看懂优先 |
| 快节奏 vs 信任 | 信任优先，尤其是高客单价/专业/转化内容 |
| 平台刺激 vs 品牌可信 | 长期可信优先 |
| AI 奇观 vs 事实证明 | 事实证明优先 |
| 信息密度 vs 观众吸收 | 可理解密度优先 |

---

## 7. 调用规则

```text
原则库必须在输出前调用，用来做最后校验。
当原则冲突时，优先服务观众状态变化和真实素材约束。
```

---

## 8. 停止标准

一条原则可以入库，必须满足：

```text
1. 能解释为什么有效。
2. 有适用和不适用场景。
3. 能落到变量或动作。
4. 能用于检查输出质量。
5. 能说明影响注意力、理解、情绪、信任、记忆、行动中的哪个变量。
```
