# 08｜案例拆解库

> 作用：沉淀跨行业视频案例中的可迁移机制。  
> 本库不是收藏夹，而是把案例拆成“为什么有效”和“哪些方法能迁移”。

---

## 0. 第一性原理

案例不能直接复制，只能提炼机制。

```text
表层：标题、音乐、字幕样式、转场、镜头外观。
机制：它改变了观众哪个状态，用什么证据、节奏、声音和结构做到。
```

案例库只收“可迁移机制”，不收“爆款迷信”。

## 4. 案例分类

| 类别 | 重点看什么 | 可迁移机制 |
|---|---|---|
| 汽车广告 | 速度、空间、材质、驾驶欲望 | 运动镜头、低频声音、细节质感 |

| 带货视频 | 信任、需求、行动 | 痛点-演示-证据-权益 |
| 品牌短片 | 价值观与真实故事 | 场景化价值观、人物承载 |
| AI 生成短片 | 概念、视觉奇观、风格一致性 | 世界观设定、镜头连续性 |
| 电影片段 | 视听叙事、情绪推进 | 镜头动机、声音层、节奏变化 |

| 直播切片 | 高光提取、上下文补足 | 金句前置、问题背景、行动出口 |
| 个人 IP 视频 | 人设、观点、关系感 | 真实判断、稳定语言、连续议题 |

## 6. 拆解判断标准

### 6.1 开头 3 秒

看：

```text
是否建立相关性
是否制造悬念或冲突
是否给出结果或利益
是否有强画面或强声音
是否符合平台观看速度
```

### 6.2 核心创意

看：

```text
是否一句话说得清
是否和观众需求有关
是否有可被记住的表达
是否能用画面证明
```

### 6.3 可迁移方法

只提炼方法，不照搬表层：

```text
不要复制同款标题。
不要复制同款音乐。
不要复制同款字幕样式。
要提炼背后的状态变化、结构、证据和视听变量。
```

---

## 7. 调用规则

```text
当任务涉及创意、开头、分镜、剪辑、平台改写、复盘时，必须调用案例库。
案例库不能单独输出结论，必须与原则库和视频类型库一起使用。
```

---

## 8. 停止标准

一条案例可以入库，必须满足：

```text
1. 有明确来源或文件位置。
2. 拆出观众状态变化。
3. 写清为什么有效。
4. 写清可迁移方法。
5. 写清不可照抄部分。
```
