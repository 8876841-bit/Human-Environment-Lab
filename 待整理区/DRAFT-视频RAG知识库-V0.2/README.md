# Video RAG System｜视频导演知识库索引

> 本目录是 `09-内容与视频执行中台` 的导演 RAG 子系统。  
> 它服务内容与视频执行链路，不重新定义 HEL 根基，不替代数字生命的最高判断。

---

## 目录定位

```text
现实输入
↓
原创判断
↓
内容任务定义
↓
平台与受众判断
↓
用户行为目标判断
↓
视频导演 RAG 判断
↓
导演方案 / 分镜 / 剪辑表 / 提示词 / 自动化制作指令
↓
发布运营
↓
数据与反馈回流
```

导演 RAG 的工作不是“回答视频问题”，而是把模糊意图转成可执行导演决策。

---

## 第一性原理

```text
视频 = 时间中的感知工程。
导演 = 在真实约束内组织视听材料，使观众发生状态变化的人。
导演 Agent = 把用户意图、平台场景、素材约束和视听变量组合成可验证状态变化的系统。
```

本系统不把知识条目当模板，而把它们当 Operator（算子）：

```text
触发条件
↓
视听动作
↓
影响注意力 / 理解 / 情绪 / 信任 / 记忆 / 行动
↓
约束与失败模式
↓
验证方法
```

## 停止标准

本目录的知识库达到可用状态，至少要满足：

```text
1. 每条知识都有稳定 ID、来源、可信度、适用场景和不适用场景。
2. 每个用户任务都能先被归入一个任务类型，而不是直接检索资料。
3. 每个导演输出都能说明观众初始状态、目标状态和视听执行方式。
4. 每个主观词都能落到至少 3 类可执行变量。
5. 每个平台判断都区分用户心态、观看速度、开头要求、标题封面逻辑。
6. 每个案例都提炼“为什么有效”和“可迁移方法”，不只收藏链接。
```
