## 一、脚本（中文语境优化版）

```
[0-5秒｜钩子]

一帮做建材的人一起没落，反而不再挣扎了。

[5-12秒｜展开]

你一个人生意不好的时候，你会想办法。你会焦虑。你会睡不着。
但一圈人都不好了——你反而不焦虑了。

我前几天去了一个供应商那里。他跟我说，
大家都在扛。扛不住的已经悄悄关了。
说这话的时候他很平静，甚至笑了一下。

那个笑，让我很不舒服。

[12-20秒｜反转]

不是他。是我突然想明白了一件事——
当不幸只落在一个人头上，它是惨。
当不幸落在一群人头上，它就变成了一种……常态。
常态不用你负责。常态不需要改变。
"大家都这样嘛。"

[20-30秒｜扎进去]

但这句话的可怕，就在这里。

不是因为行业真的不行了。
是因为"大家都这样"让你不用动了。
你不动，你就跟着一起往下滑。
所以一群人的没落，不是抱团取暖。
是一起静止。一起等。等到最后，悄无声息地散掉了。

[30-40秒｜追问]

你说这是无力回天吗？
不是。无力回天是还有力气，还在挣，挣不过而已。

那是顺天由命吗？
也不是。顺天由命是看清楚了大势，接受了，
然后在新的位置上重新开始。

他们不是接受。
他们是在"大家都这样"里面，把自己放平了。
那个东西不叫接受。叫麻木。

[40-50秒｜收束]

我选择不这样的原因很简单。

一个人挣扎，是惨的。
但一个人挣扎了，找到了新的位置——
他就是下一批还站着的人。
```

## 二、7 个镜头 AI 图片生成

### 全系列统一的视觉设定

```
场景：一间温暖的等候室。米白色木墙裙，淡黄墙壁，深棕色木地板。墙上挂着一个大圆钟。一束斜阳从左侧高窗打进室内。空气里有极细的灰尘，在光柱里缓慢浮着。

人物：圆润的、极简的小人。深灰色小西装。每人手里一个白色号码牌。脸部只有两粒黑色小圆眼睛。没有嘴。

钟：所有镜头里时针指在四点十分——从没动过。日历偶尔翻页——但钟不动。

色调：米白、淡黄、木色、柔灰。点缀极少的深蓝。下午四点的光——暖，但开始变薄。

风格：Wes Anderson 式对称构图 + 吉卜力手绘水彩质感 + Edward Hopper 光的孤独感。

画幅：16:9 横版。手绘水彩，纸纹透出，边缘略带铅笔线。不上纯色。

每张图都没有任何文字。画面安静。暖但不暖。
```

### 镜头1（0-5秒）

**画面任务：** 建立世界。五个一模一样的小人坐在长椅上。开场即"不对劲"——他们在等什么？

**Prompt：**
```
一幅16:9横版手绘水彩插画。一个安静的等候室。米白色木墙裙，淡黄色墙壁，深棕色木地板。墙上挂着一个大圆钟——时针指在四点十分。一束斜阳从左侧的高窗打进来，空气里有细微的灰尘在光柱里缓缓浮动。

房间中央，一条深色木质长椅上坐着五个小人。他们一模一样——圆润的身体、深灰色小西装、每人手里拿着一个白色的号码牌。脸部极简：只有两粒小小的黑色圆眼睛，没有嘴。五个人都面朝前方，安静地、耐心地、空洞地。

画面构图严格对称。暖色调但不温暖——是那种下午四点、光线开始变薄的感觉。

画风：手绘水彩，吉卜力质感，纸的纹理透出来。Wes Anderson式的精确构图。没有文字。
```

### 镜头2（5-12秒）

**画面任务：** 有人感觉到不对了。但只是"察觉"——没有行动。

**Prompt：**
```
和上一张完全相同的等候室、相同的光线、相同的色调、相同的画风。16:9横版手绘水彩。

同一个场景，但镜头推近到了中间那个小人。他——圆润的身体、灰色小西装、白色号码牌——微微转过头，往右看。右邻的小人依然面朝前方、一动不动。他又往左看。左邻也不动。他的两粒小眼睛里多了一点点东西——不是恐惧，是"察觉到了什么"的那种微小的不安。

其他人依然静止。墙上的钟依然是四点十分。光柱里的灰尘还在缓慢浮动。空气是静止的。

构图依然对称，但中间的小人转了头——微小的不对称，让人不舒服。Wes Anderson + 吉卜力水彩质感。没有文字。
```

### 镜头3（12-20秒）

**画面任务：** 人少了一个。没人转头。日历翻了。钟没动。

**Prompt：**
```
和上一张完全相同的等候室、相同的光线、相同的色调、相同的画风。16:9横版手绘水彩。

回到第一张的全景构图——五个人的长椅。但现在，左边第二个位置空了。只剩四个人。空位上的号码牌还在椅子上，静静地躺着。没有人转头看那个空位。

墙上挂着一个老式日历——那种一页一页撕的——它翻了一页。但墙中央的大钟依然是四点十分。光柱里的灰尘还在浮。

暖色调，但画面比之前更安静了一点点——那是一种少了一个人、但没有人愿意承认的安静。Wes Anderson对称构图 + 吉卜力水彩。没有文字。
```

### 镜头4（20-28秒）

**画面任务：** 有人站起来了。坐着的目光让他犹豫了。

**Prompt：**
```
和上一张完全相同的等候室、相同的光线、相同的色调、相同的画风。16:9横版手绘水彩。

最右边的那个小人站起来了。他站在长椅旁，身体转了一半——一只脚朝向门的方向，另一只脚还对着长椅。他低头看着还坐着的三个小人。三个坐着的小人同时抬起头，用那两粒黑色的小圆眼睛看着他。

站着的小人脸上没有表情——但他的身体在说"我想走"。坐着的小人脸上也没有表情——但他们的注视在说"你为什么要走"。那双眼睛没有愤怒，没有责备，只是一片安静的、均匀的"不理解"。号码牌还在他们各自手里。

光还是那束下午四点的斜阳。Wes Anderson构图 + 吉卜力水彩。没有文字。
```

**Prompt：**

```
和上一张完全相同的等候室、相同的光线、相同的色调、相同的画风。16:9横版手绘水彩。

宽景。长椅被拉远——可以看到整条椅子以及两侧的空椅子。长椅上只剩两个小人并排坐着。他们之间的间隔和原来一样——那个空出来的位置没有人去填。左侧两张空椅子、右侧一张空椅子，均匀地排列在构图中。

没有一个人说话。没有一个人转头。光柱里的灰尘还在缓慢浮着。下午四点的光线，比之前更薄了一点点——不是天黑，是光线开始知道自己要走。大钟，依然是四点十分。

暖色调的画面，但不再是暖的感受——是一种克制的、干净的沉默。Wes Anderson + 吉卜力水彩。没有文字。
```

```
没有人物。阳光还是下午四点——但光柱里的灰尘浮得更慢了，好像连灰尘都在犹豫。

极度安静的画面。暖色，但不暖。画面里有很多留白。吉卜力水彩 + Edward Hopper式光的孤独感。没有文字。
```

```
阳光从左侧打在他身上，他的影子长长地落在空椅子上。他的两粒小眼睛里没有悲伤、没有恐惧、也没有笃定——他在想事情。是一个正在做决定的人的表情。

墙上大钟依然是四点十分。但窗帘的下角动了一点点。那一丝风还在。

暖色画面的最后定格。Wes Anderson构图 + 吉卜力水彩 + Hopper的光。没有文字。
```

## 三、制作步骤

### 步骤1：出图
- 打开 ChatGPT，逐条粘贴 Prompt，用相同的风格描述保持一致性
- 每张图生成前提醒：「这7张是同一系列，请和前一张保持场景、光线、色调、人物完全统一」
- 下载到本地文件夹，按 1-7 编号

### 步骤2：录音
- 用你跟我说话的语气——不加重，不煽情，不表演
- 注意停顿：「不是他」之前停半秒。「那个东西不叫接受，叫麻木」之前停半秒
- 结尾「他就是下一批还站着的人」——平淡，笃定，不加感叹号

### 步骤3：合成
- 7 张图按时间轴排列
- 配音铺上。不加 BGM——只用开头和结尾处极轻的单音钢琴，或者完全不加
- 字幕：
  - 开头：「一帮做建材的人一起没落，反而不再挣扎了」
  - 中段：「那个东西不叫接受。叫麻木。」
  - 结尾：「挣扎的人，是下一批还站着的」

### 步骤4：发布包
- 视频号标题：「大家都这样，我就不用动了」
- 小红书图文版：7 张图 + 脚本全文
- 抖音版：精简到 35 秒（留钩子 + 反转 + 结尾，去中间展开）
