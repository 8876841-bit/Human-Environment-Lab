# 人与环境观察框架 V1

## 总母线

```
通过环境观察人：人在宇宙熵增的大背景下，持续创造局部秩序。
```

人不是对抗熵增的战士，人是在熵增中创造秩序的参与者。

---

## 核心公式

```
需求 × 行为 × 环境 × 系统 = 原创选题
```

---

## 四个基本问题

每一个内容选题，都先问四个问题：

1. **人在追求什么？** → 需求
2. **人产生了什么行为？** → 行为
3. **环境如何影响这个行为？** → 环境
4. **这个行为发生在哪个系统里？** → 系统

---

## 选题母线

### 总母线（1条）

```
通过环境观察人：人如何建立秩序、维持秩序、扩张秩序。
```

### 八条分支母线

#### 1. 空间秩序母线

**关键词**：`柜子 / 玄关 / 厨房 / 洗衣区 / 动线 / 收纳`

**核心问题**：空间如何帮助人减少混乱？

**典型选题**：
```
鞋柜为什么永远是乱的？
洗衣柜本质上是在购买注意力。
柜子不是柜子，是生活秩序系统。
```

---

#### 2. 材料感官母线

**关键词**：`木材 / 石材 / 金属 / 玻璃 / 颜色 / 触感 / 温度`

**核心问题**：材料如何影响人的感受、情绪和行为？

**典型选题**：
```
材料不是材料，是环境给人的反馈。
为什么木色让人放松？
为什么不锈钢让人觉得干净？
```

---

#### 3. 工艺机制母线

**关键词**：`封边 / 收口 / 安装 / 共振 / 防潮 / 结构 / 交付`

**核心问题**：工艺背后到底在解决什么生活风险？

**典型选题**：
```
洗烘机噪音大，不一定是机器坏了。
封边不是小细节，它影响柜子的寿命。
安装翻车，很多时候不是审美问题，是机制问题。
```

---

#### 4. 案例探家母线

**关键词**：`真实家庭 / 真实客户 / 生活方式 / 空间选择`

**核心问题**：一个家为什么会变成现在这个样子？

**典型选题**：
```
为什么有的人家看起来高级，却不想待？
为什么餐桌总是变成杂物中转站？
一个家的布局，其实暴露了一个家庭的运行方式。
```

---

#### 5. AI认知秩序母线

**关键词**：`AI / Agent / 工具 / 学习 / 工作流 / 知识库`

**核心问题**：AI如何重组人的认知、工作和社会连接？

**典型选题**：
```
AI不是工具，是认知秩序系统。
为什么普通人学AI最难的不是技术？
AI为什么让一群陌生人重新聚在一起？
```

---

#### 6. 真实生活与身份转型母线

**关键词**：`转型 / 旧身份失效 / 真实生活 / 不做AI牛马`

**核心问题**：人在时代变化中，如何重新建立自己的生活秩序？

**典型选题**：
```
旧行业失效以后，人怎么重新安放自己？
AI时代，真实生活为什么反而更稀缺？
我不是在学AI，我是在重建一种生存方式。
```

---

#### 7. 商业服务母线

**关键词**：`缝合怪木作中转站 / 诊断 / 匹配 / 责任划分 / 价格透明`

**核心问题**：混乱的行业里，如何帮客户建立判断秩序？

**典型选题**：
```
全屋定制最贵的不是柜子，是判断错误。
谁设计谁收设计费，谁管理谁收管理费。
客户真正缺的不是工厂，而是判断系统。
```

---

#### 8. 意义与文明观察母线

**关键词**：`存在 / 秩序 / 意义 / AI时代 / 人类未来`

**核心问题**：当技术越来越强，人还剩下什么？

**典型选题**：
```
如果AI解决了大部分问题，人还需要什么？
人为什么需要意义？
未来真正稀缺的，可能是有限肉身里的真实感。
```

---

## 核心原则

```
观察，比内容重要。
规律，比观点重要。
框架，比技巧重要。
```

**不要从热点出发。从真实生活、真实空间、真实行为、真实感受出发。**
