# 06-Dify 多 Agent 工作流

> 当前状态：`IMPLEMENTATION / PARTIAL_SYNC`

本目录是 Human-Environment-Lab 的 Dify / 多 Agent 技术实现层。

V2 阶段，它用于内容生产流水线：

```text
选题 → 脚本 → 视觉 / 视频 → 发布 → 复盘
```

V3 阶段，它的定位升级为：

```text
碳基真实输入
→ 硅基数字处理
→ Lab 交付判断
→ 表达传播执行包
→ 现实反馈回流
```

也就是说，Dify 不再是“自动做内容”的工具，而是 Human-Environment-Lab 的工作流底座之一。

## 三、V3 使用方式

搭建完成后，优先打开：

```text
HEL-总控Agent
```

但不要再用“帮我做爆款内容”的方式启动。

正确启动方式是输入一个真实触发：

```text
我今天真实遇到/看到/想到：……
我的身体或情绪反应是：……
它表面像是：……
我怀疑背后其实是：……
目前已有证据：……
不能公开的信息：……
```

总控 Agent 应先判断：

```text
1. 这是不是碳基真实输入？
2. 证据强度如何？
3. 需要硅基数字生命如何处理？
4. 本轮应交付成什么？
5. 是否真的需要公开表达？
```

只有当 Lab 判断“适合公开表达 / 内容传播”时，才进入选题、脚本、视觉 / 视频和发布包。
