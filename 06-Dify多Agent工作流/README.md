# 06-Dify 多 Agent 工作流

> 当前状态：`LEGACY / REFERENCE`

本目录保留为 V2-V4.1 内容生产工作流参考。

它不再作为 Human-Environment-Lab 的当前主线，也不再继续逐个同步旧脚本 Agent、视觉 Agent、视频 Agent、复盘 Agent。

V3 新主线已迁移到：

```text
06-硅基数字生命工作流-V3/
```

---

## 一、为什么冻结本目录

本目录原始结构服务于 V2 内容生产流水线：

```text
选题 → 脚本 → 视觉 / 视频 → 发布 → 复盘
```

这套结构在 V2 阶段有效，沉淀了大量表达、视觉、视频和复盘资产。

但 V3 的主线已经升级为：

```text
碳基真实输入
→ 硅基数字处理
→ Lab 交付判断
→ 表达 / 传播 / 工具 / 产品 / 服务 / 行动 / 暂不表达
→ 物理世界验证
→ 数字生命与 Lab 双重迭代
```

如果继续逐个同步旧 Agent，系统会被旧内容生产结构重新拉回去。

因此，本目录冻结为参考资产。

---

## 二、本目录仍然有价值的部分

旧资产可以提取，但不能原样继承。

可提取能力包括：

```text
人话转译
脚本节奏
视觉信息层级
镜头证据意识
视频表达形式
反馈分类
误解识别
新触发点提取
```

不再继承：

```text
默认生成选题
默认进入脚本
默认做图文 / 视频
默认以平台数据为核心判断
默认以内容发布为最终出口
```
