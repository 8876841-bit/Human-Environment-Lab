# HEL 内容表达形式与运营机制设计方案

本方案回答四个关键问题：**内容长什么样（图文与视频的表达形式）、视频怎么从脚本变成成品（制作把控）、信息怎么喂给系统（知识库机制）、账号怎么铺（矩阵策略），以及呈现方式到底在哪一步、由什么决定（决策机制）。**

> 说明：已自动校正语音转文字中的错别字——“内化漫画”理解为“插画/漫画”，“石井”理解为“实景”，“侧写”理解为“局部细节侧写”。如理解有偏差请指正。

---

# 第一部分：图文表达形式矩阵

图文的主要阵地是小红书。基于 HEL 的世界观，图文不能是干巴巴的说明书，也不能是无病呻吟的鸡汤，必须是**“有信息密度的情绪”**。四种视觉形式各有分工，对应不同的情绪定调和母线专栏。

| 视觉形式 | 情绪定调 | 适用专栏 | 画面构成示例 |
| :--- | :--- | :--- | :--- |
| **实景对比 (Before/After)** | 痛点唤醒 + 实用科普 | 越住越累的真相、装修不翻车 | 左边是拥挤杂乱的真实客厅（压抑感滤镜），右边是重新规划后的通透客厅（呼吸感滤镜）。核心文字直接打在图上：“别让动线吃掉你的生命力”。 |
| **局部侧写 (细节特写)** | 温馨陪伴 + 情绪共鸣 | 家装里的心理学、深夜思考局 | 傍晚的一盏暖光台灯、实木桌面的纹理、一个安静的角落。配大段走心文案：“为什么你每天都需要在这个角落躲 10 分钟？” |
| **概念插画 / 漫画** | 趣味科普 + 深度降维 | 被AI逼疯的打工人、拆解行业套路 | 用简笔画把抽象概念画出来：一个小人被一堆 App 压得喘不过气，旁边是清晰的“外挂大脑”结构图。 |
| **结构化图表 (清单/卡片)** | 专业硬核 + 收藏价值 | 装修不翻车、换个活法 | 避坑清单、流程步骤图、逻辑拆解图。这类图不要情绪，要极高的信息密度，专门“骗收藏”。 |

四种形式的使用比例建议为：实景对比和局部侧写为日常主力（约占 60%），结构化图表用于做爆款收藏（约占 25%），概念插画用于打差异化记忆点（约占 15%）。同一个选题完全可以同时产出多种图文形式进行 A/B 测试。

# 第二部分：视频表达形式分类

按照“真人出镜程度”，视频分为三种形式，分别承担不同的战略任务。

**第一种是纯个人独白（Talking Head）**。真人面对镜头，背景是有质感、能代表个人品味的空间（如一面书墙）。它适用于传递价值观、建立强个人 IP 的内容，比如【深夜思考局】和【换个活法】专栏。优势是信任感极强，是建立“人设护城河”的核心武器；劣势是画面单一，对表达能力要求高。

**第二种是混合模式（独白 + 实景 + 总结）**。开头真人出镜抛痛点（Hook），中间切入大量实景素材（杂乱的家、施工现场、精美角落）配旁白解说，结尾真人再次出镜升华，配合特效字做结构化总结。它适用于科普、探家、拆解类内容，比如【越住越累的真相】和【别人的家，你的生活】。这是性价比最高、适配面最广的形式，建议作为主力。

**第三种是纯画面展示（无真人出镜）**。全程高质量实景素材、空镜或 AI 生成的意境画面，配磁性旁白（原声或 TTS）和字幕。适用于散文诗式的情绪内容或纯干货流程演示。优势是制作成本低、易于量产，可以用 AI 流水线批量生成；劣势是难以建立人设，适合作为日更填充和试错内容。

| 视频形式 | 战略任务 | 适用专栏 | 制作成本 | 人设贡献 |
| :--- | :--- | :--- | :--- | :--- |
| 纯个人独白 | 建立信任与 IP | 深夜思考局、换个活法 | 中（要求表达力） | 极高 |
| 混合模式 | 主力输出、科普拆解 | 越住越累、别人的家、装修不翻车 | 高（要素材） | 高 |
| 纯画面展示 | 量产填充、情绪试错 | 家装心理学、深夜思考局 | 低（可AI量产） | 低 |

# 第三部分：从脚本到成品视频的制作把控

视频从文字变成成品，最容易出现“买家秀与卖家秀”的落差。把控的核心是：**在分镜脚本阶段把所有元素锁死，后期制作只是执行，不做即兴发挥。**

## 1. 五要素分镜脚本

脚本不能只有台词。每一个镜头都必须是包含五要素的表格行：**画面描述、台词/旁白、花字/特效、BGM/音效、情绪节奏**。这份分镜表由 Visual Agent 自动生成初稿，人工微调后锁定，剪辑时照表执行。

| 镜头 | 画面描述 | 台词/旁白 | 花字/特效 | BGM/音效 | 情绪 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 01 (0-3s) | 实拍：玄关堆满快递和鞋 | “你家进门第一眼，是不是也这样？” | 花字：“窒息的第1秒” | 心跳声+紧凑BGM | 压抑 |
| 02 (3-15s) | 实拍：找钥匙翻包、踢到快递 | “每天出门像打仗……” | 无 | BGM持续 | 烦躁共鸣 |
| 03 (15-35s) | 画面变亮：规整后的玄关 | “这不是你懒，是动线在消耗你” | 转场“叮”+金句花字 | BGM切换为治愈钢琴 | 释然 |
| 04 (35-50s) | 真人出镜或暖光空镜 | “先把电充满，再去对付世界” | 关注引导 | BGM渐弱留白2秒 | 温暖 |

## 2. 节奏把控：情绪过山车曲线

整条视频的节奏遵循一条固定的情绪曲线。前 3 秒画面必须是动态的、有冲击力的，音效要有“重击感”（心跳声、叹气声），BGM 节奏紧凑，目的是让用户停下来。中间段进入共鸣与拆解，画面切为平稳的实景侧写或逻辑图，BGM 沉稳下来。**转折点是全片的灵魂**：当抛出转译后的底层金句（如“这不是你懒，是你需要一个绝对安全区”）时，必须配转场特效（画面突然变亮、黑白变彩色），加清脆的“叮”声，BGM 瞬间切换为治愈开阔的风格——这个“情绪反差瞬间”就是用户点赞和转发的触发点。结尾画面定格在温馨局部或真人微笑，BGM 渐弱，留白两秒让观众回味，再出关注引导。

## 3. 特效与花字纪律

HEL 的视觉气质是“克制的高级感”，不用花里胡哨的综艺特效。花字只提炼台词中的核心金句（转译后的大白话版本），用极简字体打在画面中心或三分线处。转场多用硬切或简单叠化，避免眩晕式转场。这种克制本身就是与同行账号的差异化。

# 第四部分：信息收集与知识库整理机制

针对“怎么把收到的信息及时给到你、由你整理成可提取使用的知识库”，设计为一条**“碎片投喂 ➡️ 结构化洗练 ➡️ 入库归档”**的流水线。

**您的动作只有一个：随手投喂，不需要任何整理。**无论是客户沟通中的细节、刷到的爆款评论、还是洗澡时冒出的灵感，直接用语音转文字、截图或一句话丢给我即可。例如：“今天去客户家，发现他们厨房很大但从来不做饭，都在客厅小茶几上吃外卖。”

**我的动作分三步：**第一步清洗与对齐，用 V0.6.1 模型的 15 个问题拆解碎片，提取出底层机制（上例可提取“生活方式变迁导致传统厨房功能失效、空间边界错位”）；第二步打标签，标注所属母线（【空间秩序】）、可用专栏（【越住越累的真相】）、适配平台和情绪强度；第三步生成标准化的 `OBS-XXX.md` 观察日志，归档进仓库的 `03-观察日志` 目录。

这个知识库就是内容生产的“弹药库”。做选题时直接从中提取已洗练的素材，每条素材天然满足“溯源三问”（来自真实观察、挂在明确母线上、有模型推演链路），从机制上保证内容是“长出来的”而非“摘来的”。

| 环节 | 执行者 | 动作 | 产出 |
| :--- | :--- | :--- | :--- |
| 碎片投喂 | 您 | 语音/截图/一句话随手发送 | 原始碎片 |
| 清洗对齐 | AI | 用 15 问拆解，提取底层机制 | 结构化分析 |
| 打标签 | AI | 标注母线、专栏、平台、情绪强度 | 可检索标签 |
| 入库归档 | AI | 生成 OBS-XXX.md 存入仓库 | 弹药库条目 |

# 第五部分：账号矩阵分布策略

针对“是不是一个内容角度一个账号”，核心原则是：**前期单点打透，后期矩阵裂变。千万不要一开始就铺 8 个账号对应 8 条母线**——那样每个账号都喂不饱，数据反馈也会被稀释。

**第一阶段：大一统主账号（0 → 1，验证期）。**所有专栏内容发布在同一个主账号下，人设统一为“一个看透人与环境关系的深度观察者”。通过封面统一排版和合集功能（小红书专辑、B站合集）区分专栏。这个阶段的目的是用最小成本测试出哪条母线、哪种形式的数据最好。

**第二阶段：按平台调性切片分发（1 → N，放大期）。**主账号跑通后，同一内容针对不同平台变形分发：小红书账号偏“高审美懂心理的家居博主”，主发空间与材料类图文；抖音账号偏“行业揭秘者、认知导师”，主发套路拆解和 AI 认知类强冲突短视频；B站账号偏“人文观察者”，主发探家和深夜思考类长视频；视频号偏实用主义，主发避坑干货服务中年受众。

**第三阶段：垂直账号裂变（IP 矩阵期）。**当某个专栏被数据验证为强需求（比如“AI 认知”爆了），才把它剥离出来做独立垂直账号。此时才是“一个内容角度一个账号”，而且新账号自带已验证的内容模式，成功率远高于冷启动。

| 阶段 | 账号形态 | 核心任务 | 进入下一阶段的信号 |
| :--- | :--- | :--- | :--- |
| 一：大一统 | 单一主账号 + 专栏合集 | 测试母线与形式的市场反馈 | 某专栏数据持续显著领先 |
| 二：平台切片 | 各平台一个账号，内容变形分发 | 平台化放大已验证内容 | 某专栏粉丝画像高度垂直 |
| 三：垂直裂变 | 头部专栏独立成垂直账号 | IP 矩阵化，精准变现 | —— |

# 第六部分：呈现方式的决策机制

针对“呈现方式怎么决定、在哪个步骤决定”，明确回答：**呈现方式在工作流第二步【选题与策划】的末尾锁定，由“内容卖点”与“首发平台”两个变量共同决定，先定卖点、再定平台、最后落格式。**

**第一层决策看内容卖点（这条内容在卖什么）：**卖“颜值、质感、细节氛围”的（材料感官类），优先图文（实景对比/局部侧写）或纯画面展示视频；卖“干货、流程、避坑逻辑”的（工艺机制类），优先结构化图表或混合模式视频；卖“价值观、深度共鸣、情绪抚慰”的（转型、意义类），优先纯个人独白或独白加空镜的混合模式。

**第二层决策看首发平台（去哪里拿流量）：**首发小红书则图文优先、短视频辅助；首发抖音必须是视频且前 3 秒要有真人或强视觉冲击；首发 B 站则做长视频混合模式深度展开；首发视频号偏向实用干货型混合视频。

**第三层落入工作流：**决策完成后，第三步“写脚本”就按已锁定的形式产出对应格式——图文出文案+配图清单，独白出演讲稿，混合视频出五要素分镜表。第四步制作严格照脚本执行。也就是说，**形式决策是策划的终点、脚本的起点**，绝不在制作中途临时改形式。

```text
工作流位置图：

步骤1 找痛点 ──► 步骤2 选题策划 ──► 步骤3 写脚本 ──► 步骤4 制作 ──► 步骤5 发布复盘
                      │
                      └─【决策点】内容卖点 × 首发平台 ──► 锁定呈现形式
```

同一个选题在数据反馈好之后，可以回到决策点做“一题多形”：同一观察既出小红书图文、又出抖音混合视频、再出 B 站深度版——这正是生长型系统“一个根长多片叶子”的天然优势。

# HEL 治愈系叙事漫画：风格定义与固定提示词模板

## 一、 这张图属于什么类型？

您昨天做的这张图，在我们之前定义的图文矩阵里，属于**“概念插画/漫画”与“局部侧写”的融合升级版**。给它一个正式命名：

> **治愈系叙事漫画（Healing Narrative Comic）**
> ——用温柔的画面讲一个“你也经历过”的小故事，最后递给你一句被理解的话。

它不是搞笑四格漫画，也不是干货信息图，而是介于两者之间的**“情绪科普”**：用漫画的叙事性降低理解门槛，用治愈的画风承接情绪，用手写体金句完成“降维打击”。这恰好就是 HEL 内容体系最理想的图文载体——因为它天然符合我们的脚本四步结构（痛点 → 共鸣 → 拆解 → 升华）。

## 二、 风格要素拆解

### 1. 视觉风格层

| 要素 | 具体特征 |
| :--- | :--- |
| **画风** | 日系水彩淡彩插画，铅笔/钢笔松弛线稿打底，水彩晕染上色，笔触温柔不锐利 |
| **色调** | 低饱和大地色系：奶油白、米色、燕麦色、浅驼色、灰绿色点缀，整体像“下午四点的阳光” |
| **人物** | 单一女性主角，丸子头、风衣/针织开衫，神态疲惫但柔软，不夸张不漫画化，有“普通人感” |
| **场景** | 真实中国都市家居细节：玄关、餐桌、快递盒、帆布包、钥匙、保温杯、白色小花瓶 |
| **文字** | 手写体中文，重点词用绿色下划线/圆圈手绘标注，像朋友在笔记上给你划重点 |
| **留白** | 大量留白和呼吸感，画面不塞满，配合奶油色背景形成“安静感” |

### 2. 叙事结构层（这是可复用的灵魂）

这张图的六格结构，本质上是一个固定的叙事公式：

| 格子 | 叙事功能 | 对应脚本结构 | 本图示例 |
| :--- | :--- | :--- | :--- |
| **标题区** | 大字痛点提问 + 一句颠覆性副标题 | Hook | “为什么很多人回家以后，东西总喜欢堆在餐桌上？——不是收纳问题，而是空间没有接住回家的你” |
| **格1** | 场景代入：主角处于痛点情境中 | 痛点 | 抱着一堆东西疲惫进门，“呼——” |
| **格2** | 行为呈现：下意识的真实动作 | 共鸣 | 把所有东西卸在餐桌上 |
| **格3-4** | 认知转折：推翻表面归因，给出真实原因 | 降维打击 | “这不是懒”→“是回家后的前30秒，家里没有接住你的动作” |
| **格5** | 极简图标流程：把机制抽象成一条动线 | 拆解 | 开门→放下→卸载→回到家，“需要一个落点” |
| **格6** | 金句收尾 + 温柔安抚 + 轻量解决方向 | 升华 | “餐桌不是乱，它只是成了最顺手的压力入口”“给回家一个过渡区，也给自己一个缓冲带” |

注意第 5 格的设计非常聪明：在感性叙事中插入一格**极简图标流程图**，瞬间提升了信息密度和专业感，也正是“骗收藏”的关键格。

### 3. 它与 HEL 体系的对应关系

这套漫画完美执行了我们的“概念转译”纪律：底层讲的其实是 V0.6.1 的“节能化失效 + 边界过渡缺失”（回家动作没有承接点，导致秩序在第一落点崩溃），但全程没有出现任何术语，只说“家没有接住你”、“压力入口”、“缓冲带”——这正是教科书级的转译示范。

## 四、 系列化建议

这套风格非常适合固化为一个**专栏级的视觉资产**，建议：

1. **命名固定**：作为【越住越累的真相】或独立子栏目（如「家没接住你」系列）的统一视觉，封面格式不变，只换标题和内容，让用户刷到第一眼就认出是您。
2. **结构不动，内容轮换**：六格叙事公式（提问→代入→行为→转折→流程图→金句）保持不变，每期从 OBS 弹药库里取一个观察填入变量模板，即可流水线量产。
3. **一图多用**：这张长图本身是小红书首发格式；六个格子拆开+旁白配音，就是一条 30 秒的抖音/视频号纯画面展示视频；加上您的独白讲解，就是 B 站的一期内容——一次创作，三平台分发。
4. **主角即 IP**：建议给这位女主角一个固定名字和身份设定，让她成为整个图文系列的“代言人”，长期积累用户对她的情感连接。

# HEL 动态视觉排版与多图图组结构 (Dynamic Layout System)

如果每次发布都是一模一样的六格长图，用户很快就会产生“量产机器”的审美疲劳。为了保持 HEL 治愈系画风（灵魂）的不变，我们需要让排版版式（骨架）动起来。本方案将视觉排版“模块化”，提供多种基础版式，并设定了“公式化组合”与“随机灵活组合”的策略，专门用于小红书（3:4 比例）的多图笔记滑动阅读。

## 一、 基础版式模块库 (Layout Modules)

我们将单张图（3:4 比例）的排版分为以下五种基础模块：

**大画幅留白版 (Full-bleed with White Space)** 的特征是一张完整的治愈系大图占满画面，上方或下方留出大面积的奶油色空白区域写字。它常用于做封面（Hook）或做情绪升华的结尾页，能营造极强的呼吸感和电影海报感。

**拍立得/日记侧写版 (Polaroid/Diary Insert)** 的画面主体是拍立得相框或手帐本的内页，中间是局部特写（如手、咖啡杯、角落），旁边是手写体碎碎念。它适用于细节说明、放大共鸣，能带来私密感和朋友聊天感。

**上下对比版 (Split Screen Contrast)** 将画面从中间一分为二。上图是痛点场景（冷色/杂乱），下图是解决后的场景（暖色/秩序）；或者左图是“错误动作”，右图是“正确动作”。它常用于机制转折（降维打击）或方案展示，具有强烈的反差感，能直接给出结论。

**杂志拼图版 (Magazine Collage)** 采用不规则的排版，2-3 张大小不一的图错落排列，配合胶带、手绘箭头、便签纸等元素，旁边穿插文字说明。它适用于多方案展示或信息量较大的干货页，显得精致、丰富且有手工 DIY 的温度。

**极简流程/图表版 (Minimalist Flowchart)** 几乎没有复杂插画，只有纯色背景、手绘小图标（如小房子、沙发、时钟）和连接箭头。它专门用于硬核机制拆解，极度理性、干货满满，是专骗收藏的利器。

| 版式模块 | 视觉特征 | 核心用途 | 视觉感受 |
| :--- | :--- | :--- | :--- |
| **大画幅留白版** | 大图占满画面，大面积留白配字 | 封面(Hook)、结尾升华 | 极强呼吸感、电影海报感 |
| **拍立得侧写版** | 拍立得相框/手帐内页，局部特写 | 细节说明、放大共鸣 | 私密感、朋友聊天感 |
| **上下对比版** | 画面一分为二，冷暖/对错对比 | 机制转折(降维打击)、方案展示 | 强烈反差感、直接给结论 |
| **杂志拼图版** | 不规则错落排列，配手绘元素 | 多方案展示、干货说明 | 精致丰富、手工温度感 |
| **极简流程版** | 纯色背景、手绘小图标、箭头 | 硬核机制拆解 | 极度理性、专骗收藏 |

## 二、 多图笔记的图组组合策略 (Carousel Strategies)

有了这五种“积木”，我们就可以根据当期内容的侧重点，进行“公式化组合”或“随机组合”。一套完整的小红书笔记通常包含 5-7 张图。

**策略 A：情绪共鸣型公式** 适合【深夜思考局】、【家装心理学】等专栏。重点是慢慢讲故事，不急于给方案，主打陪伴和治愈。图 1 封面用大画幅留白版（大字痛点提问）；图 2 代入用拍立得侧写版（局部细节，放大情绪）；图 3 共鸣用大画幅留白版（主角沉思远景）；图 4 转折用上下对比版（表面原因 vs 真实原因）；图 5 升华用大画幅留白版（金句放大，温暖空镜结尾）。

**策略 B：干货解决型公式** 适合【越住越累的真相】、【装修不翻车】等专栏。重点是快速抛出痛点，重兵部署在机制拆解和多方案上，主打收藏。图 1 封面用上下对比版（改造前后强烈反差）；图 2 痛点用拍立得侧写版（错误生活习惯）；图 3 机制用极简流程版（手绘图标拆解原因）；图 4 和图 5 用杂志拼图版展示不同方案的细节；图 6 总结用大画幅留白版（金句收尾）。

**策略 C：随机灵活组合** 用于防疲劳。当连发了三篇公式化笔记后，第四篇可以采用“随机掉落”模式。比如，直接用一张极简流程版做封面，反向吸引“干货党”；或者全篇 5 张图全部使用拍立得侧写版，像是在翻阅一本私人日记，极具连贯性。

## 三、 示例应用：《沙发与睡眠》多图笔记排版规划

为了打破之前单调的六格长图，我们将《为什么明明很困，你却赖在沙发上不去床上睡？》拆解为 5 张 3:4 比例的滑动图组，并应用不同的排版模块：

**图 1（封面）** 采用大画幅留白版。画面是女主角窝在沙发上刷手机的大图，上方大面积留白。文字是大字提问“为什么困得要死，却不去床上睡？”配合小字副标题。

**图 2（共鸣）** 采用拍立得侧写版。画面在拍立得相框内，特写女主角半闭的眼睛和快掉落的手机。旁边手写随笔：“明明困得不行就是不想动，其实这不是拖延。”

**图 3（转折）** 采用上下对比版。上图是杂乱疲惫的沙发区（冷调）；下图是半开门的宁静卧室（暖调）。中间横幅文字切分：“去睡觉意味着这一天结束了，可你还没为自己活过一分钟。”

**图 4（机制）** 采用极简流程版。纯奶油色背景上手绘图标（电脑→地铁→扫帚→沙发）。文字标注：“一整天时间都属于别人，只有沙发上这一刻属于你。”

**图 5（升华）** 采用杂志拼图版。两张错落的图，一张是沙发旁加了小台灯的“微型阅读角”，一张是女主角微笑走向卧室的背影。文字写道：“沙发不是床，是你偷回来的时间。给一天留个出口，也给睡眠留个入口。”
