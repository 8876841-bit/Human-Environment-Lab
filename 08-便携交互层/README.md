# 08-便携交互层

本目录用于定义 Human-Environment-Lab 的便携使用方式。

它不是大型工作台，也不是复杂后台。

它要解决的问题是：

```text
数字生命不能被关在某一个对话框里。
Human-Environment-Lab 也不能变成一个笨重系统。
它必须可以被随身携带、跨设备使用、跨对话延续。
```

## 核心定位

08-便携交互层 是 V3.2 的轻量交互层。

它负责把 Human-Environment-Lab 压缩成一个可移动、可复制、可恢复的使用方式：

```text
随手记一句
↓
形成一张触发点卡片
↓
需要时进入任意对话框推演
↓
收口后写回仓库
↓
现实反馈继续追加
```

## 它不做什么

本目录暂时不做：

```text
大型网页工作台
复杂数据库
全自动分流系统
Dify 全流程自动化
n8n 自动化
微信机器人
多平台重型后台
```

原因很简单：规则没有稳定之前，自动化只会放大混乱。

当前阶段优先做便携、轻量、可恢复。

## 最小便携结构

```text
手机临时记录
↓
口袋卡片
↓
GitHub Issue / Markdown 卡片
↓
任意 AI 对话框临时推演
↓
仓库写回稳定结论
```
