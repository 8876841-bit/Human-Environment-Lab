# 02-手机端使用方式

手机端是便携层的第一入口。

因为真实触发大多发生在路上、现场、聊天中、刷信息时，而不是坐在电脑前。

## 手机端只负责捕捉，不负责整理

手机端不要承担完整系统。

手机端只做：

```text
随手记一句
拍一张图
录一段语音
保存一段原话
标一个简单反应
```

不要在手机上强行完成：

```text
完整分析
复杂归档
系统判断
长文写作
多目录整理
```

## 推荐入口

当前阶段推荐：

```text
苹果备忘录
微信文件传输助手
语音备忘录
GitHub Mobile
截图相册
```

不要求一次到位。

先把真实触发抓住。

## 手机记录格式

最短格式：

```text
记一下：
我今天看到 / 听到 / 想不明白：……
我当时反应：……
```

或者更短：

```text
触发：……
反应：……
```

## 什么时候转成卡片

以下情况需要转成口袋卡片：

```text
这个触发点反复出现。
它让我停了一下。
它可能连接到长期追问。
它需要现实验证。
它可能形成表达、工具、服务或规则。
```

如果只是临时情绪，可以暂时不转。

## 手机到仓库的最小路径

```text
手机临时记录
↓
整理成口袋卡片
↓
放入 GitHub Issue 或运行中台收件箱
↓
需要推演时复制到任意 AI 对话框
↓
收口后更新卡片状态
```

## 使用边界

手机端只解决“不要丢”。

仓库和运行中台解决“怎么处理”。

对话框解决“怎么理解”。

现实世界解决“怎么验证”。
