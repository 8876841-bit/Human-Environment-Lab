# 01-口袋卡片模板

口袋卡片用于把一个真实触发点压缩成最小可携带单元。

它的目标不是完整分析，而是让触发点可以被保存、转移、继续处理和写回。

## 标准模板

```text
卡片编号：

标题：

我看到 / 听到 / 想不明白的事：

现场来源：
在哪里发生？谁说的？我怎么遇到的？

我当时的反应：
困惑 / 不舒服 / 好奇 / 怀疑 / 触动 / 其他

我初步觉得里面有：
不用写完整判断，只写直觉。

当前状态：
先放着 / 要继续想 / 要问人 / 要验证 / 可以表达 / 已收口

下一步：
只写一个动作。

是否需要写回仓库：
是 / 否 / 待定
```

## 极简模板

手机上来不及写完整时，用这个：

```text
标题：
一句话触发：
我的反应：
下一步：
```

## 示例

```text
卡片编号：TRG-20260616-001

标题：
为什么很多建材人觉得过两年市场会变好？

我看到 / 听到 / 想不明白的事：
最近听到建材行业里的人反复说：再熬两年，市场应该会好。

现场来源：
来自行业对话和日常观察。

我当时的反应：
困惑。觉得这句话不只是市场判断，背后可能有旧周期经验、自我安慰和生存惯性。

我初步觉得里面有：
人在旧系统下行时，如何判断自己是在等待周期，还是在逃避重构。

当前状态：
要验证。

下一步：
问 5 个建材人：你说的“变好”具体指什么？

是否需要写回仓库：
是。
```

## 使用规则

```text
一张卡只放一个触发点。
一张卡只保留一个下一步。
卡片可以粗糙，但不能没有现场来源。
没有下一步的卡片，默认先进“先放着”。
```

## 卡片和长分析的关系

卡片不是分析。

卡片进入对话框后，才可以展开分析。

分析结束后，只把必要结论写回卡片：

```text
当前状态变了什么？
下一步变了什么？
有没有形成规则？
有没有产生新分支？
```
