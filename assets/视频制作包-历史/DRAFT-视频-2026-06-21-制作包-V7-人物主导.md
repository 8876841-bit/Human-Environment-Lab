# 视频制作包 V7｜人物主导 + 画中画 + 口型同步

口播：88.8秒，已录制
人物形象：OSS `codex-video/portrait-photos/2026-06-21/`（5张，不同妆造可切换）
格式：人物（写实，口型一致）+ 补充画面（动画/图文，同时1-3个不等）
节奏：紧凑，每句口播对应独立画面组

---

## 画面布局规则

```
人物始终在画面内，但有三种状态：

状态A「主镜」：人物居中/偏侧，大比例，口型同步口播。无补充画面。
状态B「半镜」：人物缩至一侧（1/4-1/3画面），另一侧 + 上方出现1-3个补充画面。
状态C「小窗」：人物缩至角落小窗，画面主体是补充内容。人物持续可见但不抢眼。

切换节奏：A → B → C → B → A → B → A。状态变化本身形成节奏。
```

## 背景设计总则

```
不用平面色块。所有背景有空间深度、材质纹理、光的层次。

贯穿全片的视觉锚点：
- 光的色温从冷→暖→冷→暖（呼应口播情绪的起伏）
- 材质从粗粝→光洁→温润（呼应"门外汉→找到方向→回来"）
- 空间从压迫→开阔→安静（呼应她内心的变化）

避免：纯色背景、渐变背景、科技感网格、蓝紫霓虹。
追求：建筑空间感、自然光、材质本身就是表达。
```

## 逐句画面

### 0-4s｜"好几天没更了。"

**人物**：状态A。居中，中近景。米色外套。口型同步。

**补充画面**：无。

**场景**：背景是一面有年头的石灰墙面，粗粝但干净。自然光从画面外左上角斜打进来，在墙面留下柔和的光斑渐变。她站在墙前，光只照亮她半边脸。空气里有微尘在光柱中缓慢浮动。

---

### 4-8s｜"家里事多，另一方面，我一直在做一个东西。"

**人物**：状态B。画面左移，缩至左1/3。

**补充画面**：右侧同时出现两个画中画窗口——
- 右上：快速翻页的日历，日期被连续划掉（动画风格，手绘线条）
- 右下：层层叠叠的文档和草图，越堆越高（动画风格，纸片叠加速度越来越快）

**过渡**：人物口型从上一句延续。右画面从她身后弹出。

---

### 8-14s｜"说白了就是我的一个分身。我脑子里有很多想分享的内容，一个人搞不过来，我想让AI帮我。"

**人物**：状态C。缩至左下角小窗（1/6画面），口型持续。

**补充画面**：全屏主体——
- 画面中央：她的轮廓剪影（暖琥珀光），从身体里走出一模一样的轮廓，转身面对她。两个轮廓面对面站。
- 四周：密密麻麻的小气泡从第一个轮廓的头部涌出，每个气泡里是不同的词——"案例""工艺""判断""AI""想法""材料""趋势""观点"——气泡太多互相碰撞。
- 第二个轮廓（分身）抬起手，所有气泡被吸入它体内。画面归于安静。

**风格**：人物小窗是写实的她，大画面是发光的剪影动画。

---

### 14-18s｜"但我真的是门外汉——越做发现缺的越多，补一个坑又出一个坑，就一直陷在里面。"

**人物**：状态B。回到画面右侧1/3，口型同步。表情：一丝苦笑。

**补充画面**：左侧 + 上方同时三个窗口——
- 左上：一张不断扩大的网状图，每补上一根线，旁边就断开两根。永远补不完。
- 左中：俯拍视角——她的小人（动画）站在一个越来越大的迷宫中央，墙越筑越高。
- 左下：文字动画——"门外汉"三个字逐字弹出，越来越倾斜。

**风格**：人物写实 + 三个补充画面全是黑白线条动画，和她的暖琥珀色形成强对比。

---

### 18-22s｜"今天才觉得，稍微有点眉目。"

**人物**：状态A。居中，回到中近景。光线从冷灰微微转暖。口型同步。表情：一点如释重负。

**补充画面**：无。

**场景**：背景过渡——墙面纹理变得更细腻，像美术馆的展墙。她居中，光从左侧高位窗投射下来，形成一道窄而长的光束穿过空间。身后的墙上有极淡的影子在缓慢移动——是窗外树叶的影子。空气干净，没有微尘了。

---

### 22-28s｜"这个分身不太一样。它不是从模板里套内容——"

**人物**：状态B → C。从右侧1/3开始，说到"模板"时缩至右下小窗。口型持续。妆造切换：开始过渡到黑西装（portrait-02）。

**补充画面**：全屏——
- 画面主体：灰色传送带从左往右移动。传送带上，一模一样的光滑盒子一个接一个出来。每个盒子盖着红色大章——"模板"。
- 一条传送带。没有尽头。画面是冷灰的、机械的。

**风格**：补充画面为机械动画风格——冷灰调，和人物暖琥珀光对立。

---

### 28-38s｜"是从我自己相信的底层逻辑出发的。我的判断标准、我觉得什么重要——它从这个根上往出长。"

**人物**：状态B。回到左侧1/3，黑西装。口型同步。表情笃定。

**补充画面**：右侧 + 右下同时两个窗口——
- 右侧主窗口：传送带突然卡住。所有灰盒子翻倒。盒子底下，一颗发着暖琥珀光的种子裂开。根往下扎，穿透传送带、穿透灰色地板，进入下面的泥土。画面从灰色过渡到温暖的深棕。
- 右下小窗口：文字动画——逐层出现三个词——"底层逻辑"→"判断标准"→"什么重要"。三个词叠成金字塔。

**过渡**：灰盒子翻倒的瞬间，画面色调从灰色跳回暖琥珀。

---

### 38-44s｜"所以出来的内容不会跟人雷同。"

**人物**：状态A。居中，黑西装。口型同步。挑眉——一个小表情，不夸张。背景是一面有纵向凹槽的石灰华纹理墙面，光从右侧低位打过来，在她脸上形成微弱的三角光。

**补充画面**：人物身后出现——
- 一排八个灰色轮廓的盒子。一棵歪歪扭扭但发光的树从它们中间长出来。树不对称、有几根枝条特别长、有几根特别短。它旁边的灰盒子自动倒塌碎掉。画面只剩这棵发光的树。

**风格**：补充画面为半透明叠加在人物身后的背景层。

---

### 44-52s｜"而且它会跟着我往前走，今天想明白一个新东西，它就多一层。"

**人物**：状态B。左侧1/3，口型同步。

**补充画面**：右侧同时两个窗口——
- 右上：树的横截面动画——年轮一圈一圈往外加。先3圈，叠化成5圈，再叠化成8圈，还在继续。每圈标注一个词——"ROOT-LOCK 1""ROOT-LOCK 2""ROOT-LOCK 3"……
- 右下：快速闪现三个真实截图（Obsidian笔记、ROOT-LOCK文件片段、待整理区目录），每个只停留0.8秒。证明"它"是真实存在的。

**风格**：年轮是动画，截图是真实素材——又一次"写实+动画"碰撞。

---

### 52-58s｜"我不是在喂机器——"

**人物**：状态C。缩至画面中央极小的圆窗。口型同步。黑西装。

**补充画面**：全屏——
- 一只手往自动贩卖机投币。机器吐出一张纸。纸上是"AI标准回复"。画面冷灰色调。纸掉到地上。

**风格**：补充画面为讽刺漫画风格——故意放大"冷""机械"感，两秒闪完。

---

### 58-68s｜"是在养一个能替我表达的内容。我的想法是不断的，它出来的内容就是不断的。"

**人物**：状态B → A。从小窗放大到左侧1/3，再放大到居中。黑西装→开始过渡到白旗袍（portrait-03）。口型同步。

**补充画面**：右侧 + 上方同时三个窗口——
- 右主画面：一双手捧着土里的幼苗。浇水。苗上涌出泉水——不是喷涌的水，是发光的金色胶状体。每一滴落下来变成一段文字——"案例""观点""判断""脚本"——文字落地后自动排列成行。
- 右上小窗：计数器在跳动——"内容 1→27→103→还在增加"。
- 右中小窗：日历翻页动画——从今天往后翻，每天自动填充一个内容标题。

**过渡**：贩卖机场景和这个场景之间硬切。冷暖对比。

### 68-74s｜"你们现在看到的，就是它自己做的——画面、剪辑，全是AI跑出来的。"

**人物**：状态B。左侧1/3，白旗袍。口型同步。一个"你看到了吧"的微表情。

**补充画面**：右侧——
- 视频剪辑时间轴界面。多层轨道上排满刚才所有的画面片段。每个片段标注"AI Generated / Seedance"。鼠标在时间轴上自动移动、自动剪切。画面跳出时间轴——一行字从界面顶端落下："你现在看的这支视频 = 全AI生产"。
- 右下小窗：代码滚动窗口——API调用日志实时滚动，可以看到 Seedance、LiblibAI、ARK 的请求记录。

**风格**：补充画面为真实录屏/截图风格。时间轴可以用真实Premiere或剪映界面截图 + 标注叠加。

### 74-80s｜"算是我这些天折腾出的第一个小成果。"

**人物**：状态A。居中。白旗袍。口型同步。安静地笑了一下。背景是一面温暖的大理石墙面，米白底色带极淡的灰纹。光从正面偏上方打下来，柔和均匀。整个画面像一幅文艺复兴后期的肖像——安静、有重量。

**补充画面**：无。纯人物。身后墙面上的大理石纹理在光下微微泛暖，像日出前十分钟的天光。

### 80-89s｜"不算什么。但是个开始。我回来了。"

**人物**：状态A → 画面中央，然后缓慢缩小。白旗袍。口型同步到最后三个字——"我回来了"说完，口型闭合。

**补充画面**：无。

**场景**：人物从居中慢慢缩小。背景是同一面大理石墙，但光开始变暗——不是黑，是黄昏将至的深蓝灰。她的白旗袍在暗下去的空间里像一个暖色的光点。画面暗掉。最后一行字——"我回来了"——以极小的白色衬线体出现在中央，停留两秒，黑屏。

## 画面节奏曲线

```
0-4s   主镜  ───────────── 慢，建立连接
4-8s   半镜  ─── 2个补充画面弹出
8-14s  小窗  ─ 4个补充画面同时运行（最密）
14-18s 半镜  ─── 3个补充画面
18-22s 主镜  ───────────── 慢下来，呼吸
22-28s 小窗  ─── 传送带动画
28-38s 半镜  ─── 2个补充画面 + 色调转折
38-44s 主镜  ───────────── 再次慢
44-52s 半镜  ─── 2个补充 + 3个截图闪现
52-58s 小窗  ─ 贩卖机（最快，2秒过）
58-68s 半→主 ─── 3个补充画面（情绪高点）
68-74s 半镜  ─── 2个补充画面（元叙事揭晓）
74-80s 主镜  ───────────── 慢，落地
80-89s 主→暗 ───────────── 收束
```

## Codex 执行指令

1. **人物视频生成**：用 OSS 肖像（portrait-02/03/05，按妆造表切换）作为参考图，Seedance 图生视频模式。关键帧需保证人物面部清晰、口型自然。
2. **补充画面生成**：每个补充画面单独生成——动画/图文风格的视频片段（无需人物）。部分可用 AI 生成（Seedance），部分可用录屏/截图叠加。
3. **合成**：用 ffmpeg 或视频编辑脚本，按每段的画面布局组装。人物层在最上，补充画面在下层或侧层。位置/大小按标注调整。
4. **口型同步**：口播叠加后，微调人物片段速度，使口型大致对齐。优先保证关键句（"门外汉""底层逻辑""养""我回来了"）的口型准确。
5. **色调**：人物始终保持写实质感 + 暖琥珀光。补充画面按段落需求切换——灰色（模板/机器）、暖色（根/树/养）、白色（揭晓/回来）。
