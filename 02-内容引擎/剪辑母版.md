# 剪辑母版 V1

## 定位

剪辑是内容的第二次创作。不是炫技，是精准表达。

---

## 基本原则

1. **节奏匹配文案节奏**：快则快，慢则慢
2. **画面服务于内容**：每一帧都应该有意义
3. **情绪连贯**：避免情绪断层
4. **留白**：给观众喘息和思考的空间

---

## 剪辑流程

```
素材整理 → 粗剪 → 精剪 → 调色 → 音效 → 导出
```

---

## 各环节详解

### 1. 素材整理

**工作**：
- 分类素材（按分镜/按场景）
- 命名规范（镜号_时长_备注）
- 备份原始素材

**工具**：剪映 / PR / Final Cut Pro

---

### 2. 粗剪

**目标**：形成完整叙事结构

**要点**：
- 按脚本顺序排列镜头
- 保留完整镜头，不要过度剪辑
- 记录需要调整的地方

---

### 3. 精剪

**目标**：精准控制每一帧

**节奏控制**：
```
开头：3秒内切入正题
中间：每15-30秒有一个节奏变化
结尾：留2-3秒让情绪沉淀
```

**剪辑技巧**：
| 技巧 | 适用场景 |
|------|----------|
| 跳切 | 强调、加快节奏 |
| 慢动作 | 关键信息、情绪强调 |
| 叠化 | 转场、情绪过渡 |
| 关键帧 | 动态元素、强调 |

---

### 4. 调色

**原则**：统一色调，强化氛围

**色感参考**：
| 风格 | 色调 |
|------|------|
| 温暖自然 | 暖黄 +5~10，饱和度 +5 |
| 极简专业 | 中性色，饱和度 -5~10 |
| 电影质感 | 降低饱和，提升对比度 |
| 未来科技 | 蓝色调，青色 +10 |

**工具**：DaVinci Resolve / 剪映调色

---

### 5. 音效

**BGM选择原则**：
```
情绪匹配 > 流行度 > 个人喜好
```

**音效层次**：
| 层级 | 内容 | 音量 |
|------|------|------|
| 背景层 | BGM | -20dB ~ -15dB |
| 中间层 | 环境音 | -25dB ~ -20dB |
| 顶层 | 关键音效 | 0dB ~ -5dB |

**常用音效**：
- 关键信息出现：轻击、咔哒
- 转场：柔和过渡音
- 强调：音效 + 视觉特效配合

---

### 6. 导出

**格式建议**：
```
平台：抖音/小红书
分辨率：1080x1920（9:16竖屏）
码率：15-20 Mbps
格式：MP4 (H.264)
帧率：30fps 或 60fps
```

## 节奏模板

### 60秒版

```
0-3s：   开头钩子
3-15s：  问题建立
15-35s： 分析展开
35-50s： 核心洞察
50-60s： 金句收尾
```

### 90秒版

```
0-3s：   开头钩子
3-20s：  问题建立
20-50s： 分析展开（可分段）
50-70s： 核心洞察
70-90s： 金句收尾 + CTA
```

---

## 常见问题处理

### 问题：完播率低

**可能原因**：
- 开头不够吸引
- 内容太散，没有重点
- 节奏太慢

**解决方向**：
- 优化前3秒
- 精简内容，去掉废话
- 加快节奏

### 问题：情绪断层

**可能原因**：
- 剪辑点不自然
- 画面和文案节奏不匹配
- BGM情绪跳跃

**解决方向**：
- 找更自然的剪辑点
- 调整剪辑点位置
- 更换BGM或调整音量

### 问题：看起来"平"

**可能原因**：
- 镜头变化太少
- 节奏太均匀
- 缺乏视觉强调

**解决方向**：
- 增加景别变化
- 在关键信息处做节奏变化
- 使用特效/字幕强调
