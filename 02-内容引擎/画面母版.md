## 风格库

### A. 温暖自然

**适用**：家居、生活类内容

```
色调：暖黄/米白/木色
光线：自然光为主，柔和
质感：哑光、纹理感
```

### B. 极简专业

**适用**：知识干货、工艺讲解

```
色调：黑白灰+单色点缀
光线：冷白、专业感
质感：光滑、干净
```

### C. 电影质感

**适用**：深度洞察、文明观察

```
色调：低饱和、有氛围
光线：戏剧化光影
质感：胶片感、颗粒
```

### D. 未来科技

**适用**：AI、数字工具类

```
色调：蓝紫/赛博朋克
光线：霓虹、发光
质感：光滑、数字感
```

## AI绘图提示词模板

### 公式

```
主体 + 场景 + 光线 + 色调 + 风格 + 细节
```

### 示例

**家居温暖风格**：
```
A cozy home interior, warm afternoon light streaming through windows, 
wooden furniture, organized shelves with books and plants, 
soft shadows, warm color palette of beige and amber, 
photorealistic, shallow depth of field, 9:16 aspect ratio
```

**极简专业风格**：
```
Clean minimalist interior, white walls, 
modern furniture with simple lines, 
bright daylight from large windows, 
monochromatic palette with subtle accent colors, 
architectural photography style, sharp focus, 9:16 aspect ratio
```

**电影质感风格**：
```
Cinematic scene, moody atmosphere, 
golden hour light with long shadows, 
warm tones with cool blue accents in shadows, 
film grain texture, anamorphic lens effect, 9:16 aspect ratio
```

- [ ] AI提示词是否清晰可执行？
