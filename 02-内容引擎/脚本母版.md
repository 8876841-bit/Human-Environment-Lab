# 脚本母版 V1

## 短视频脚本通用模板

适用于60-120秒竖屏内容

---

## 标准结构

```
┌─────────────────────────────────────────────────────────┐
│ 01. 开头（Hook）                                        │
│     时间：0-5秒                                          │
│     任务：抓住注意力，建立好奇心                         │
├─────────────────────────────────────────────────────────┤
│ 02. 第一段（Problem）                                   │
│     时间：5-20秒                                        │
│     任务：建立一个让人有共鸣的问题/现象                 │
├─────────────────────────────────────────────────────────┤
│ 03. 第二段（Analysis）                                   │
│     时间：20-50秒                                        │
│     任务：展开分析，给出新视角                           │
├─────────────────────────────────────────────────────────┤
│ 04. 第三段（Insight）                                    │
│     时间：50-80秒                                        │
│     任务：核心洞察，颠覆认知或提供新思路                 │
├─────────────────────────────────────────────────────────┤
│ 05. 结尾（CTA）                                          │
│     时间：80-120秒                                       │
│     任务：金句收尾 + 行动召唤                            │
└─────────────────────────────────────────────────────────┘
```

---

## 各部分详解

### 01. 开头（Hook）

**目标**：3秒内抓住注意力

**公式**：
```
反常识 + 情绪共鸣 = 开头钩子
```

**常见写法**：
- "你知道吗，你家柜子乱的根本原因不是收纳方法……"
- "我观察了100个家庭，发现一个反直觉的现象……"
- "材料不是材料，是环境给你的反馈。"

---

### 02. 第一段（Problem）

**目标**：建立问题，让人觉得"这说的就是我"

**要素**：
- 具体场景描述
- 共鸣的情绪
- 问题的表面原因（通常是错的）

**常见模式**：
```
"很多人/我见过很多家庭……"
↓
"他们通常会……"
↓
"但问题是……"
```

---

### 03. 第二段（Analysis）

**目标**：展开分析，提供新视角

**要素**：
- 观察到的真实行为/现象
- 背后的机制/规律
- 为什么表面解法行不通

**原则**：
- 不要一次性说完
- 留悬念
- 用具体例子支撑

---

### 04. 第三段（Insight）

**目标**：核心洞察，一句话颠覆认知

**公式**：
```
现象 + 本质 + 新视角 = 核心洞察
```

**示例**：
```
"鞋柜不是鞋柜，是回家仪式系统。"
"你买的不只是柜子，是生活判断系统。"
"材料不是材料，是情绪反馈机制。"
```

---

### 05. 结尾（CTA）

**目标**：金句收尾，引发行动

**公式**：
```
洞察升华 + 情绪收尾 + 行动召唤 = 完美结尾
```

**常见写法**：
- "所以下次当你看到……的时候，你也许可以……"
- "记住，……才是真正的……"
- "从今天开始，观察你家的……"

---

## 不同风格的脚本模板

### 风格A：洞察型

**适用**：颠覆认知的选题

```
开头：反常识陈述
第一段：描述常见现象
第二段：分析背后的机制
第三段：给出新视角
结尾：升华 + 行动召唤
```

### 风格B：故事型

**适用**：案例探家类选题

```
开头：从一个场景切入
第一段：描述观察到的问题
第二段：深入分析原因
第三段：给出解决方案/思考
结尾：总结 + 启示
```

### 风格C：知识型

**适用**：工艺/材料类选题

```
开头：抛出问题
第一段：解释原理
第二段：实际案例/演示
第三段：总结要点
结尾：实用建议
```

## 脚本检查清单

- [ ] 开头3秒能抓住注意力吗？
- [ ] 整个脚本有明确的核心洞察吗？
- [ ] 是否属于八条母线之一？
- [ ] 能否回答四个基本问题？
- [ ] 有真实的观察支撑吗？
- [ ] 文案节奏是否适合口语表达？
- [ ] 结尾有call to action吗？

---

## 时长控制参考

| 时长 | 结构建议 |
|------|----------|
| 60秒 | 去掉第二段，直接 Problem → Insight → CTA |
| 90秒 | 标准结构，可增加一个案例 |
| 120秒 | 可增加一个反面案例 + 正面案例 |
