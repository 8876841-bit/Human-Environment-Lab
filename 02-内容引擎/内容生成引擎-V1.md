# 内容生成引擎 V1

## 定位

内容生成引擎是一个将"观察"转化为"内容"的流水线。

不是从热点出发，而是从真实观察出发。

---

## 流水线

```
观察 → 选题 → 脚本 → 画面 → 剪辑 → 发布 → 数据 → 复盘 → 再观察
                    ↑                                    │
                    └──────────── 形成闭环 ──────────────┘
```

---

## 各环节说明

### 1. 观察

**输入**：真实生活、真实空间、真实行为、真实感受

**输出**：OBS-XXX 格式的观察记录

**要求**：每个观察必须有真实的来源/场景/行为描述

---

### 2. 选题

**输入**：观察记录 + 选题母线

**输出**：符合四问公式的选题

```
需求 × 行为 × 环境 × 系统 = 原创选题
```

**判断标准**：
- 属于八条母线之一
- 有真实的观察支撑
- 能回答四个基本问题

---

### 3. 脚本

**输入**：选题

**输出**：短视频脚本（60-120秒）

**结构**：
```
开头（hook）
↓
第一段（建立问题）
↓
第二段（展开分析）
↓
第三段（给出视角）
↓
结尾（call to action / 金句）
```

---

### 4. 画面

**输入**：脚本

**输出**：分镜脚本 + AI绘图提示词

**包含**：
- 每个镜头的画面描述
- 场景/风格/色调/氛围
- 对应的AI绘图提示词

---

### 5. 剪辑

**输入**：分镜脚本 + 素材

**输出**：成片

**原则**：
- 画面服务于内容，不炫技
- 节奏匹配文案节奏
- BGM选择与情绪匹配

---

### 6. 发布

**平台**：根据内容定位选择

**要求**：
- 标题包含核心洞察
- 封面与选题情绪一致
- 发布时间参考数据调整

---

### 7. 数据

**关注指标**：
- 完播率（核心）
- 互动率
- 转发率
- 新增关注

**不追求**：
- 单纯播放量
- 蹭热点带来的流量

---

### 8. 复盘

**问题**：
- 完播率低：开头不够吸引/内容太散
- 互动率高：戳中了什么情绪
- 转发率高：提供了什么价值

**输出**：内容优化建议

---

### 9. 再观察

根据复盘结论，回到观察环节。

闭环的目的不是优化技巧，而是验证框架。

## HEL Agent Workbench

多Agent内容生产流水线已实现自动化：

```bash
cd hel-agent-workbench
python src/index.py "选题主题"
```

支持：
- 自动选题生成
- 自动脚本创作
- 自动分镜设计
- 自动AI绘图

## 核心原则

```
内容不是从同行模板里摘出来的
内容是从观察中自然长出来的
```
