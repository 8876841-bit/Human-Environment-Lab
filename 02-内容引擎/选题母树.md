# 选题母树

## 总览

选题母树是整个内容生产系统的根。从这里生长出所有原创选题。

---

## 总母线

```
通过环境观察人：人如何建立秩序、维持秩序、扩张秩序。
```

人在宇宙熵增的大背景下，持续创造局部秩序。

---

## 八条母线分支

### 1. 空间秩序母线

**关键词**：`柜子 / 玄关 / 厨房 / 洗衣区 / 动线 / 收纳`

**核心问题**：空间如何帮助人减少混乱？

**选题方向**：
- 柜子作为生活秩序系统的本质
- 玄关作为回家/出门的仪式感设计
- 厨房动线与烹饪体验
- 洗衣区的注意力经济学
- 收纳的终极目标不是整齐，是减少决策疲劳

---

### 2. 材料感官母线

**关键词**：`木材 / 石材 / 金属 / 玻璃 / 颜色 / 触感 / 温度`

**核心问题**：材料如何影响人的感受、情绪和行为？

**选题方向**：
- 木头的温度与安全感
- 不锈钢的洁净感与心理暗示
- 石材的厚重与权力感
- 玻璃的通透与空间延伸
- 材料如何影响人对时间的感知

---

### 3. 工艺机制母线

**关键词**：`封边 / 收口 / 安装 / 共振 / 防潮 / 结构 / 交付`

**核心问题**：工艺背后到底在解决什么生活风险？

**选题方向**：
- 封边与柜子寿命的关系
- 安装翻车的真实原因（不是审美，是机制）
- 共振噪音的本质
- 防潮处理的底层逻辑
- 交付标准与客户期望的落差

---

### 4. 案例探家母线

**关键词**：`真实家庭 / 真实客户 / 生活方式 / 空间选择`

**核心问题**：一个家为什么会变成现在这个样子？

**选题方向**：
- 高级感与居住感的矛盾
- 餐桌作为杂物中转站
- 家里最乱的角落暴露了什么
- 家的布局与家庭运行方式
- 真实客户的决策逻辑

---

### 5. AI认知秩序母线

**关键词**：`AI / Agent / 工具 / 学习 / 工作流 / 知识库`

**核心问题**：AI如何重组人的认知、工作和社会连接？

**选题方向**：
- AI作为认知放大系统
- 普通人学AI最难的不是技术
- AI活动的人群聚集效应
- Agent作为数字研究助理
- 工作流设计与知识管理

---

### 6. 真实生活与身份转型母线

**关键词**：`转型 / 旧身份失效 / 真实生活 / 不做AI牛马`

**核心问题**：人在时代变化中，如何重新建立自己的生活秩序？

**选题方向**：
- 旧行业失效后的安放问题
- AI时代真实生活的稀缺性
- 转型期的身份焦虑
- 从业者视角的观察
- 重建生存方式的路径

---

### 7. 商业服务母线

**关键词**：`诊断 / 匹配 / 责任划分 / 价格透明 / 缝合怪木作中转站`

**核心问题**：混乱的行业里，如何帮客户建立判断秩序？

**选题方向**：
- 全屋定制最贵的是判断错误
- 谁设计谁收设计费，谁管理谁收管理费
- 客户真正缺的是判断系统
- 信息不对称的本质
- 行业透明化的路径

---

### 8. 意义与文明观察母线

**关键词**：`存在 / 秩序 / 意义 / AI时代 / 人类未来`

**核心问题**：当技术越来越强，人还剩下什么？

**选题方向**：
- AI解决大部分问题后，人还需要什么
- 人为什么需要意义
- 有限肉身里的真实感
- 效率提高后，人如何不失真地活着
- 未来真正稀缺的是什么

---

## 选题判断标准

一个好选题必须满足：

1. **从观察中来**，不是从热点/同行模板中来
2. **能回答四个基本问题**（需求/行为/环境/系统）
3. **属于八条母线之一**
4. **有真实的观察基础**
