---

## 1. 为什么要锁定根基

前期系统升级过程中，曾出现一个风险：

```text
后来的执行系统，开始反向解释原始根基。
```

这会导致一个问题：

```text
表面上系统越来越完整，实际上原创内容的源头被新结构慢慢改写。
```

因此，从本文件生效开始，仓库遵守以下原则：

```text
先锁根，再长系统。
```

## 补充锁定｜来自 2026-06-17 深度处理（重做版）

> 以下内容来自真实录音的系统性深度分析。每个判断都推到第一性原理层，不可再分的判断写入根基，可操作的判断写入底层逻辑。

---

### 一、世界观：螺旋模型

**螺旋是基本世界观。不是循环，不是线性。**

三种模型的本质区别：
- 循环：事情回到原点。适合自然节律，不适合需要进化的系统。
- 线性：无限向前。忽略了"似曾相识"的体验——人确实会回到相似的情境。
- 螺旋：回到相似的处境，但你已经不是原来的你。终点和起点有相似之处，但不完全一样。

**为什么"等两年就好了"是错的：** 它用的是循环模型——默认经济会回暖、行业会回来。但建材行业面对的是结构变化（底层逻辑变了），不会回到原点。下一个"两年后"不在同一个平面上。

**三层应用：**
- 行业：不会回到熟人社会模式。会在更高层面重建规则和信任。
- 个人：同样的困惑会再次出现，但每次带着更多积累，答案不一样。
- 内容：重复话题≠重复内容。是螺旋上升的重新表达——同一个话题，更深的理解。

---

### 二、活人感：第一性原理与操作

**活人感的第一性原理：真实的人是不完整的、矛盾的、会犯错的、有偏好的。**

**为什么AI生成的内容"人机"：** 不是因为语言不自然，是因为AI的内在结构太完整了——
- 逻辑一致（真实的人前后矛盾）
- 立场稳定（真实的人今天推翻昨天的自己）
- 充满确定性（真实的人常说"我不确定"）
- 没做过错事（真实的人会说"这个我当时搞错了"）
- 没有偏好（真实的人会说"我就是不喜欢这个"）

活人感不是什么：不是加情绪词、不是加口语、不是加省略号。

**注入操作：在每条内容里，至少有一个你真实的具体时刻——**
1. 一个具体的时刻（"上周二下午三点，我在那个客户家的厨房里站了十分钟"）
2. 一个你还不确定的困惑
3. 一个你有立场且知道有人会不认同的判断
4. 一个你做过的错误判断
5. 一个只有你亲历才会知道的细节

操作极简版：生成内容之前问"这件事，我自己经历过什么？"把那句原话放进开头或中间。一句就够。

---

### 三、内容本质定位

**不是装修教程，是行业信息纠偏。**

建材行业的"基因问题"——四个初始条件决定了行业结构：
1. 信息高度不对称——消费者看不到材料来源、工艺标准、真实成本
2. 低频高客单价——一辈子装修1-2次，没有复购和口碑积累的动力
3. 熟人经济——靠关系拿货接单，质量不是护城河，关系才是
4. 没有第三方标准——消费者没有可理解的客观评判依据

四个条件加在一起 → **谁掌握信息，谁就有定价权。** 行业的竞争不是"谁做得更好"，而是"谁能把信息捂得更紧"。

这不是个别商家的问题，是结构性问题。科普解决的是"不知道"，这个行业的问题是"被故意不让知道"。所以内容使命是**信息纠偏**——把被刻意遮蔽的信息重新变得可获取。

**每条内容的最终判断标准：** 观众看完后，对行业里某件事的判断力有没有提升？不只是知道了什么，而是学会了自己怎么判断。

---

### 四、认知框架：三层结构

**第一性原理（普遍公理）→ 底层逻辑（个人语境）→ 具体决策（当下选择）**

真实示例：
- 第一性原理：透明比不透明更公平
- 底层逻辑：所以在全屋定制中，让客户知道每一笔钱的去向
- 具体决策：所以这一单用透明分账，报价单把材料费和人工费分开列

三层必须一致。检验方法：
- 怀疑具体决策 → 回到底层逻辑检验
- 怀疑底层逻辑 → 回到第一性原理检验推导起点是否成立
- 第一性原理在实践中反复碰壁 → 重新检验这个"公理"是否真的不可再分

**思考时一层一层往下推，决定时一层一层往上检验。**

---

### 五、AI与人：分工的精确边界

**AI给可能性地图。人做现场导航。**

分工的信任边界：
- 你信任AI做的事：穷举可能性、结构化信息、给框架（AI不会漏、不会因为情绪偏废）
- 你不信任AI做的事：说话（AI没有你的质地——没有现场的具体犹豫、临场判断、看到实际情况后脑子里冒出来的东西）

**操作定义：**
- AI准备 = 可能性地图（今天可以说的方向 + 每个方向的核心判断 + 可能引发共鸣的点）
- 人发挥 = 现场导航（选哪个方向、用什么语气、加入什么具体细节和真实情绪）

不是台词，是地图。人带着地图去现场，根据实际情况决定走哪条路。

---

### 六、AI关系：两条持续自问

**判断标准（大麻 vs 工具）：**
- AI让你更有能力面对真实世界 → 好事
- AI让你更难面对真实世界 → 大麻

**自问一：** 我用AI的这一刻，是在回避什么不舒服的感觉吗？还是在真正扩展我的能力？

**自问二：** 我在真实关系里的表达能力，有没有因为把"难说的话"都留给AI而变弱？

这两条不需要一次性答案，需要每隔一段时间问自己一次。

---

### 七、内容价值：高级的定义

**高级 = 解析 + 建立判断力。不是转发，不是点评。**

三级区别：
- 低级：给出内容（"看这个"）
- 中级：给出内容 + 你的判断（"看这个，好在X"）
- 高级：给出内容 + 你的判断 + 教会对方判断的方法（"看这个，好在X、Y、Z。以后你自己看的时候，也看这三个点"）

高级感不来自形式的复杂，来自**判断密度的提升**。你说的每一个点，都是对方自己看不出来、但你说完他觉得"原来是这样"的。

**"夸夸设计"纳入正式内容形式：** 一张图 + 声音 + 2-3个具体解析点 + 结尾判断力小结。

---

### 八、行业判断工具：周期 vs 结构

**区分方法：底层逻辑变了吗？**
- 没变 → 周期变化（会回来）
- 变了 → 结构变化（不会回来）

建材行业是结构变化——信息获取能力不可逆、竞争参照系从区域变全国、AI正在把"获取信息"变成"获取整理过的信息"。等不来。

**凡是听到"等X年就好了"，先问：底层逻辑变了吗？**

### 九、感知开关：具体→感受，统计→认知

**核心规律：同一个事实，呈现方式决定感知类别。**

- 具体呈现（一张脸、一个名字、一个具体时刻）→ 触发感受模式 → 道德判断、情绪反应、行动意愿
- 统计呈现（一个数字、一个趋势、一个类别）→ 触发认知模式 → 分析判断、知识获取、认知距离

**为什么：**
- 个体事件有叙事完整性——"怎么会偏偏是他"，偶然性触发道德反应
- 群体事件超过认知容量——无法处理几十万个独立故事，自动切换为统计模式
- 统计模式触发的是知识系统，不是情绪系统

**这是认知规律，不是道德缺陷。** 人的大脑无法对"几十万"产生共情，但可以对"这一个人"共情。这不是冷血，是认知架构的边界。

**反向操作（识别操控）：**
当一个不公正被说成"很多人都是这样"的时候，它在利用这个规律让你接受——"普遍"不等于"正常"。

---

### 十、内容传播第一原则：用具体不用抽象

**想让观众感受到 → 给一个具体的人、具体的时刻、具体的面孔。**
**想让观众理解到 → 给趋势、给数据、给结构。**

讲行业问题的时候，不讲"这个行业存在普遍问题"。讲"上周二下午，我站在那个客户的厨房里"。

**造势原理：势 = 同一方向上具体化感受的持续叠加。**
- 不是一次大事件 → 是一系列具体故事的累积
- 不是"大家都觉得" → 是"这一个人觉得" × 100次
- 用具体造势，不用抽象造势

一百条讲"一个人"的内容叠在一起，它的力量远大于一条讲"很多人"的内容。

---

### 十一、认知双路径：上行与下行必须都走

**上行路径（从具体到普遍）：** 微观 → 宏观 → 客观  
从具体现象出发 → 观察累积效果 → 抽取出普遍规律

**下行路径（从普遍到具体）：** 第一性原理 → 底层逻辑 → 具体决策  
从普遍公理出发 → 在具体情境中推导行为原则 → 做出当下选择

上行找规律，下行做决策。只走一条会偏：
- 只上行不下行 → 有洞察没行动
- 只下行不上行 → 有行动没根基

**操作原则：** 每次形成一个判断时，问自己：这两个方向都走过了吗？

### 十二、视频的第一性原理

**视频 = 时间中的感知工程。**

导演的本质不是"拍画面"，而是在限制条件内组织视听材料，让观众从一个状态进入另一个状态。

六条感知控制链：
- 画面控制：看见什么
- 声音控制：感到什么
- 剪辑控制：何时理解
- 结构控制：记住什么
- 平台控制：在什么心态下接收
- 行动出口控制：状态变化是否落地

**导演判断的最小公式：**
```
视频决策 = 观众状态变化 × 平台观看场景 × 视听变量 × 真实素材约束
```

如果一个建议不能说明它影响了哪个感知变量（注意力/理解/情绪/信任/记忆/行动），它就不是导演判断——只是审美形容词。

**主观词的翻译原则：**
"真实"不是滤镜，是信任变量上升。"高级"不是颜色，是认知负担下降、秩序感上升。"电影感"不是 LUT，是空间、光线、镜头动机、声音和节奏形成叙事关系。

**观众状态机：**
```
无关 → 停下 → 知道在说什么 → 愿意相信 → 觉得值得 → 记住一个判断 → 产生行动
```
导演的第一任务不是"怎么拍好看"，是"观众现在卡在哪个状态"。

### 十三、中文说话艺术的第一性原理

**说话不是技巧堆砌，是五个条件同时成立：**
内容正确（事实和判断可靠）、关系合宜（知道对谁说）、风格得体（语气节奏适合场合）、文化可感（能调用共同记忆）、传播有效（对方能理解、记住并行动）。

**中文表达的最高原则：**
```
以诚驭巧，以礼定巧，以情润巧，以势用巧。
```
诚 = 真实（和人类倩倩的核心价值观完全一致）。技巧永远被诚驾驭，不是反过来。

**中文表达的核心特征：**
```
信息不只存在于字面，也存在于关系、语气、语境和未说尽之处。
```
高水平中文表达不把所有结论说完——让听者在意象、转折和留白中参与完成。

**短视频表达的金标准：**
快而不乱，短而不浅，强而不假。

**短视频五段结构：**
冲突开场 → 结论前置 → 三段展开（原因/案例/方法）→ 边界说明（什么情况下不适用）→ 行动收束（告诉观众下一步）。

**表达能力六维评价：**
内容准确、结构逻辑、语用得体、修辞表现、非言语协调、媒介适配。不同场景调不同权重——商务谈判重语用，演讲重修辞，短视频重媒介和结构。

**AI表达的四个边界（不可逾越）：**
- 事实边界：不把未经核实的内容包装成确定事实
- 身份边界：合成声音明确标识
- 责任边界：AI辅助表达，不替代人承担责任
- 风格边界：不让所有内容变成同一种流畅但空洞的"AI腔"

### 十四、提示词工程的第一性原理

**提示词不是"写一句好指令"，而是：设计、组织、约束、优化与评测模型输入上下文的一整套方法学。目标是稳定提升任务表现、降低成本、控制风险。**

提示词工程的进化路径：单条指令 → 模板化 → 链式推理 → 自动优化 → 版本化+评测+缓存。现在已经不只是"会写"，而是**提示—评测—优化—部署**的工程闭环。

**结构化提示的核心公式（不分平台）：**
```
[主体] + [场景] + [主风格] + [媒介] + [构图/镜头] + [光线/色彩] + [情绪] + [细节] + [负面约束]
```
风格控制不是"多写风格词"，而是管理八类视觉变量与模型原生控制接口的对应关系。

**视频提示的核心公式：**
```
[视觉层：主体+环境+构图+光线+风格+材质]
+
[运动层：主体动作+环境运动+镜头运动+速度+节奏]
```

**三条最重要的工程原则：**
- 提示必须和评测绑在一起——没有数据验证，"更好的提示"可能只是偶然
- 结构化输出、版本化与缓存比"花式咒语"更容易带来真实收益
- 提示的核心问题正在从"如何诱导回答"转向"如何约束代理、分配上下文、定义成功标准"

### 十五、时间有限性——所有决策的底层约束

**"向阳而生，向死而生。"**

"向阳"是方向向量——朝向生长、朝向创造、朝向秩序。
"向死"是边界条件——知道终点在哪，所以不在中间绕路。

两者必须同时成立：没有边界的生长是无限扩张（散），没有方向的边界是虚无主义（废）。

**为什么是根基：**

螺旋世界观（一）说了"时间有方向，不回原点"。但没有说"时间走多远"。方向感和终点感是两回事——方向感让人不走回头路，终点感让人不在路上逗留。

时间有限性给所有已有根基加了一个边界条件：
- 一（螺旋）：时间有方向 → 方向有终点 → 完整时空观
- "不要等"从策略建议变成第一性原理推论：因为时间不可逆，"等"不是中性行为，是消耗
- "先跑起来比想清楚重要"从经验变成推论：思考的边际收益递减，想到50%就动，后面50%的清晰度在行动中获得
- "AI省下来的时间用来做什么"从开放问题变成判断标准：省下的时间用来做了只有你能做的事，还是回避了只有你能面对的事？

**为什么之前没放进去：** 不是不重要，是太重要、太重了。人建系统时先建"能用"的部分——怎么选题、怎么写、怎么拍。时间有限性没有操作感——知道"时间有限"之后今天该干什么？答案不直接出来。但恰恰是这种"不用说"的东西最应该说——它悄悄影响所有判断。

---

### 十六、好奇——认知的真正起点不是"看到"，也不是"想到"

**螺旋的真正起点是好奇。**

之前认为"看到→想到"的顺序是错的，修正为"想到在先"。但再往下推——最初的第一个"想到"是从哪来的？更早的"看到"吗？不。是**好奇**。

好奇不是一个看到，也不是一个想到。好奇是一个方向——想看清楚、想搞明白、想知道为什么。你走进一个空间，不是被动"看到"，也不是脑子里有明确的"想到"，是你有一个朝向。这个朝向让你既"看到"别人看不到的，也"想到"别人想不到的。

```
好奇（朝向）→ 想到（模糊的）→ 看到 → 更深想到 → 螺旋往上
```

**这也解释了内容为什么有活人感：** 它不是从"我应该做个什么内容"出发的，是从"我想搞明白这个事"出发的。好奇在前，内容在后。失去了好奇，内容就只剩技巧。

**对已有的修正：**
- 之前说"每个想到的源头是某个更早的看到"——这个判断不完整。真正的源头是好奇——它决定了你最初的方向，这个方向决定了你能看到什么、想到什么。
- 螺旋世界观（一）和认知螺旋在这一点上完全一致——螺旋的第一推动力不是"看到信息"，是"想知道"。

---

### 十七、圆盘卡槽——不完整是匹配的前提

**活人感（二）的深化。**

活人感的第一性原理：真实的人是不完整的。圆盘卡槽往前推了一步——不完整不是缺陷，是匹配的前提。圆盘能卡进卡槽，恰恰因为它有凹凸，不是完美圆形。完美圆形什么槽都能放，但哪个都卡不紧。

**检验找到了吗：** 做这件事的时候比大多数人更不费力。不是不努力，是不觉得"耗"。这个"还好"就是卡槽对上了的信号。

**如果卡槽还没被造出来：** 有些人的闪光点太独特，市场上没有现成的"位置"。不是"找卡槽"，是**造卡槽**。找是匹配，造是创造。创造没有参照物，不适是正常的。

**和AI使用原则（六）的呼应：** AI让"通用能力"贬值，让"独特闪光点"升值。AI时代的能力 = AI底层认识 × 自我认知。认清闪光点→更敢用AI→更从容。
