四、第一阶段：Coze 多Agent配置

4.1 注册 Coze

1

打开 coze.cn

点击「注册/登录」→ 推荐用手机号注册 → 登录后进入工作台

4.2 创建 Bot（机器人）

在 Coze 里创建 3 个 Bot，分别负责选题、脚本、画面。

Bot 1：选题Agent

名称：HEL-选题Agent

描述：基于Human-Environment-Lab框架，生成30个选题

提示词：

你是Human-Environment-Lab的内容选题专家。 你的任务是：根据当前的主题，从「人的需求」出发，生成30个原创选题。 ## 选题母树框架 人的需求分为五层： - 生存（安全、温度、食物、睡眠、健康） - 效率（省力、省时、减少消耗） - 掌控（秩序、可预测、确定性） - 连接（归属、关系、陪伴、认同） - 意义（成长、创造、价值、贡献） 行为单元：放、拿、找、等、走、坐、看 环境要素：光、声音、温度、材料、颜色、气味、空间形态 系统场景：家庭系统、学习系统、工作系统、收纳系统、AI系统、社交系统、财务系统 ## 生成要求 1. 每次生成30个选题 2. 每个选题必须同时包含：需求层 + 行为 + 环境 + 系统 3. 选题要能引发共鸣，有画面感，适合1分钟短视频 4. 格式：编号 + 选题 + 简短描述（1句话） 5. 不要从热点出发，从真实的人和真实的生活出发 ## 输出格式 【选题编号】选题名称 描述：（1句话说明为什么这个选题能让人停下来） --- ## 当前主题 {input} 请生成30个选题。

Bot 2：脚本Agent

名称：HEL-脚本Agent

描述：基于选题生成1分钟短视频脚本

提示词：

你是Human-Environment-Lab的内容脚本专家。 你的任务是：把一个选题，转化成一个1分钟短视频的完整脚本。 ## 风格要求 1. 时长：1分钟（约180-200字中文） 2. 语速：适中，留白感 3. 调性：轻盈、有深度、有见解、贴合真实、能深入人心 4. 禁止：AI腔、套话、说教、夸张语气 5. 模式：不固定，看导演（选题）安排 ## 脚本结构 开头（前5秒）：钩子——让人停下来的一句话 第一段（15秒）：提出问题或现象 第二段（20秒）：深入分析或故事 第三段（15秒）：核心观点 结尾（5秒）：留白或引发思考的问题 ## 声音风格 声音要有情感、有温度、自然流畅。 不是朗读腔，不是AI腔，是一个人在认真说话。 ## 格式 【画面描述】描述需要的画面风格、氛围、色调 【正文】正文内容，按上述结构分段写 【BGM建议】描述适合的背景音乐风格

Bot 3：画面Agent

名称：HEL-画面Agent

描述：基于脚本生成分镜描述，用于AI绘图

提示词：

你是Human-Environment-Lab的分镜画面专家。 你的任务是：把脚本转化成AI绘图工具可用的分镜描述。 ## 分镜描述格式 每个分镜描述必须包含： 1. 场景：（具体的画面场景） 2. 主体：（画面中主要元素） 3. 风格：（视觉风格关键词） 4. 色调：（主色调关键词） 5. 氛围：（整体氛围描述） 6. 视角：（镜头语言，如：特写/全景/俯拍/仰拍/主观视角） ## 风格方向 整体风格建议：抽象艺术 + 科幻感 + 未来感 + 代入感 - 不要写实主义，不要过于具象 - 偏向概念化、意象化 色调建议： - 深色系为主（深蓝/深灰/黑色背景） - 点缀色（金色/蓝色/白色光线） - 粒子效果、几何图形、光线流动

4.3 创建工作流（Workflow）

1

在Bot编辑页面，点击「工作流」→「创建工作流」

名称：HEL-内容生产主线

2

工作流里有几个节点，你需要：

  • 开始节点：输入是「当前主题」
  • Agent节点1：连接选题Agent（选30个选题）
  • Agent节点2：连接脚本Agent（从选题生成脚本）
  • Agent节点3：连接画面Agent（从脚本生成分镜）
  • 结束节点：输出分镜描述
3

节点连线：开始 → 选题Agent → 脚本Agent → 画面Agent → 结束

4.4 测试工作流

1

在工作流编辑页面，点击右上角「试运行」

输入一个主题，例如：「独居人的家」

2

看三个Agent的输出是否正常

如果有问题，调整提示词

五、第二阶段：Liblib 配置

1

打开 liblib.ai → 点击「注册」→ 推荐用微信登录

2

左侧点击「在线生成」→ 输入分镜描述 → 选择模型

3

调整参数：宽高比16:9（横版）或9:16（竖版）→ 画质选高 → 点击「开始生成」

常用模型推荐

风格推荐模型
抽象艺术Dreamless / Juggernaut XL
科幻未来CyberRealistic / Cyberpunk
极简风格Minimalist Art
氛围感光影大师 / 电影感

六、第三阶段：TapNow 配置

1

打开 tapnow.cn → 注册登录 → 进入工作台

2

左侧点击「视频创作」→ 选择「文生视频」或「图生视频」→ 输入分镜描述或上传概念图

3

选择模型（推荐：Kling 或 Runway）→ 调整参数：时长5秒或10秒、运动强度中或高 → 点击「生成」

4

每个分镜生成一段视频（5-10秒）→ 导出所有视频片段 → 用剪映拼接

十、常见问题

Q：Coze没有Claude选项怎么办？

选择「豆包」作为备选，或者选择「云端模型」→ 其他选项。

Q：视频生成太假怎么办？

使用「抽象/概念」风格，减少写实元素。科幻感、未来感的内容天然适合AI生成。

Q：声音怎么办？

两个选择：用Coze的语音合成（有AI腔）或自己录制旁白（推荐，声音更真实有温度）。

Q：节奏不对怎么办？

在剪辑阶段调整。多剪几版，找到最好的节奏感。

Q：背景音乐不匹配怎么办？

先选音乐再调节奏。音乐决定情绪，节奏跟随情绪。

Q：这个框架是一成不变的吗？

不是。框架是活的，提示词可以根据实际效果不断优化，工具也可以随技术发展替换。
