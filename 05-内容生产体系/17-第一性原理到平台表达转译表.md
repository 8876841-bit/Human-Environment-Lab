# 第一性原理到平台表达转译表

> 本文件用于固定 HEL 的核心转译链：  
> **底层逻辑 / 第一性原理 → 用户真实感受 → 平台表达 → 成品形式**。

它解决两个偏差：

```text
1. 只追平台热点，内容没有内核。
2. 只讲底层理论，用户听不懂、平台也不适配。
```

---

## 一、总链路

每条内容都必须走这条链：

```text
真实触发点
↓
第一性原理锚点
↓
用户真实感受
↓
平台表达
↓
内容形式
↓
成品执行包
```

---

## 二、每条内容必须填写的 5 个字段

```text
1. 触发点：一句真实感受 / 判断 / 现象
2. 第一性原理锚点：这件事背后的底层规律
3. 用户真实感受：用户心里实际怎么想
4. 平台表达：对外怎么说人话
5. 成品形式：图文 / 视频 / 一题多形
```

---

## 三、转译规则

### 规则 1：内部可以深，外部必须清楚

内部可以使用：

```text
底层逻辑
第一性原理
母线
系统规律
结构关系
```

外部必须转成：

```text
用户能马上理解的状态、问题、判断或行动。
```

---

### 规则 2：不能直接把内部术语端上平台

内部术语：

```text
认知秩序
系统框架
工具过载机制
熵增
边界化
可预测化
认知卸载
平台反噬
```

不能原样放到标题、封面、口播里。

---

### 规则 3：平台表达不能丢掉底层判断

不能为了平台停留，只剩：

```text
焦虑
标题党
工具堆叠
反差钩子
情绪宣泄
```

平台表达必须还能追溯回内部锚点。

---

## 四、常用转译表

| 第一性原理 / 内部判断 | 用户真实感受 | 平台表达 |
|---|---|---|
| 工具过载会破坏普通人的判断顺序 | AI 工具越多，我越不知道先学哪个 | 你不是不会用 AI，是顺序错了 |
| 入口过多会让行动成本变高 | 我收藏了很多教程，但没有真正开始 | 别先收藏 100 个教程，先判断你要解决什么 |
| 没有任务边界，工具就会反过来牵着人走 | 每个工具看起来都重要 | 先看你卡在内容、代码，还是流程 |
| 空间缺少归位系统，物品会自然堆积 | 家里总是越住越乱 | 家里乱，不一定是人懒，可能是没有顺手归位的位置 |
| 材料会影响人的感受和行为 | 有些空间一进去就让人压抑 | 材料不只是好不好看，也会影响你待在里面的感受 |
| 工艺本质是在提前处理风险 | 很多装修问题入住后才暴露 | 工艺不是细节控，是在提前挡住入住后的麻烦 |
| 家的布局暴露家庭运行方式 | 一个家为什么越住越累 | 布局不是摆家具，它会影响一家人每天怎么动 |
| 商业服务的价值来自判断和责任边界 | 客户不是找不到工厂，是不知道怎么判断 | 客户缺的不是工厂，是一套判断系统 |
| 真实生活不能被效率完全吞掉 | AI 越强，我越不想做时代牛马 | AI 不是让人一直加速，而是帮人把生活重新拿回来 |
| 平台信息流会放大焦虑 | 看得越多，越觉得自己落后 | 你以为你在学习，其实可能只是被信息流推着跑 |

## 五、转译模板

### 模板 1：AI / 工具类内容

```text
触发点：我看到很多 AI 工具，但越看越乱。
第一性原理锚点：入口过多会破坏行动顺序。
用户真实感受：我怕落后，但不知道先学哪个。
平台表达：AI 工具越多，为什么你反而越不知道怎么开始？
成品形式：视频抓焦虑，图文做收藏卡。
```

---

### 模板 2：空间 / 家装类内容

```text
触发点：家里东西总是堆在餐桌上。
第一性原理锚点：物品没有低成本归位路径，就会流向最近的平面。
用户真实感受：我不是不想收拾，是总觉得顺手一放就乱了。
平台表达：餐桌总是乱，不一定是你懒，可能是家里少了一个顺手放东西的位置。
成品形式：图文场景拆解 / 实景标注视频。
```

---

### 模板 3：工艺 / 材料类内容

```text
触发点：一个小工艺为什么这么麻烦？
第一性原理锚点：工艺是在入住前提前处理未来风险。
用户真实感受：我看不懂为什么要多花这一步。
平台表达：这个细节不是设计师矫情，是为了避免你入住后反复出问题。
成品形式：实景对比标注 / 混合增强视频。
```

---

### 模板 4：商业服务类内容

```text
触发点：客户总想找源头工厂，但还是容易踩坑。
第一性原理锚点：复杂行业中，真正稀缺的是判断系统和责任边界。
用户真实感受：我不是找不到人做，是不知道谁靠谱、谁负责。
平台表达：你缺的不是工厂，而是知道谁该为哪一步负责。
成品形式：图文判断表 / 口播解释视频。
```

## 六、平台转译示例：同一个底层锚点

第一性原理锚点：

```text
工具过载会破坏普通人的判断顺序。
```

### 抖音 / 快手表达

```text
AI 工具越多，你是不是反而越乱？
不是你不会用，是顺序错了。
```

### 小红书表达

```text
选 AI 工具前，先问自己 3 个问题：
内容？代码？流程？
```

### 视频号表达

```text
普通人学 AI，先别急着追工具。
很多时候，先判断要解决什么，比马上开始学哪个工具更重要。
```

### B站表达

```text
为什么 AI 工具越多，普通人越难开始？
这背后不是工具问题，而是判断顺序被打乱了。
```

## 七、禁止转译方式

禁止这样转：

```text
第一性原理锚点：工具过载会破坏普通人的判断顺序。
错误表达：AI 时代，认知秩序的重建决定个体效率跃迁。
```

问题：

```text
术语太重。
不像平台语言。
用户不知道跟自己有什么关系。
```

也禁止这样转：

```text
第一性原理锚点：工具过载会破坏普通人的判断顺序。
错误表达：不学这个工具，你一定会被淘汰。
```

问题：

```text
偏离底层判断。
制造焦虑。
平台风险高。
```

## 八、转译检查表

每条内容生成前检查：

```text
1. 有没有第一性原理锚点？
2. 用户真实感受是否具体？
3. 平台表达是否像人话？
4. 是否避免术语外露？
5. 是否避免纯标题党？
6. 是否能追溯回底层判断？
7. 是否符合平台规则和调性？
```

---

## 九、一句话标准

```text
HEL 的内容不是把底层理论讲给用户听，而是把底层判断翻译成用户当下真正需要的一句话、一个方法、一个画面。
```
