# TP-001｜B2 方法卡图文 V3

> 主题：AI 工具越多，反而不知道怎么开始
>
> 形式：真实 + AI 增强型图文
>
> 平台优先：小红书
>
> 当前目标：做一组有收藏价值、能引导评论、能反向校准视频表达的图文卡片。

---

## 0. 核心判断

这组图文不是为了单纯讲清楚“AI 工具怎么分类”。

它真正要做的是：

```text
让用户先进入困惑，
然后马上拿到一张能用的判断卡，
再知道不同任务该找哪类工具，
最后能写出自己的 AI 任务句子。
```

底层逻辑：

```text
第 1 页：让人进入
第 2 页：必须出干货
第 3 页：继续给工具方向
第 4 页：给可套用模板
第 5 页：引导评论与下一轮真实触发点
```

---

## 1. 用户动作设计

### 1.1 主互动目标

```text
第一目标：收藏
第二目标：评论
第三目标：转发
点赞顺带发生
```

### 1.2 收藏动机

用户收藏不是因为“看懂了”，而是因为：

```text
这张东西以后还能用。
下次选 AI 工具前可以拿出来对照。
它能降低我未来的试错成本。
```

因此，本组图文必须包含真正可复用的干货页：

```text
P2：AI 任务判断卡
P3：工具类型匹配表
P4：一句话任务模板
```

### 1.3 评论动机

评论不是靠“欢迎评论”产生的，而是靠“留下一个空位”产生的。

本组评论入口：

```text
评论区写一句：
我想让 AI 帮我 ______。
```

后续可把评论区变成下一批真实触发点来源。

### 1.4 转发动机

转发不是因为内容完整，而是因为用户想到一个具体对象。

转发钩子：

```text
发给那个还在乱学 AI 工具的人。
```

## 2. 页面结构最终版

### P1｜进入页

#### 页面任务

```text
让用户停住，并产生代入：
“我确实越学越乱。”
```

#### 用户动作

```text
停留 / 点赞 / 继续翻页
```

#### 主文案

```text
AI工具越学越乱？
你不是笨，是入口错了。
```

#### 辅助文案

```text
很多人一开始就问：
哪个 AI 工具最好用？

但真正该先问的，不是工具，而是任务。
```

#### 视觉方向

```text
以主理人本人形象为主。
画面真实、亲和、自然。
可以出现工具卡片、收藏夹、教程窗口、便签，但不能过度杂乱。
情绪是“被工具信息压住，但还愿意继续弄明白”。
```

#### 视觉禁忌

```text
不要黑色科技风
不要泛AI模板感
不要满屏Logo
不要人物表情太冷
不要发型乱糟糟
```

---

### P2｜核心干货页：AI 任务判断卡

#### 页面任务

```text
第二页必须直接出干货。
让用户觉得：这页值得收藏。
```

#### 用户动作

```text
收藏
```

#### 主文案

```text
AI任务判断卡
先分清：你现在属于哪一类？
```

#### 内容结构

```text
1. 写东西
文案 / 脚本 / 总结 / 标题 / 方案
关键词：生成文字 / 改写 / 提炼
常见场景：写小红书笔记、写脚本口播、总结长文、写方案、写邮件报告
可先试：ChatGPT / Claude / Kimi / Notion AI

2. 做东西
图片 / 视频 / 表格 / 页面 / PPT
关键词：生成成品 / 出画面 / 出文件
常见场景：做封面图、做配图海报、剪视频、做PPT、做页面演示、做表格可视化
可先试：Midjourney / 即梦 / Canva / 剪映 / Gamma

3. 重复干活
整理 / 改写 / 归档 / 批量处理 / 固定流程
关键词：重复 / 批量 / 自动化
常见场景：批量改写、翻译润色、整理资料、归档文件、自动回复、固定流程自动执行
可先试：Dify / Coze / n8n / Zapier
```

#### 底部收藏钩子

```text
以后每次选 AI 工具前，先看这一页。
```

#### 视觉方向

```text
一页内放三栏判断卡。
人物可以在旁边作为主理人讲解锚点，但不要压缩信息空间。
三栏必须比人物更清楚。
工具名称放进对应框里，不要只放概念。
```

#### 视觉重点

```text
这一页不是为了漂亮，而是为了让人收藏。
```

---

### P3｜工具类型匹配页

#### 页面任务

```text
让用户进一步明确：不是哪个工具最厉害，而是哪个工具匹配当前任务。
```

#### 用户动作

```text
收藏 / 转发给正在乱选工具的人
```

#### 主文案

```text
任务分清后，再找对应工具
```

#### 内容结构

```text
如果你要写东西：
优先找 对话模型 / 写作助手 / 文档工具
可试：ChatGPT / Claude / Kimi / Notion AI

如果你要做图片：
优先找 图像生成 / 修图 / 设计工具
可试：Midjourney / 即梦 / Canva

如果你要做视频：
优先找 视频生成 / 剪辑 / 分镜工具
可试：剪映 / 即梦 / 可灵 / Runway

如果你要做PPT或页面：
优先找 演示生成 / 页面生成 / 设计排版工具
可试：Gamma / Canva / Notion AI

如果你要做流程：
优先找 工作流 / Agent / 自动化工具
可试：Dify / Coze / n8n / Zapier

如果你要批量处理：
优先找 自动化 / 批处理 / 脚本工具
可试：n8n / Dify / Python / Zapier
```

#### 底部句

```text
工具没有最好，只有最合适。
```

#### 视觉方向

```text
做成“任务 → 工具类型 → 可试工具”的对照表。
信息要比 P2 更具体。
不要再只放三类大概念。
```

### P4｜一句话任务模板

#### 页面任务

```text
让用户马上能把自己的需求说清楚。
```

#### 用户动作

```text
收藏 / 截图 / 套用
```

#### 主文案

```text
把任务说清楚，用这个模板
```

#### 模板

```text
我想让 AI 帮我：
把【什么内容】
变成【什么结果】
用于【什么场景】
要求【什么格式/风格】
```

#### 示例 1

```text
我想让 AI 帮我：
把一段口播素材
变成一条小红书图文脚本
用于 AI 学习账号
要求清楚、真实、适合收藏。
```

#### 示例 2

```text
我想让 AI 帮我：
把客户提出的问题
整理成一张判断表
用于木作咨询前沟通
要求简单、可执行、能看出责任边界。
```

#### 视觉方向

```text
做成便签 / 输入框 / 表单式页面。
这页要像一个可以直接复制的模板。
人物可以作为辅助，不要抢模板。
```

### P5｜行动页

#### 页面任务

```text
引导用户把自己的真实需求写出来，形成评论区触发点。
```

#### 用户动作

```text
评论 / 转发 / 关注后续拆解
```

#### 主文案

```text
今天只写一句话：
我想让 AI 帮我 ______。
```

#### 评论钩子

```text
评论区写下这句话，
我可以帮你判断：
它属于写东西、做东西，还是重复干活。
```

#### 转发钩子

```text
也可以发给那个还在乱学 AI 工具的人。
```

#### 视觉方向

```text
中心是一张空白便签或输入框。
工具卡片退到远处。
情绪从“乱”转为“可以开始”。
人物表情更亲和，可以轻微微笑。
```

## 3. 统一视觉母版

### 3.1 人物形象

```text
人物以用户本人形象为主。
气质：真实、亲和、自然、有判断力。
不要过度完美，不要网红棚拍感太重。
```

### 3.2 服装造型方向

可使用多套造型，不要每次同一套：

```text
1. 中性黑色西装 / 白衬衫 / 黑裤
2. 宽松飞行夹克 / 白T / 工装裤 / 球鞋
3. 街舞感运动套装 / 黑白灰为主
4. 黑色西装 + 浅色内搭，带一点女性柔和感
5. 温柔裙装 / 旗袍风 / 新中式，只作为阶段性视觉变化，不作为主视觉
```

### 3.3 当前偏好记录

```text
喜欢中性、街舞感、韩国女团里偏中性表达的妆造方向。
可以有亲和力，但不要太甜。
可以时尚，但不要过度摆拍。
发型要干净，不要乱糟糟。
```

### 3.4 图文画面气质

```text
真实桌面感
轻微随意感
信息层级清楚
有干货
有主理人锚点
不做冰冷AI模板
```

## 4. 当前判断

V3 不再采用“5页都慢慢解释”的结构。

最终结构为：

```text
P1：进入
P2：干货判断卡
P3：工具匹配表
P4：一句话任务模板
P5：评论与转发行动
```

其中：

```text
P1 负责让人进入
P2 必须马上给干货
P3 让用户对工具有方向
P4 让用户能立刻套用
P5 负责评论与下一轮内容触发点
```
