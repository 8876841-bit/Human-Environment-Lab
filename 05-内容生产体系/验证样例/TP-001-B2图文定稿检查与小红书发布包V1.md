## 0. 当前确认结论

这组图不是单张好看图，而是一组连续阅读路径。

已经确认的核心规则：

```text
1. 同一组图必须同一套妆造。
2. 只改单张时，也必须继承原系列人物、服装、发型、气质。
3. 人物姿态要和页面信息融在一起，不能像硬贴上去。
4. 第1张负责让人进入。
5. 第2张必须直接给干货。
6. 第3张不能重复第2张，要负责“任务 → 工具匹配”。
7. 第4张给任务表达模板。
8. 第5张负责评论和行动。
```

## 1. 最终页面路径

```text
P1：进入页
用户问题：为什么我越学 AI 越乱？
页面任务：让用户停住，产生代入。

P2：任务判断页
用户问题：我现在到底属于哪类任务？
页面任务：直接给干货，形成收藏动机。

P3：工具匹配页
用户问题：任务分清后，我该找哪类工具？
页面任务：让工具选择变得有方向。

P4：任务模板页
用户问题：我怎么把需求说清楚？
页面任务：给一个可套用表达模板。

P5：行动评论页
用户问题：我现在该做什么？
页面任务：让用户写出自己的任务句子，形成评论区触发点。
```

## 2. 视觉定稿检查

### 2.1 系列一致性

检查项：

```text
[ ] 人物是否是同一个主理人形象
[ ] 服装是否保持同一套妆造
[ ] 发型是否一致且干净
[ ] 表情是否自然亲和
[ ] 人物是否没有忽然变成另一种气质
[ ] 页面编号是否连续
[ ] 色彩是否统一：米白 / 暖白 / 深绿 / 棕色
[ ] 字体气质是否统一
[ ] 卡片边框、贴纸、便签风格是否统一
```

### 2.2 信息层级

检查项：

```text
[ ] 每页是否只有一个最大主句
[ ] 主句是否一眼能看懂
[ ] 副句是否没有抢主句
[ ] 人物是否辅助理解，而不是抢信息
[ ] P2 是否确实有收藏价值
[ ] P3 是否和 P2 不重复
[ ] P4 是否能直接套用
[ ] P5 是否有明确评论动作
```

### 2.3 用户动作

```text
P1：停留 / 翻页
P2：收藏
P3：收藏 / 理解工具方向
P4：收藏 / 套用
P5：评论 / 转发
```

## 5. 小红书正文 V1

```text
很多人学 AI，第一步就开始找工具。

哪个工具最好用？
哪个模型最强？
哪个软件最适合普通人？

但我最近越来越觉得，普通人真正卡住的地方，不是工具不够多，而是任务没分清。

你到底是想让 AI 帮你写东西？
还是帮你做东西？
还是帮你处理一堆重复的事情？

这三类任务，对应的工具和用法完全不一样。

所以我把它整理成了一组任务判断卡。
以后每次想学一个新工具前，先看一下自己现在到底属于哪类任务。

先判断任务，再选择工具，真的能少走很多弯路。

你也可以在评论区写一句：
我想让 AI 帮我 ______。

我可以帮你判断，它属于写东西、做东西，还是重复干活。
```
