# TP-001｜项目视觉母版 V1

> 项目：AI 工具越多，反而不知道怎么开始  
> 所属母线：AI 认知秩序  
> 文件性质：项目级视觉母版 / 关键帧生成前硬闸门  
> 使用边界：本文件必须在 KF01 / KF02 / KF03 关键帧生成前通过检查。  
> 核心原则：**同一条视频必须像同一个世界里连续发生的事，而不是几张单独好看的图。**

---

## 一、项目基础信息

### 1. 平台

```text
小红书视频笔记
```

### 2. 画幅

```text
9:16 竖屏
```

### 3. 目标时长

```text
45-55 秒
```

### 4. 内容任务

```text
让用户从“AI 工具太多，不知道先学哪个”的混乱感，
转向“先判断自己想让 AI 完成什么”的清晰行动入口。
```

### 5. 核心表达

```text
你不是不会用 AI。
是你还没想清楚：
你到底想让 AI 帮你写东西、做东西，还是重复干活。
```

```text
AI 认知秩序
```

## 三、项目视觉母版锁定

## 1. 人物模板

### 人物设定

```text
同一个年轻人
20-30 岁年龄感
普通学习者 / 内容创作者 / 转型中的普通人
灰色卫衣
背影 / 半背影为主
不正脸强表演
不夸张崩溃
```

### 人物固定规则

```text
KF01 / KF02 / KF03 必须是同一个人物设定。
不允许突然换成女性插画角色。
不允许突然换成商务职场人。
不允许突然换成科技大片人物。
```

### 人物状态变化

允许变化的是状态，不是人物：

```text
KF01：困惑，手抓头，面对大量弹窗。
KF02：停顿，视线集中，混乱开始被冻结。
KF03：姿态更稳定，开始面对清晰卡片。
```

---

## 2. 空间模板

### 空间设定

```text
同一个家庭办公桌 / 学习桌
温暖浅色室内
电脑屏幕前
桌面略乱但可读
有笔记本、便签、书、本子、咖啡杯等学习痕迹
```

### 空间固定规则

```text
三张关键帧必须发生在同一个空间。
不允许 KF02 突然变成手绘白板。
不允许 KF03 突然变成纯表格页面。
不允许突然换到办公室、城市、科幻空间。
```

### 空间变化规则

允许变化的是画面秩序：

```text
KF01：空间略乱，弹窗多。
KF02：混乱被冻结，左右开始分区。
KF03：桌面和 UI 明显变清楚。
```

---

## 3. 画面语言模板

### 主画面语言

```text
真实摄影感 + 少量清晰 UI 浮层
```

### 不采用

```text
手绘插画
黑色电影感
PPT 讲解页
纯信息图
3D 卡通
科技发布会风
```

### 硬规则

```text
本项目不使用“双世界结构”。
所以不允许现实摄影和手绘插画混用。
所有关键帧必须像同一个视频连续镜头。
```

---

## 4. 色彩模板

### 主色

```text
米白
浅灰
暖白
```

### 文字色

```text
深灰
深墨绿
```

### 强调色

```text
墨绿
少量淡黄色高亮
少量红点用于通知数字
```

### 禁止色彩倾向

```text
大面积黑色
霓虹蓝紫
赛博朋克色
高饱和红蓝撞色
过度暗调
```

---

## 5. 字幕与文字模板

### 文字原则

```text
大字少字
每屏一个核心句
用户一秒能看懂
```

### 标题样式

```text
深墨绿色大标题
少量黄色手绘高亮线
不使用复杂装饰字体
```

### 每屏文字量

```text
主标题：不超过 12 个字
辅助小字：不超过 2 行
UI 卡片：每张不超过 2 行
```

### 禁止

```text
满屏小字
侧边栏说明
复杂表格堆满画面
专业术语直接外显
内容 / 代码 / 工作流 作为第一层表达
```

---

## 6. UI / 卡片系统模板

### UI 卡片样式

```text
白色圆角卡片
轻阴影
浅灰边框
简洁图标
少量红色通知角标
文字大而清楚
```

### 卡片类型

```text
工具卡片：ChatGPT / Claude / Dify / n8n / Codex / Canva 等
状态卡片：收藏夹 / 待学教程 / 学习提醒
任务卡片：写东西 / 做东西 / 重复干活
路径卡片：想做什么 → 判断任务 → 选择工具 → 产出结果
```

### 真实 Logo 使用规则

```text
可以少量出现工具名。
不强依赖真实 Logo。
工具名不能抢走主线。
工具只是背景压力，任务判断才是主角。
```

### 禁止

```text
堆满真实 Logo
工具卡片过多导致看不清
卡片风格每张都变
UI 变成复杂仪表盘
```

## 四、KF01 / KF02 / KF03 连续性设计

## KF01｜混乱入口

### 镜头任务

```text
让用户 1 秒看懂：AI 工具太多，我不知道先学哪个。
```

### 画面

```text
同一个灰色卫衣年轻人坐在电脑前

屏幕上弹出大量 AI 工具、教程、收藏、提醒卡片
桌面有便签和学习笔记
整体略乱但不脏乱
```

### 主字

```text
AI 工具越多，越乱？
```

### 情绪

```text
轻焦虑
共鸣
信息过载
```

---

## KF02｜认知反转

### 镜头任务

```text
让用户明白：不是我笨，也不是工具不够，是任务没分清。
```

### 画面

```text
仍然是同一个人物、同一个桌面、同一个电脑前场景。
左侧保留部分混乱工具卡片。
中间出现清晰停顿区。
右侧开始出现三张任务卡的雏形。
```

### 主字

```text
不是你不会
是任务没分清
```

### 关键变化

```text
工具卡片从漂浮混乱变成被冻结。
画面从“散”开始向“分区”过渡。
右侧隐约出现：写东西 / 做东西 / 重复干活。
```

### 禁止

```text
不换人物
不换空间
不变成手绘插画
不变成白板讲解页
不变成纯信息图
```

---

## KF03｜清晰选择

### 镜头任务

```text
让用户马上知道自己可以从哪类任务开始。
```

### 画面

```text
同一个电脑前场景。
混乱工具卡片退到背景。
前景出现三张清晰任务卡。
人物姿态更稳定，像看到了判断入口。
```

### 三张卡片

```text
写东西：标题 / 文案 / 脚本
做东西：网页 / 表格 / 图片
重复干活：整理 / 分类 / 提醒
```

### 主字

```text
先判断任务
再选择工具
```

### 情绪

```text
清楚
稳定
可执行
```

## 六、关键帧生成前硬检查

生成任何关键帧前必须确认：

```text
1. 是否仍属于 AI 认知秩序母线？
2. 是否继承浅色桌面 + UI 浮层 + 决策卡片系统？
3. 是否是同一个灰色卫衣年轻人？
4. 是否是同一个家庭办公桌？
5. 是否保持真实摄影感？
6. 是否没有突然变成插画 / PPT / 黑色科技风？
7. 是否仍围绕写东西 / 做东西 / 重复干活？
8. 是否能接上前一个镜头？
9. 是否能推进到下一个镜头？
10. 是否服务“任务没分清”这个核心判断？
```

任意一项不通过：

```text
判废，不进入下一步。
```
