# TP-001 执行样品：AI 工具越多，反而不知道怎么开始

> 本文件用于验证 HEL 的“触发点 → 形式判断 → 成品结构 → 执行清单”流程。  
> 当前状态：**TP-001 图文样式 V1 已确认，视频脚本 V1 已确认，进入视频素材测试阶段。**

---

## 一、触发点

```text
AI 工具越多，我反而越不知道怎么开始。
```

这不是一个“工具科普”选题，而是一个真实焦虑入口。

用户表面上在问：

```text
我到底该学哪个 AI 工具？
```

实际上在卡：

```text
我没有判断顺序，所以每个工具看起来都重要。
```

---

## 二、前置校验规则

每条内容进入脚本前，必须先过四个问题。

### 1. 平台规则 / 平台调性

先判断发哪里，再决定时长、开头强度、信息密度和标题方式。

| 平台 | 推荐版本 | 主要任务 |
|---|---|---|
| 抖音 / 快手 | 15-30 秒短冲击版 | 抓焦虑、打痛点、促评论 |
| 小红书 / 视频号 | 40-90 秒解释收藏版 | 讲清楚、给方法、引导收藏 |
| B站 | 3-8 分钟深度拆解版 | 讲透逻辑、建立信任、做系列 |

### 2. 谁在看

不是“所有学 AI 的人”。

更准确是：

```text
已经被 AI 工具搞焦虑、怕落后、想开始但不知道先学哪个的人。
```

他们的状态：

```text
怕自己落后
觉得工具太多
每个都想学
不知道先学哪个
收藏很多教程，但真正用起来的不多
```

### 3. 我们要表达什么

不是：

```text
介绍 AI 工具大全。
```

而是：

```text
你不是不会用 AI，是还没先想清楚：你现在到底要解决内容、代码，还是流程。
```

### 4. 怎么转译成适合平台的表达

不能把底层逻辑直接端到表面上。

禁止这样说：

```text
AI 工具选择涉及认知秩序重建和系统框架搭建。
```

要转译成：

```text
你是不是越学 AI 越乱？
今天看到 Codex，明天看到 Dify，后天又想学 n8n。
不是你不会用，是你还没先想清楚：你现在到底要解决内容、代码，还是流程。
```

## 四、一个触发点的形式规则

本样品确认一条重要规则：

```text
一个触发点 ≠ 必须同时做图文和视频。
```

正确流程是：

```text
触发点
↓
判断主形式
↓
确定它主要完成什么作用
↓
再判断是否值得做衍生形式
```

判断标准：

```text
只需要抓情绪 → 优先视频
只需要收藏复用 → 优先图文
既有传播价值，又有收藏价值 → 一题多形
```

TP-001 属于：

```text
传播价值：强
收藏价值：强
```

所以采用：

```text
主形式：短视频
衍生形式：图文收藏卡
```

### 2. 视觉方向

确认方向：

```text

```

不采用：

```text

```

视觉关键词：

```text

深灰字
墨绿色或橄榄绿强调
少量淡黄色高亮
表格清楚
图标统一
人物弱化
信息优先
```

### 3. 五页结构

#### P1 封面

```text
AI 工具越学越乱？
你不是不会用，是顺序错了
```

小字：

```text
先判断任务，再选工具
```

#### P2 痛点共鸣页

```text
你可能不是学不会。
你是同时被太多入口拉住了。
```

内容：

```text
今天想学 Codex
明天想搭 Dify
后天又开始研究 n8n
最后每个都收藏了，但真正用起来的不多
```

#### P3 判断三问页

```text
选工具前，先问自己 3 个问题
```

内容：

```text
1. 我现在要解决的是内容、代码，还是流程？
2. 这件事是一次性的，还是要长期复用？
3. 我缺的是工具，还是步骤？
```

#### P4 工具用途表

```text
我要做什么 → 可以先用什么 → 能产出什么
```

| 我要做什么 | 可以先用什么 | 能产出什么 |
|---|---|---|
| 写内容 | ChatGPT / Claude | 选题、脚本、标题、文案 |
| 改代码 | Codex / Claude Code | 改文件、读仓库、修 bug |
| 搭流程 | Dify / n8n / Coze | 工作流、自动化、机器人 |
| 做画面 | Canva / 即梦 / 可灵 | 封面、图文、视频素材 |

#### P5 最小行动卡

```text
今天先做这一步就够了
```

内容：

```text
别先收藏 100 个教程。
先写一句话：
我现在最想让 AI 帮我完成什么？

再判断它属于：内容 / 代码 / 流程。
```

收束句：

```text
先判断，再选工具。
```

## 九、字幕 / BGM / 平台注意

### 字幕风格

```text
字体清楚，偏现代，不花哨。
深灰为主，墨绿色强调，少量淡黄色做重点。
每屏最多出现 1 个核心句。
不要满屏堆字。
```

### BGM 节奏

```text
0-10 秒：轻微紧张，节奏快。
10-17 秒：突然停顿，制造反转。
17 秒后：节奏变稳定，像问题被理清。
结尾：干净、落地，不煽情。
```

### 平台注意

```text
不要说“学会这个就能逆袭/赚钱/超过别人”。
不要堆太多真实工具 Logo，可以用文字卡片代替工具图标。
不要把画面做得太焦虑、太压迫。
不要把底层术语直接讲出来。
要从混乱逐渐转为清晰。
```
