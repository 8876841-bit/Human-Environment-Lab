# TP-001｜C1 纯智能体生成视频｜视频运动提示词与生成方式 V1

> 项目：TP-001
>
> 主题：AI 工具越多，反而不知道怎么开始
>
> 形式：C1 纯智能体生成视频
>
> 当前阶段：关键帧已进入测试，下一步为分段图生视频 / 首尾帧视频。

---

## 0. 核心原则

这条视频不能直接把所有关键帧丢给 AI 一次性生成完整视频。

正确流程：

```text
关键帧
↓
分镜头生成短视频片段
↓
剪辑软件拼接
↓
加旁白、字幕、音乐、转场
↓
成片
```

原因：

```text
1. 保护人物一致性
2. 保护妆造一致性
3. 控制节奏
4. 控制信息递进
5. 避免工具图标乱飞、变形、失真
6. 避免视频一次性生成导致叙事失控
```

```text
KF02：单图生视频
```

其中：


---

## 2. 角色与场景硬规则

```text
主角：以用户本人为原型
风格：真实桌面感 + 轻漫画 + 暖色纸质卡片感
妆造：同一条视频中保持同一套妆造
发型：干净，不凌乱
服装：深色宽松外套 / 白色内搭 / 中性休闲风
场景：家庭办公桌 / 电脑 / 便签 / 笔记本 / 咖啡杯 / 工具卡片
禁忌：赛博风、黑色科技风、企业宣传片感、人物每帧变脸
```

## 3. 分镜运动提示词

## KF01｜被工具淹没

### 生成方式

```text
单张关键帧 → 图生视频
时长：3-4 秒
```

### 视频运动提示词

```text
保持同一人物、同一发型、同一服装、同一桌面场景。镜头缓慢向人物推进。周围的 AI 工具卡片从四周轻轻漂浮靠近人物和电脑屏幕，形成信息包围感，但不要遮挡人物脸部。人物坐在桌前，眼神在工具卡片和电脑之间轻微移动，表情困惑但克制。整体光线温暖，画面有真实桌面感和轻漫画卡片感。不要改变人物身份，不要改变服装，不要让工具卡片变形。
```

### 负面约束

```text
不要赛博朋克，不要强烈霓虹，不要人物变脸，不要换衣服，不要夸张惊恐表情，不要工具卡片遮住脸，不要镜头剧烈晃动。
```

### 对应字幕

```text
AI工具越学越乱？
```

## KF02｜收藏很多，开始空白

### 生成方式

```text
单张关键帧 → 图生视频
时长：4 秒
```

### 视频运动提示词

```text
保持同一人物和同一妆造。镜头稳定，轻微横向移动，从左侧堆满的收藏夹、教程截图、工具清单，慢慢移到右侧空白文档。人物坐在中间，手撑脸或轻靠桌面，看着空白页面，表情是真实卡住感。左侧信息可以轻微叠加浮动，右侧空白文档保持安静，形成对比。画面温暖、真实、清晰，不要让场景突然变化。
```

### 负面约束

```text
不要人物换脸，不要换发型，不要变成职场会议室，不要让空白文档自动写满，不要工具卡片继续乱飞，不要画面过度拥挤。
```

### 对应字幕

```text
收藏夹很满
真正开始时还是空白
```

## KF03｜认知反转

### 生成方式

```text
单张关键帧 → 图生视频
时长：4 秒
```

### 视频运动提示词

```text

```

### 负面约束

```text

```

### 对应字幕

```text

单张关键帧 → 图生视频
```


## KF05｜工具归位

### 生成方式

```text
首尾帧视频
时长：6-8 秒
```

### 首帧要求

```text
工具卡片仍然有些分散，三张任务卡已经出现：写东西、做东西、重复干活。人物看向画面中央，准备整理。
```

### 尾帧要求

```text
工具卡片已经归类完成：
写东西 → ChatGPT / Claude / Kimi / Notion AI
做东西 → Midjourney / Canva / 剪映 / 即梦 / Gamma
重复干活 → Dify / Coze / n8n / Zapier
画面变得整齐清楚。
```

### 视频运动提示词

```text
保持同一人物、同一发型、同一服装、同一桌面场景。从首帧到尾帧，原本分散的 AI 工具卡片自动移动、排队、归类到对应任务卡下面。运动要清晰、有秩序，像整理桌面卡片一样。人物可以轻微伸手整理卡片，表情从困惑变清楚。画面从乱到整齐，强调“任务分清后，工具才有方向”。不要让人物变脸，不要让卡片内容变形。
```

### 负面约束

```text
不要卡片乱飞出画面，不要工具图标变形，不要新增无关工具，不要文字乱码，不要人物换衣服，不要场景突然变成科技空间。
```

### 对应字幕

```text
任务分清后
工具才有方向
```

## 6. 成片验收表

```text
[ ] 人物是否从头到尾像同一个人
[ ] 妆造是否统一
[ ] 场景是否统一
[ ] 是否能看出从混乱到清晰
[ ] KF03 是否有认知反转
[ ] KF04 三类任务是否清楚
[ ] KF05 工具是否真的归位
[ ] KF06 是否有明确行动
[ ] 旁白和画面是否对应
[ ] 字幕是否不挡人物和关键信息
```

---

## 7. 推荐执行顺序

```text
1. 先用 KF01 做 3 秒图生视频测试
2. 检查人物是否稳定
3. 再做 KF02
4. 检查人物、服装、场景是否延续
5. 通过后再做 KF03-KF04
6. 最后单独做 KF05 首尾帧工具归位
7. 做 KF06 行动结尾
8. 剪映中合成旁白、字幕、音乐
```

---

## 8. 本阶段结论

```text
这条 C1 视频不追求一次性自动生成完整成片。
它追求：分段稳定生成，再系统合成。

稳定优先于炫技。
清晰优先于复杂。
人物一致优先于画面新鲜感。
```
