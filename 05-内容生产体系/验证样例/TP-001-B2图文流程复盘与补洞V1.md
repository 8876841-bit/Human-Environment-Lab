>

---

## 0. 复盘结论

TP-001 B2 图文最终成品方向是可用的。

已经做对的地方：

```text
1. 明确了不是单张图，而是一组连续阅读路径。
2. 明确了 P1-P5 的页面任务。
3. 修正了 P2 和 P3 重复的问题。
4. 识别出同一组图必须同一套妆造。
5. 识别出只改单张也必须继承原系列人物系统。
6. 形成了发布包：标题、正文、首评、标签、发布前检查。
```

但之前的流程仍然有缺漏。它最后能跑通，主要依赖用户不断指出问题，而不是一开始就有完整闸门。

核心问题：

```text
之前是“边生成边发现问题”。
正确流程应该是“先列闸门，再生成”。
```

## 1. 按可信流程反查

## 1.1 任务定义

### 已完成

当前文档已经明确：

```text
主题：AI 工具越多，反而不知道怎么开始
形式：小红书图文｜方法卡 / 收藏卡
当前状态：图文系列结构与视觉方向已基本确认，进入发布包准备
```

### 缺漏

任务定义还可以更明确：

```text
这组图的第一目标：收藏
第二目标：评论
第三目标：转发
点赞只是顺带结果
```

虽然前面对话中已经确认过，但发布包文件里没有把这个作为最高级目标单独写在前面。

### 修正建议

在发布包开头补一段：

```text
本组图第一目标不是点赞，而是收藏。
收藏来自 P2 判断卡、P3 工具匹配、P4 任务模板。
评论来自 P5 的“我想让 AI 帮我____”。
转发来自“发给还在乱学 AI 工具的人”。
```

---

## 1.2 专业领域对标

### 已完成

实际执行中已经涉及：

```text
小红书图文阅读路径
方法卡 / 收藏卡设计
人物视觉一致性
发布包设计
```

### 缺漏

文档里还没有明确写：

```text
这不是普通海报设计。
它属于：信息设计 + 平台图文阅读路径 + 收藏转化型内容。
```

如果没有这句话，后续复用时容易又回到“做一组好看的图”。

### 修正建议

增加“专业对标”段：

```text
TP-001 B2 的专业参照不是广告海报，而是收藏型信息卡。
判断标准不是画面多精致，而是：
用户是否一眼懂、是否愿意保存、是否知道下一步该评论什么。
```

## 1.3 风险地图

### 已完成

后期我们实际识别了这些风险：

```text
P2 和 P3 重复
人物妆造不统一
人物姿态像硬贴上去
第2页不够干货
第5页评论动作不够明确
```

### 缺漏

这些风险不是一开始就列出来的，是做着做着才发现。

还遗漏了几个图文专用风险：

```text
1. 字太多导致手机端读不清
2. 推荐工具名过多，降低一眼理解
3. P1 封面钩子够不够强，没有做 A/B 备选视觉
4. P2 收藏价值强，但是否过于拥挤，需要单独检查
5. P3 工具匹配页可能更适合做成“任务 → 工具方向 → 可试工具”三列，而不是满页段落
6. P4 模板页是否需要留更大空白，让用户感到“可直接套用”
7. P5 是否应该更强地引导评论，而不是只做温和收口
```

### 修正建议

后续所有 B2 方法卡图文，生成前必须先写“风险地图”。

## 1.4 总控表

### 已完成

现有发布包已经有页面路径：

```text
P1：进入页
P2：任务判断页
P3：工具匹配页
P4：任务模板页
P5：行动评论页
```

### 缺漏

这个页面路径是结果，不是完整总控表。

缺少这些字段：

```text
页面目标
用户心理动作
主视觉动作
信息层级
收藏 / 评论 / 转发动机
是否需要人物
人物姿态任务
视觉禁忌
验收标准
```

### 修正建议

TP-001 B2 应补一个完整页面总控表。

推荐格式：

```text
页码｜页面任务｜用户心理动作｜核心句｜信息模块｜人物姿态｜用户动作｜验收标准
```

## 1.5 分阶段生成

### 已完成

实际过程最后变成了：

```text
先做单页
发现问题
修正第3页
再统一整套图
```

### 缺漏

最开始没有明确区分：

```text
概念草图
视觉样张
正式可发布图
```

导致中间出现过：

```text
把检查图当成成品方向
单张图好看但系列不统一
改某一张时妆造跑掉
```

### 修正建议

以后图文生产分三阶段：

```text
1. 黑白结构稿：只看信息路径
2. 视觉样式稿：只看风格、妆造、版式
3. 正式成品稿：统一输出整套图
```

不能直接从内容文字跳到正式图。

---

## 1.6 阶段验收

### 已完成

后期已经确认了：

```text
内容结构 OK
视觉统一 OK
人物妆造 OK
P2/P3 区分 OK
发布包 OK
```

### 缺漏

之前缺少“分阶段验收表”。

应当拆成：

```text
结构验收
视觉验收
成图验收
发布验收
```

每个阶段不要混验。

例如结构阶段不讨论妆造；视觉阶段不再大改选题。

## 2. 对现有 TP-001 B2 的具体缺漏检查

## 2.1 页面逻辑

### 当前状态

基本通过。

```text
P1：进入
P2：判断任务
P3：匹配工具
P4：表达模板
P5：行动评论
```

### 需要补强

P1 可以再强化“为什么用户要继续翻”。

现有 P1：

```text
AI工具越学越乱？
你不是笨，是入口错了。
```

这个可用，但还可以备选：

```text
别再问哪个 AI 工具最好用
先问你到底要它帮你做什么
```

这个更直接指向方法。

---

## 2.2 P2 干货页

### 当前状态

通过。

P2 已经具备收藏价值。

### 风险

信息量较大，手机端可能拥挤。

### 检查建议

成图前必须看手机预览，确认：

```text
工具名能不能读清
三类任务是否一眼区分
人物是否没有挤压干货区
```

---

## 2.3 P3 工具匹配页

### 当前状态

方向已修正。

P3 不再重复 P2，而是回答：

```text
任务分清后，该找哪类工具？
```

### 仍需注意

P3 最好采用三列或表格式：

```text
任务类型 → 工具方向 → 可试工具
```

如果做成段落，视觉上容易和 P2 混。

---

## 2.4 P4 模板页

### 当前状态

通过。

模板有直接套用价值。

### 可补强

P4 应该更像“可以截图保存的模板页”。

建议：

```text
减少装饰
增加空白
模板框更大
示例不要太多，最多一个主示例 + 一个小示例
```

---

## 2.5 P5 评论页

### 当前状态

可用。

### 可补强

P5 可以更明确：

```text
你不用写完整需求。
只要写：我想让 AI 帮我____。
```

这样降低评论门槛。

另外“发给还在乱学 AI 工具的人”可以作为转发句，但不要太刺人，保持口吻自然。

---

## 3. 视觉流程复盘

## 3.1 做对的地方

```text
1. 最终确认了整组图统一妆造。
2. 纠正了单张修改导致妆造跑偏的问题。
3. 明确人物不能硬贴，要和页面任务融在一起。
4. 形成了“人物姿态服务信息”的规则。
```

## 3.2 缺漏

视觉流程一开始没有先锁：

```text
角色母版
妆造母版
页面姿态表
人物出场比例
每页人物任务
```

导致前面出现过：

```text
每次生成像换一个妆造
改第3页时人物体系跑掉
人物姿态和页面信息不够融合
```

### 修正建议

以后图文系列必须先写“人物视觉母版”：

```text
人物原型
妆造
发型
服装
表情范围
姿态范围
每页人物功能
禁忌
```
