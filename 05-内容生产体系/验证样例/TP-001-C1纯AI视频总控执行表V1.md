# TP-001｜C1 纯 AI 视频总控执行表 V1

> 项目：TP-001
>
> 主题：AI 工具越多，反而不知道怎么开始
>
> 形式：C1 纯智能体生成视频
>
> 目标：用 AI 原生短片表现“工具越多越乱 → 先分任务 → 再选工具”。

---

## 0. 视频任务

```text
项目：TP-001
主题：AI 工具越多，反而不知道怎么开始
形式：C1 纯智能体生成视频
比例：9:16
建议时长：30-38 秒
主角：以用户本人为原型的 AI 视觉角色
目标：用一条短片把“工具越多越乱 → 先分任务 → 再选工具”的认知转向讲清楚。
```

这条视频不是工具合集，不是炫技片，不是纯动画展示。

它的本质是：

```text
认知短片 + 方法入口 + 评论引导
```

---

## 1. 固定项与弹性项

## 1.1 必须固定的东西

```text
1. 视频主线：
混乱 → 卡住 → 反转 → 方法 → 归位 → 行动

2. 核心判断：
不是先选工具，而是先定义任务。

3. 三类任务：
写东西 / 做东西 / 重复干活

4. 结尾动作：
我想让 AI 帮我 ______。

5. 人物系统：
同一个人、同一套妆造、同一气质，不中途换人。

6. 声音逻辑：
旁白先行，音乐最后。
```

## 1.2 可以灵活变化的东西

```text
1. 每段具体镜头角度
2. 卡片漂浮方式
3. 桌面道具细节
4. 人物轻微动作
5. 补充画面的插入顺序
6. 转场强弱
7. 字幕排版
8. 音乐风格，只要不抢旁白
```

## 1.3 灵活但不能越界的东西

```text
人物可以轻微眨眼、呼吸、看屏幕，但不能夸张表演。
工具卡片可以漂浮、归类，但不能乱飞和遮脸。
转场可以有设计感，但不能比内容更抢戏。
补充画面可以增加理解，但不能打断主线。
```

## 2. 旁白主线 V1

```text
AI工具越学越多，
反而越不知道从哪开始？

收藏夹很满，
教程看了一堆，
真正开始时还是空白。

问题可能不是你不会用 AI，
而是你一开始就问错了。

别先问哪个工具最好用，
先问：
我现在到底要完成什么任务？

普通人用 AI，
先分三类：

写东西，
做东西，
重复干活。

任务分清了，
工具才有方向。

今天先写一句话：

我想让 AI 帮我 ______。

先写出任务，
再谈工具。
```

旁白允许后期微调，但不能改掉三个核心信息：

```text
1. 工具多不等于会开始
2. 先分任务，再选工具
3. 用一句话启动行动
```

| 段落 | 语义状态 | 建议时长 | 旁白内容 | 画面任务 | 允许灵活变化 |
|---|---|---:|---|---|---|
| S1 | 混乱 | 4-5s | AI工具越学越多，反而越不知道从哪开始？ | 表现“工具太多，人被信息围住” | 工具卡片数量、漂浮路径、镜头推进强弱 |

## 4. 分段执行表

## S1｜混乱

### 固定任务

让用户一眼看到：AI 工具太多，普通人被信息压住。

### 画面

```text
主角坐在桌前，电脑打开。
周围有 ChatGPT、Claude、Kimi、Midjourney、Canva、Dify、Coze、n8n 等工具卡片。
工具卡片从四周靠近，但不要遮住人物脸。
```

### 谁能动

```text
工具卡片：可以慢慢漂浮靠近
镜头：可以极轻微推进
人物：只允许眨眼、呼吸、轻微眼神变化
背景：不动
文字：后期加
```

### 转场到 S2

连续推进，不花转。
从“工具多”自然过渡到“收藏很多但开始空白”。

### 可用补充画面

```text
工具卡片
教程卡片
收藏夹图标
搜索结果风卡片
```

### 禁止

```text
人物夸张惊讶
张嘴说话
工具卡片遮脸
霓虹科技风
镜头大幅晃动
```

---

## S2｜卡住

### 固定任务

表现：不是没努力，而是努力没有落到任务上。

### 画面

```text
左侧是收藏夹、教程截图、工具清单。
右侧是空白文档或空白输入框。
人物坐在中间，看着空白页。
```

### 谁能动

```text
左侧收藏内容：可以轻微堆叠
右侧空白页：保持安静
人物：轻微低头或看空白页
镜头：稳定或轻微横移
文字：后期加
```

### 转场到 S3

冻结 + 背景变淡 + 中心任务卡浮现。

这是第一个明显状态变化点。

### 可用补充画面

```text
空白文档
闪烁光标
教程缩略图
收藏夹堆叠
鼠标停住
```

### 禁止

```text
空白页自动写满
画面继续乱飞
人物变成崩溃表情
突然切到陌生场景
```

---

## S3｜认知反转

### 固定任务

告诉用户：问题不是工具不够，而是任务没定义。

### 画面

```text
工具卡片暂停、后退、变淡。
中间出现一张任务卡：
别先选工具，先定义任务。
```

### 谁能动

```text
工具卡片：暂停、淡出、后退
任务卡：浮现
人物：视线转向任务卡
镜头：轻微聚焦
背景：变干净
```

### 转场到 S4

任务卡展开成三张任务卡。

### 可用补充画面

```text
中心任务卡
简洁箭头
聚焦光效
任务框高亮
```

### 禁止

```text
炫酷爆炸特效
故障风
复杂流程图
加入新工具
文字变形
```

---

## S4｜方法出现

### 固定任务

让用户记住三类任务：写东西 / 做东西 / 重复干活。

### 画面

```text
三张任务卡依次出现：
写东西
做东西
重复干活

每张卡下方可以有少量关键词：
写东西：文案 / 脚本 / 总结
做东西：图片 / 视频 / 表格
重复干活：整理 / 改写 / 归档
```

### 谁能动

```text
三张任务卡：依次落下
人物：自然指向或解释
镜头：稳定
工具卡片：暂时弱化或停在背景
文字：尽量后期加
```

### 转场到 S5

连续动作转场。
三张任务卡摆好后，工具卡片开始往对应任务区移动。

### 可用补充画面

```text
任务标签
简洁图标
关键词贴纸
小箭头
```

### 禁止

```text
三张卡信息过满
人物姿势像硬摆拍
卡片飞太快
画面像 PPT 模板
```

---

## S5｜工具归位

### 固定任务

表现：工具不是消失了，而是要放到任务后面。

### 画面

```text
工具卡片自动归类到三张任务卡下面：

写东西：
ChatGPT / Claude / Kimi / Notion AI

做东西：
Midjourney / Canva / 剪映 / 即梦 / Gamma

重复干活：
Dify / Coze / n8n / Zapier
```

### 谁能动

```text
工具卡片：主要运动，自动归位
人物：可以轻微整理卡片
任务卡：保持稳定
镜头：稳定
背景：不动
准确文字：后期加
```

### 转场到 S6

元素退场 + 留白收口。
多余工具卡退后，只留下人物、便签或输入框。

### 可用补充画面

```text
工具名字卡
归类箭头
磁吸动画
分类框
轻微高亮
```

### 禁止

```text
工具卡乱飞
卡片文字乱码
新增无关工具
人物换脸
画面变成科技空间
```

---

## S6｜行动收口

### 固定任务

给用户一个马上能做的动作。

### 画面

```text
人物在便签或输入框里写：
我想让 AI 帮我 ______。
```

### 谁能动

```text
人物：轻微写字
笔尖 / 光标：可以动
背景：安静
工具卡片：只保留少量，不能抢戏
镜头：轻微拉近
```

### 结尾方式

停在空白横线上。
让用户自然产生“我也可以填一句”的感觉。

### 可用补充画面

```text
便签纸
输入框
手写线条
评论框
光标闪烁
```

### 禁止

```text
结尾继续炫技
画面重新变乱
写太多文字
出现复杂工具列表
音乐突然抢戏
```

## 5. 转场总表

| 转场 | 方式 | 目的 | 是否允许变化 |
|---|---|---|---|
| S1 → S2 | 连续推进 | 从混乱进入卡住 | 可以调整镜头方向 |
| S2 → S3 | 冻结 + 淡出 + 中心卡浮现 | 制造认知反转 | 固定，不建议改 |
| S3 → S4 | 任务卡展开 | 从结论进入方法 | 可以变化展开形式 |
| S4 → S5 | 连续动作 | 从分类进入归位 | 固定逻辑，形式可变 |
| S5 → S6 | 元素退场 + 留白 | 从系统整理进入个人行动 | 固定，不建议花哨 |

## 8. 字幕策略

准确文字不交给 AI 视频模型。

```text
视频生成阶段：画面可有模糊占位文字，但不依赖它。
剪辑阶段：中文标题、工具名、字幕、任务卡文字统一后期添加。
```

重点字幕：

```text
AI工具越学越乱？
收藏夹很满，开始还是空白。
别先选工具，先定义任务。
写东西 / 做东西 / 重复干活
任务分清后，工具才有方向。
我想让 AI 帮我 ______。
```

## 9. 音乐策略

声音顺序：

```text
先旁白
再画面
再字幕
最后音乐
```

音乐要求：

```text
轻电子
轻节奏
温暖
不抢人声
不诡异
不煽情
不做大片感
```

生成视频片段阶段：

```text
全部无声。
即使 AI 工具自动生成音乐，后期也删除音轨。
```

## 10. 灵活性控制机制

总控表不是为了固定死格式，而是为了防止乱。

### 固定骨架

```text
语义状态
核心判断
人物一致性
用户动作
声音逻辑
发布目标
```

### 弹性表达

```text
镜头角度
卡片运动
补充画面
人物轻微姿态
画面节奏
转场细节
```

### 创意预算

每条视频允许有 20%-30% 的灵活变化。

```text
70%-80%：按总控表执行，保证稳定。
20%-30%：允许镜头和表现有新鲜感。
```

但创意不能破坏：

```text
人物一致
语义推进
任务判断
结尾行动
```

## 11. 分段验收标准

### S1 验收

```text
能不能一眼看出工具太多？
人物有没有稳定？
工具卡有没有自然围过来？
```

### S2 验收

```text
收藏很多和空白开始的对比是否清楚？
用户是否能共鸣？
画面是否不乱？
```

### S3 验收

```text
反转是否明确？
“先定义任务”是否成为中心？
画面是否从乱变干净？
```

### S4 验收

```text
三类任务是否清楚？
用户能不能记住？
画面有没有变成纯 PPT？
```

### S5 验收

```text
工具是否真的归位？
归类关系是否能看懂？
运动是否自然？
```

### S6 验收

```text
用户是否知道下一步要写一句话？
结尾是否安静、有行动感？
是否适合引导评论？
```

## 12. 成片验收标准

成片必须通过：

```text
1. 用户看完能复述核心判断：
先分任务，再选工具。

2. 用户能记住三类任务：
写东西 / 做东西 / 重复干活。

3. 画面从混乱到清晰，变化明显。

4. 人物从头到尾是同一个人。

5. 旁白、画面、字幕对得上。

6. 音乐不抢旁白。

7. 结尾有明确动作：
我想让 AI 帮我 ______。

8. 不像 PPT，不像工具广告，不像炫技片。
```

## 14. 当前结论

这条 C1 不追求机械统一。

它追求：

```text
主线稳定
人物稳定
判断稳定
表现灵活
画面有变化
结尾能行动
```

总控表管的是“不能乱的地方”。
创意空间留给“可以变化的地方”。
