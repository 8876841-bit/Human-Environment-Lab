# 05-表达与传播模块（原内容生产体系）

> 当前状态：`OUTPUT / PARTIAL_SYNC`

本目录原名为“内容生产体系”。在 V2 阶段，它是 HEL 的执行主线；在 V3 阶段，它被降级并升级为：

```text
Human-Environment-Lab 的表达与传播模块。
```

它不再决定 HEL 的最高方向。它只在 Lab 判断某个真实触发点适合进入“公开表达 / 内容传播 / 平台发布”时被调用。

---

## 一、V3 中的定位

V3 主线是：

```text
碳基真实输入
→ 硅基数字处理
→ Human-Environment-Lab 转译与研究
→ 表达 / 传播 / 工具 / 产品 / 服务 / 行动 / 暂不表达
→ 物理世界验证
→ 数字生命与 Lab 双重迭代
```

本目录只负责其中的这一段：

```text
Lab 判断适合公开表达 / 内容传播
↓
平台表达转译
↓
图文 / 视频 / 长文 / 发布包
↓
物理世界反馈
```

因此，内容不是默认目标。

```text
不是所有真实触发都要做成内容。
不是所有观察都适合公开传播。
不是所有表达都要服务平台增长。
```

---

## 二、调用本目录之前，必须先完成的判断

每个触发点进入本目录之前，必须先回答：

```text
1. 它是否来自碳基物理世界的真实触发？
2. 它经过数字生命的整理、分析、推演和边界检查了吗？
3. 它目前是事实、假设、推演，还是个人判断？
4. 它是否适合公开表达？
5. 如果公开表达，目标是传播、解释、建立信任、引发反馈，还是现实交付？
6. 有没有隐私、伦理、误导、夸大、过度简化风险？
```

没有完成这些判断，不能直接进入选题、脚本、图文或视频生产。

## 五、V3 使用流程

```text
1. 从 RUNBOOK.md 输入真实触发。
2. 经过碳基真实性、证据强度、数字边界检查。
3. 由 Lab 判断交付形式。
4. 只有交付形式为“公开表达 / 内容传播”时，进入本目录。
5. 使用本目录完成平台表达、形式决策、图文 / 视频 / 发布包。
6. 发布或交付后，反馈必须回到 RUNBOOK / 03-观察日志 / 规则库。
```

## 六、当前硬边界

```text
没有真实触发，不进入内容生产。
没有数字边界检查，不进入公开表达。
没有平台与受众判断，不进入脚本。
没有隐私与伦理检查，不进入发布。
没有现实反馈，不进入稳定规则。
```
