## 一、核心定位

## 二、底层逻辑层

### 平台算法本质

所有平台都是"用户需求 ↔ 内容特征"的匹配游戏。

#### 抖音算法
- **漏斗机制**：500-1000 初级池 → 完播率≥30%、点赞率≥5%、评论率≥1% → 逐级放大
- **行为权重**：收藏/转发 > 点赞 > 完播
- **核心公式**：推荐优先级 = 预测用户行为概率 × 行为价值权重

#### 小红书算法
- **CES 评分**：`点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8`
- **2小时黄金期**：2小时内高权重互动决定流量跃迁
- **搜索权重**：30% 用户直接搜索，长尾词布局重要
- **字数加成**：超过 600 字获得额外权重

#### B站算法
- **硬币权重高**：互动指标权重高于点赞
- **系列内容优势**：同系列内容有加成
- **完播率重要**：尤其是30秒、1分钟、3分钟节点

### 平台选择矩阵

| 平台 | 核心人群 | 适合内容 | 算法偏好 |
|------|----------|----------|----------|
| 抖音 | 下沉市场、中青年 | 情绪冲突、生活共鸣 | 完播率、冲突感 |
| 小红书 | 一二线城市、女性为主 | 实用干货、治愈系 | 收藏率、颜值 |
| B站 | 年轻人、有深度需求 | 深度解析、系列内容 | 完播率、硬币 |

## 四、生产模式

### 三种生产模式

#### 模式 A：纯自动化

```
核心目标：大批量、高效率、快速测试
适用场景：验证选题方向、初期量积累
画面风格：AI抽象/概念风格
策略：内容设定 → AI生成 → 批量发布 → 数据反馈 → 筛选放大
```

#### 模式 B：纯人工

```
核心目标：真实感、信任感、温度感
适用场景：建立个人IP、建立信任
画面风格：真人出镜 / 真实场景拍摄，不加特效
策略：用真实感对抗AI泛滥，让用户感受"这是真实的人在表达"
```

#### 模式 C：人工 + 自动化结合

```
核心目标：既有人性温度，又有视觉冲击力
适用场景：精品内容制作
画面策略：
- 首图：真人/真实场景（抓眼球）
- 补充画面：AI生成（丰富视觉）
- 特效/转场：自动化增强节奏感
- 核心观点：人工金句（保灵魂）
```

## 六、账号策略

### ✅ 已确认：按角度分账号，形式跟着话题走

**策略**：
- 账号 = 角度（垂直深耕，建立认知）
- 形式 = 灵活（根据话题选最合适的表现形式）

**优点**：
- 每个账号有清晰定位，用户知道"这个账号讲什么"
- 形式灵活适配不同话题，不被形式束缚
- 数据反馈更精准：知道是"角度对了"还是"形式对了"

### 账号矩阵（8条母线 → 8个角度账号）

| 账号 | 角度 | 核心人群 | 适合形式 |
|------|------|----------|----------|
| 实用层-空间 | 空间秩序 | 需要解决收纳问题的人 | 漫画/口播/图文 |
| 实用层-材料 | 材料感官 | 对家居质感有追求的人 | 超写实摄影/漫画 |
| 实用层-工艺 | 工艺机制 | 装修踩坑er | 科普视频/图文 |
| 认知层-案例 | 案例探家 | 想要参考借鉴的人 | 探家实拍/漫画 |
| 认知层-AI | AI认知秩序 | 在适应AI变化的人 | AI演示/口播 |
| 认知层-生活 | 真实生活转型 | 转型期焦虑的人 | 感悟口播/漫画 |
| 哲学层-商业 | 商业服务 | 避免踩坑的人 | 科普/漫画 |
| 哲学层-意义 | 意义与文明 | 追问存在的人 | 深度口播/漫画 |

### 形式选择逻辑

```
话题输入
    ↓
【AI】分析话题 → 属于哪个角度？
    ↓
【AI】推荐形式 → 根据话题类型 + 平台推荐最佳形式组合
    ↓
【人工】确认形式
    ↓
```

## 十一、AI主导内容的效果把控

### 核心原则

**AI给骨架，人工给灵魂**

```
AI产出：
- 选题候选（从母线推导）
- 脚本框架（四步结构）
- 分镜描述（画面/风格/色调）
- BGM推荐（情绪匹配）

人工注入：
- 个人经历/真实案例
- 只有你能说的视角
- 核心金句（必须人工写）
- 最终审核
```

### 去AI味的3个检测问题

每个AI生成的脚本，必须通过这3问：

1. **有具体细节吗？**
   - ❌ AI味："收纳可以让生活更有序"
   - ✅ 去AI味："那天我站在衣柜前，找一件T恤翻了10分钟"

2. **有个人视角吗？**
   - ❌ AI味："很多人都遇到过这个问题"
   - ✅ 去AI味："我妈的柜子永远比我整齐，因为她从来不囤"

3. **有情绪的真实吗？**
   - ❌ AI味："这告诉我们一个道理"
   - ✅ 去AI味："我那一刻真的有点崩溃"

| 内容情绪 | BGM风格 | 示例 |
|----------|---------|------|

### 声画协调原则

```
情绪匹配 > 流行度 > 个人喜好
画面节奏跟随BGM情绪
人声与BGM音量比例：人声0dB，BGM -20dB~-15dB
```

## 十五、效果验证与迭代

### 数据诊断规则

| 指标 | 低于 | 诊断 | 调整方向 |
|------|------|------|----------|
| 完播率 | 40% | Hook没抓准 | 重写开头，更口语化 |

| 评论深度 | 无深度 | 话题不够开放 | 结尾留开放性问题 |

### 迭代闭环

```

    ↓
```

## 十六、起号策略

### 前30天行动计划

| 周 | 目标 | 动作 |
|----|------|------|
| 第1周 | 测试方向 | 发布3种不同话题，收集数据 |
| 第2周 | 确定方向 | 数据好的话题深挖，差的优化或放弃 |
| 第3周 | 建立节奏 | 确定发布频率和时间 |
| 第4周 | 复盘迭代 | 总结规律，调整策略 |

### 关键动作清单

- [ ] 前3天：养号 + 找对标账号（低粉爆款视频）
- [ ] 蹭热榜：视频内容与热榜话题相关
- [ ] 前3秒：必须有强钩子
- [ ] 积极互动：回复评论，建立粘性
- [ ] 数据复盘：每条视频发布后24小时记录数据

### 核心公式

**底层逻辑成立** + **大数据验证成立** + **差异化存在** = 可用选题

### 第一步：底层逻辑推导

从8条母线的底层规律推导选题：

```
母线：空间秩序
底层规律：人在家里需要"掌控感"，但空间限制会破坏这种掌控
↓
推导选题：为什么柜子越收越乱？（失控感）

母线：AI认知秩序
底层规律：人学AI最难的不是技术，是心理障碍
↓
推导选题：为什么看了100个教程，还是不敢用AI？（心理障碍）
```

### 第二步：大数据验证

在平台搜索验证：

```
验证方式：
1. 抖音搜索框输入 → 看是否有相关话题/视频
2. 小红书搜索 → 看有多少篇笔记/讨论热度
3. 评论区挖掘 → 真实的痛点表达

判断标准：
- 有讨论（不是没人关心）
- 痛点真实（不是伪需求）
- 有差异化空间（不是说过了、说烂了）
```

### 第三步：差异化检查（4个维度）

**只要有1个维度能差异化，这个话题就能用。**

| 维度 | 说明 | 示例 |
|------|------|------|
| **脚本角度** | 新的切入视角 | 别人讲收纳技巧，你讲"为什么越收越焦虑" |
| **内容形式** | 别人没用过的形式 | 话题被说烂了，但你用漫画表达 |
| **人群视角** | 换一个人群讲 | 别人从业主讲，你从装修师傅讲 |
| **执行质量** | 同样的内容，更极致 | 别人1分钟，你3分钟深度解析 |

### 举例说明

```
话题：厨房收纳

❌ 否掉的真正理由：
   - 4个维度都找不到差异化
   - 市场已经饱和到没有新意

✅ 不否的理由：
```
