# 21｜图文页面任务阀门

> 版本：V1  
> 状态：已沉淀为图文成品硬规则  
> 适用范围：小红书图文、抖音图集、视频号图文、图文收藏卡、方法卡、判断表  
> 核心结论：**图文不是几张同风格卡片，而是一组按顺序推进用户理解的阅读路径。**

---

## 一、为什么图文也需要页面任务阀门？

视频有关键帧任务，图文也有页面任务。

视频的问题是：

```text
几张关键帧风格一致，但镜头没有推进。
```

图文的问题是：

```text
几页卡片风格一致，但阅读没有推进。
```

如果没有页面任务阀门，就容易出现：

```text
P1 和 P2 都在说焦虑
P3 和 P4 都在说方法
P5 又重新讲一遍问题
每页都好看，但用户看完不知道自己多理解了什么
```

所以图文也要过两道闸门：

```text
视觉模板闸门：保证一组图文像同一套卡片。
页面任务闸门：保证每一页不是重复上一页。
```

---

## 二、第一性原理

图文不是图片集合。

图文的本质是：

```text
空间中的阅读路径。
```

用户从 P1 滑到 P5，不是在看五张图，而是在经历一个理解路径。

每一页都必须回答：

```text
上一页，用户已经知道了什么？
这一页，必须新增什么理解？
下一页，要把用户带到哪里？
```

如果一页没有新增理解，它就不是推进，而是重复。

---

## 三、图文页面任务卡

每一页生成前，必须先填写页面任务卡。

```text
页码：P__
页面主任务：
允许副任务：
上一页用户已经知道什么：
这一页必须新增什么理解：
下一页要接到哪里：
本页必须出现的信息证据：
本页不能抢哪一页的任务：
本页不允许重复什么：
验收一句话：
```

没有填写页面任务卡，不允许生成单页画面。

---

## 四、页面之间必须有三种推进之一

### 1. 认知推进

```text
不知道问题 → 承认自己也有这个问题
以为是工具问题 → 明白是判断顺序问题
明白问题 → 得到判断入口
```

### 2. 信息推进

```text
现象 → 原因 → 方法 → 对应 → 行动
问题 → 误区 → 判断 → 表格 → 收束
状态 → 拆解 → 选择 → 工具 → 今天做什么
```

### 3. 行动推进

```text
停下来 → 看进去 → 明白 → 对照 → 执行
```

一组图文里，每页至少要完成一种推进。  
如果只是重复相同观点，只是换版式，不算合格页面。

---

## 五、图文页任务的硬控与自由

### 必须硬控

```text
1. 每页主任务
2. 每页新增理解
3. 每页和上一页的区别
4. 每页是否能接下一页
5. 每页是否服务整组图文的收藏价值
```

### 可以放开

```text
1. 构图方式
2. 图标形式
3. 信息块位置
4. 人物是否出现
5. 卡片样式细节
6. 标注方式
7. 表格 / 判断树 / 对比 / 流程箭头的具体呈现
```

原则：

```text
阀门不是为了把每一页做死，
而是为了防止每一页都在讲同一件事。
```

---

## 六、平台规则的时效性

平台规则、平台调性、推荐节奏、审核边界、内容偏好会周期性变化。

所以本仓库里的平台规则只能作为：

```text
当前阶段的工作模型
```

不能当成永久规则。

每次涉及平台发布前，必须判断：

```text
1. 当前内容是否依赖最新平台规则？
2. 是否涉及审核风险、广告营销、AI 生成内容标识、医疗/法律/金融等敏感领域？
3. 是否涉及最新推荐机制、封面尺寸、标题规范、流量规则？
4. 是否需要查平台官方规则或创作者中心说明？
```

如果答案是“是”，必须先更新平台规则判断，再进入成品生成。

本文件只管页面任务。平台规则更新机制以：

```text
05-内容生产体系/16-平台规则与发布调性表.md
```

为准。

## 七、TP-001 图文页面任务示例

TP-001 图文为 5 页收藏型方法卡。  
所属主题：AI 工具越多，反而不知道怎么开始。  
核心表达：先判断自己想让 AI 帮你完成什么，再选择工具。

---

### P1｜封面：抓停留

#### 页面主任务

```text
让用户 1 秒停下来，觉得“这说的是我”。
```

#### 允许副任务

```text
预告这组图文会帮他理清 AI 工具选择。
```

#### 上一页用户已经知道什么

```text
无。第一页负责开场。
```

#### 这一页必须新增什么理解

```text
我现在的混乱状态被说中了。
```

#### 下一页要接到哪里

```text
P2：具体说中用户被工具拉扯的状态。
```

#### 本页不能抢哪一页的任务

```text
不能提前讲完整方法。
不能提前展开工具对应表。
```

#### 验收一句话

```text
这是停留入口，不是方法说明。
```

---

### P2｜痛点共鸣：说中状态

#### 页面主任务

```text
让用户承认：我确实每个工具都想学，但都没真正用起来。
```

#### 允许副任务

```text
降低用户自责，让他明白这不是单纯懒或笨。
```

#### 上一页用户已经知道什么

```text
AI 工具越多，自己越乱。
```

#### 这一页必须新增什么理解

```text
混乱不是抽象的，而是具体发生在 Codex、Dify、n8n、Coze、即梦、可灵等工具入口里。
```

#### 下一页要接到哪里

```text
P3：把混乱转成三个判断问题。
```

#### 本页不能抢哪一页的任务

```text
不能开始给完整判断框架。
不能直接做工具对应表。
```

#### 验收一句话

```text
这是代入，不是解决方案。
```

---

### P3｜判断三问：给判断入口

#### 页面主任务

```text
把用户从“该学哪个工具”转到“我想让 AI 帮我做什么”。
```

#### 允许副任务

```text
为 P4 的工具对应表建立分类基础。
```

#### 上一页用户已经知道什么

```text
自己被太多工具入口拉扯。
```

#### 这一页必须新增什么理解

```text
选工具前，先判断：写东西 / 做东西 / 重复干活。
```

#### 下一页要接到哪里

```text
P4：把三类任务对应到具体工具和产出。
```

#### 本页不能抢哪一页的任务

```text
不能把所有工具都列完。
不能变成工具推荐页。
```

#### 验收一句话

```text
这是判断入口，不是工具清单。
```

---

### P4｜工具用途表：给对应关系

#### 页面主任务

```text
让用户知道：不同任务对应不同工具，不要混在一起学。
```

#### 允许副任务

```text
让用户产生收藏价值。
```

#### 上一页用户已经知道什么

```text
自己要先判断写东西 / 做东西 / 重复干活。
```

#### 这一页必须新增什么理解

```text
写东西可以先用 ChatGPT / Claude；
做东西再看 Codex / Claude Code / Canva / 即梦；
重复干活再看 Dify / n8n / Coze。
```

#### 下一页要接到哪里

```text
P5：把工具判断落到今天能做的一句话任务。
```

#### 本页不能抢哪一页的任务

```text
不能继续讲焦虑。
不能新增复杂分类。
不能让工具名抢走任务判断。
```

#### 验收一句话

```text
这是对应表，不是工具大全。
```

---

### P5｜最小行动：收束执行

#### 页面主任务

```text
让用户今天就能写出一句话任务。
```

#### 允许副任务

```text
引导收藏和评论。
```

#### 上一页用户已经知道什么

```text
三类任务各自对应不同工具。
```

#### 这一页必须新增什么理解

```text
不要再收藏 100 个教程，先写清楚：我现在最想让 AI 帮我完成什么。
```

#### 下一页要接到哪里

```text
无。这里收束。
```

#### 本页不能抢哪一页的任务

```text
不能再新增新概念。
不能重新展开工具表。
不能重新制造焦虑。
```

#### 验收一句话

```text
这是行动收束，不是新一轮解释。
```

## 八、TP-001 五页阅读路径

TP-001 图文的正确推进是：

```text
P1：停住 —— AI 工具越学越乱？
P2：代入 —— 每个都想学，每个都没真正用起来
P3：明白 —— 先判断写东西 / 做东西 / 重复干活
P4：对照 —— 不同任务对应不同工具
P5：行动 —— 今天先写一句话任务
```

如果实际生成结果变成：

```text
P1：焦虑
P2：还是焦虑
P3：继续焦虑
P4：突然堆工具
P5：又回到焦虑
```

则判废。

## 九、图文页面生成前检查

生成图文前必须回答：

```text
1. 本组图文的主平台是什么？
2. 当前平台规则是否需要更新核对？
3. 本组图文的核心阅读路径是什么？
4. 每一页的主任务是否不同？
5. 每一页是否新增理解？
6. 每一页是否没有抢下一页任务？
7. 每一页是否延续统一视觉模板？
8. 每一页是否具有收藏价值？
```

只要第 2 条涉及当前规则或审核边界，必须先更新平台规则判断。

---

## 十、硬性禁止

```text
禁止一组图文只是五张同风格海报。
禁止每一页都只讲情绪。
禁止每一页都在重复同一个观点。
禁止 P3 提前变成工具表。
禁止 P4 变成工具大全。
禁止 P5 再新增复杂概念。
禁止忽视平台规则的时效性。
```

---

## 十一、一句话原则

```text
图文页面不是独立卡片，
而是用户理解一步一步往前走的阅读路径。
```
