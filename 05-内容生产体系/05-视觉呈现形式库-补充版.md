# HEL 内容视觉呈现形式库 (补充版)

除了“治愈系叙事漫画”这种高度适配【越住越累】和【家装心理学】专栏的形式外，基于 HEL 的八大痛点专栏，我们还需要建立其他几种固定的视觉风格资产。

这些风格必须满足两个条件：第一，有极强的辨识度，即统一的审美底色；第二，能够通过固定 Prompt 配合 AI 工具实现高质高效量产。

## 一、 图文形式补充库

为了丰富小红书等图文平台的视觉表现，我们设计了三种额外的图文形式，分别针对干货科普、情绪反差和深夜陪伴。

**极简结构图 / 概念解剖图 (Minimalist Anatomy)** 适用于【装修不翻车的底层逻辑】和【拆解行业的套路】专栏。其核心逻辑是用极简的线条和结构，把复杂的工艺、动线、商业套路“解剖”给用户看。视觉上采用纯色背景（深灰、克莱因蓝或米白），带有轻微噪点质感；主体是线框风格或等距视角的 3D 模型；大面积留白中用细线引出硬核的标注文字。这种风格自带“专业、理性、干货”的滤镜，极易激发用户的收藏欲。

**电影感实景对比 (Cinematic Before/After)** 适用于【别人的家，你的生活】和【越住越累的真相】专栏。它摒弃了普通中介拍房图的粗糙，用电影的布光和构图来展现“环境如何塑造人”。改造前画面呈现冷色调、杂乱且光线暗淡，带有压抑感；改造后则转为暖色调、充满秩序感，光线有明确的指向性。文字部分不写俗套的“客厅改造”，而是采用情绪金句，如“阳光照进来的那一刻，我原谅了生活的刁难”。这种强烈的视觉反差能直击情绪，唤起用户的向往。

**碎片日记 / 局部侧写 (Fragmented Diary)** 适用于【深夜思考局】和【换个活法】专栏。它用微距镜头捕捉生活中的小细节，配上走心的文案，营造一种“朋友在和你碎碎念”的亲近感。画面通常具有胶片质感，聚焦于一杯冒热气的咖啡、阳光下的猫毛或斑驳的木地板。配合拍立得风格的日期标注和日记体随笔，这种低信息密度、高情绪密度的内容在深夜时段最容易引发共鸣和转发。

| 图文形式 | 适用专栏 | 视觉特征 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **极简结构图** | 装修不翻车、拆解套路 | 纯色背景、线框/等距3D模型、硬核标注 | 传递专业感，提升收藏率 |
| **电影感对比** | 别人的家、越住越累 | 电影布光、冷暖色调对比、情绪金句 | 制造视觉反差，唤起生活向往 |
| **碎片日记** | 深夜思考局、换个活法 | 胶片质感、微距细节、日记体随笔 | 营造亲近感，深夜情绪共鸣 |

## 二、 视频形式补充库

在抖音、B 站和视频号等平台，除了真人独白，我们还需要以下三种视频形式来丰富矩阵并提升制作效率。

**空间情绪空镜 + TTS 旁白 (Space Mood B-Roll)** 适用于【家装里的心理学】和【深夜思考局】专栏。这种形式全程无真人出镜，画面由多个高质量的空间空镜组成（如微风吹动窗帘、木质家具纹理特写），切换缓慢。配合白噪音和极具质感的 TTS 旁白，营造出散文诗般的意境。其最大优势在于素材可通过 AI 视频生成工具批量生成，极易量产且能保持高审美调性。

**黑板推演 / 桌面推演 (Whiteboard / Desk Explanation)** 适用于【拆解行业的套路】和【被 AI 逼疯的打工人】专栏。视频采用俯拍视角，主体是一张干净的木桌面或黑板，真人的手在上面画结构图、摆放卡片一步步推演逻辑。这种形式比真人露脸独白更吸引注意力，因为观众的视线会跟着手部的动作走，非常适合讲透复杂的商业逻辑或 AI 工作流。

**“伪访谈” / 对话切片 (Mock Interview)** 适用于【换个活法】和【别人的家，你的生活】专栏。真人出镜但不直视镜头，而是看向画外假装接受采访。画面偶尔切入黑白滤镜或被采访者的生活实景片段。这种形式天然带有纪录片的真实感和深度感，能够极大提升内容的信任度和格调，适合用来塑造“专家”或“深度观察者”的人设。

| 视频形式 | 适用专栏 | 视觉特征 | 制作优势与作用 |
| :--- | :--- | :--- | :--- |
| **情绪空镜 + 旁白** | 家装心理学、深夜思考局 | 高质量空镜、缓慢切换、质感旁白 | 易于 AI 量产，保持高审美调性 |
| **桌面推演** | 拆解套路、AI 认知 | 俯拍视角、手部动作推演逻辑 | 强吸引力，适合讲透复杂逻辑 |
| **伪访谈** | 换个活法、别人的家 | 看向画外、纪录片滤镜、穿插实景 | 提升真实感与信任度，塑造专业人设 |
