# 13-视频成品形式库

> 本文件定义 HEL 视频内容的三类可执行成品形式。  
> 视频不是固定时长模板，也不是只输出拍摄清单。它必须从真实触发点和第一性原理出发，再按平台调性生成可发布、可复盘的成品视频包。

---

## 一、核心原则

```text
先判断内容任务和平台版本，再定视频形式和时长。
```

视频生产的默认目标不是“拍摄清单”，而是：

```text
可直接发布 / 可直接剪辑 / 可直接生成的成品视频包。
```

拍摄清单只在以下情况出现：

```text
需要真人实拍
需要现场补素材
需要人工确认隐私边界
需要人工兜底画面真实感
```

如果某条内容不需要真人拍摄，不需要现场补素材，那么最终输出必须是：

```text
成品视频文件 / 可渲染的视频工程 / 可直接导出的成片包
```

而不是：

```text
拍摄清单
拍摄建议
执行建议
```

---

## 二、视频生成前硬校验

每次生成视频前，必须先回答：

```text
1. 真实触发点是什么？
2. 第一性原理锚点是什么？
3. 首发平台是什么？
4. 谁在看？他为什么会停下来？
5. 这条视频要表达什么？不表达什么？
6. 推荐时长是多少？为什么？
7. 是否需要真人实拍 / 真实素材 / AI 画面？
8. 是否存在夸大收益、制造焦虑、隐私、版权风险？
```

视频时长不固定。

```text
抖音 / 快手：15-30 秒短冲击版
小红书 / 视频号：40-90 秒解释收藏版
B站：3-8 分钟深度拆解版
多平台测试：30-45 秒通用测试版
```

---

## 三、三类视频总览

| 类型 | 核心价值 | 成品特点 | 自动化程度 | 默认输出 |
|---|---|---|---|---|
| V1 实拍原生型 | 真实 | 现场感强、轻剪辑、低包装 | 低到中 | 拍摄清单 + 成片 |
| V2 AI 生成型 | 速度和抽象表达 | AI 画面、旁白、动效、字幕成片 | 高 | 直接成品视频包 |
| V3 混合增强型 | 真实 + 解释 + 节奏 | 实拍素材 + AI 图示/字幕/动效/转场 | 中到高 | 有素材则直接成片；缺素材才补拍清单 |

---

## 四、V1：实拍原生型

### 1. 定义

```text
以真实现场、真实人物、真实空间、真实声音为核心。
保留原生感，只做最低限度处理。
```

它不是完全不剪，而是：

```text
轻剪辑
轻字幕
轻调色
少特效
少包装
保留真实节奏
```

### 2. 适合内容

```text
探家
现场观察
材料质感
客户真实反应
工艺细节
施工问题
生活现场
```

### 3. 不适合内容

```text
抽象机制解释
AI 工具流程演示
需要大量图示辅助的内容
没有现场素材的观点内容
```

### 4. 成品结构

V1 时长按平台决定。

```text
抖音 / 快手：0-3 秒真实冲突 + 15-30 秒现场判断
小红书 / 视频号：真实画面 + 细节解释 + 40-90 秒方法或提醒
B站：真实案例开场 + 过程拆解 + 3-8 分钟深度复盘
```

### 5. AI 负责

```text
转写口播
提取高光片段
筛选可用镜头
生成标题
生成字幕
生成封面文字
生成发布文案
生成标签
```

### 6. 人工负责

```text
现场拍摄
确认哪些画面能公开
选择是否保留现场声音
审核人物、门牌、客户隐私
最终发布前检查
```

### 7. 输出成品

```text
1. 人工拍摄清单
2. 可发布视频文件
3. 字幕文件
4. 封面图
5. 标题 3-5 个
6. 平台文案
7. 标签
8. 评论区置顶问题
9. 隐私检查
```

V1 可以输出拍摄清单，但拍摄清单不是终点。

---

## 五、V2：AI 生成型

### 1. 定义

```text
主要依靠 AI 生成画面、旁白、字幕、动效和转场。
用于快速表达抽象问题、心理机制、AI 认知、生活状态和规模化选题测试。
```

V2 没有真人拍摄需求，所以默认不能只输出拍摄清单。

V2 的终点必须是：

```text
AI 生成视频成品包。
```

### 2. 核心价值

```text
速度快
成本低
适合批量测试
能表现看不见的机制
能把抽象概念具象化
```

### 3. 适合内容

```text
AI 工具越多，人反而越乱
判断系统缺失
被算法和工具牵着走
真实生活被效率吞没
空间如何影响人的状态
一个抽象机制如何运转
```

### 4. 不适合内容

```text
需要强真实信任的客户案例
需要展示真实材料细节
需要现场证据的内容
强销售转化内容
```

### 5. 成品结构

V2 时长按平台决定。

```text
短冲击版：15-30 秒
解释收藏版：40-90 秒
深度拆解版：3-8 分钟，通常需要升级为桌面推演 / B站结构视频
多平台测试版：30-45 秒
```

典型 30-45 秒结构：

```text
0-3 秒：强问题 / 强画面隐喻
3-10 秒：说中真实状态
10-17 秒：反转判断
17-35 秒：给方法 / 对应关系
35-45 秒：收束 + 互动问题
```

### 6. AI 负责

```text
生成脚本
生成分镜
生成画面提示词
生成图片 / 视频片段
生成旁白
生成字幕
生成转场
生成 BGM 情绪
生成封面
合成为成品视频
生成发布文案
```

### 7. 人工负责

```text
确认观点是否准确
确认是否来自第一性原理锚点
审核 AI 画面是否怪异
检查字幕错字
确认是否符合平台调性
确认没有夸大收益或制造焦虑风险
选择最终发布版本
```

人工负责审核，不负责拍摄。

### 8. 输出成品

```text
1. 第一性原理锚点
2. 平台表达版本
3. AI 生成视频成片 / 可剪辑工程
4. 封面图
5. 字幕文件
6. 旁白音频
7. 标题 3-5 个
8. 平台文案
9. 标签
10. 可批量衍生选题
11. 平台风险检查
```

禁止把 V2 的最终输出写成：

```text
拍摄清单
拍摄建议
素材建议
```

---

## 六、V3：混合增强型

### 1. 定义

```text
真实素材为骨架，AI 负责解释、增强、包装和节奏。
```

它不是简单混剪，而是：

```text
实拍画面
+
AI 结构图
+
AI 字幕 / 花字
+
AI 插画 / 示意画面
+
转场 / 节奏 / 特效增强
```

### 2. 核心价值

```text
既真实
又讲得清楚
画面更有意思
信息更容易被理解
比纯实拍更有表达力
比纯 AI 更有信任感
```

### 3. 适合内容

```text
案例拆解
空间解释
商业判断
AI 工具使用
复杂问题讲清楚
观点 + 现场结合
真实生活转型类内容
```

### 4. 不适合内容

```text
极短现场随拍
只有纯情绪没有解释的内容
没有任何真实素材又强行说案例的内容
```

### 5. 成品结构

V3 时长按平台决定。

```text
抖音 / 快手：真实画面开场 + 结构图快速解释
小红书 / 视频号：真实素材 + 方法解释 + 收藏承接
B站：真实案例 + 系统拆解 + 项目复盘
```

### 6. AI 负责

```text
生成结构图
生成解释性插画
生成字幕和花字
生成转场
生成镜头节奏
生成 BGM 情绪
生成封面
合成为混合增强视频
生成发布文案
生成多平台版本
```

### 7. 人工负责

```text
提供真实素材
确认核心观点
确认隐私边界
审核 AI 补充画面是否误导
最终发布前把关
```

注意：

```text
如果真实素材已经足够，V3 直接输出混合增强成片。
只有真实素材不足时，才额外输出补拍清单。
```

### 8. 输出成品

```text
1. 混合增强视频成片
2. 封面图
3. 字幕文件
4. AI 图示 / 插画素材
5. 标题 3-5 个
6. 平台文案
7. 标签
8. 可衍生图文版
9. 如素材不足，再附补拍清单
10. 隐私与平台风险检查
```

---

## 七、三类视频选择规则

| 内容情况 | 推荐类型 | 最终输出 |
|---|---|---|
| 有真实现场，真实感最重要 | V1 实拍原生型 | 拍摄清单 + 成片 |
| 内容抽象，需要快速解释 | V2 AI 生成型 | 直接成品视频包 |
| 有真实素材，又需要讲清机制 | V3 混合增强型 | 直接混合增强成片 |
| 要建立信任 | V1 或 V3 | 成片，必要时补拍 |
| 要批量测试选题 | V2 | 直接成品视频包 |
| 要做账号差异化 | V3 | 直接混合增强成片 |
| 要保留生活现场感 | V1 | 拍摄清单 + 成片 |
| 要讲复杂判断 | V3 / 桌面推演 | 成片包 |

---

## 八、视频成品输出标准

每次视频生产，必须输出成品包，不只输出建议。

```text
【视频成品包】
1. 真实触发点
2. 第一性原理锚点
3. 平台与受众判断
4. 视频类型：V1 / V2 / V3
5. 推荐时长：按平台决定
6. 成品视频文件 / 可渲染视频工程 / 成片包
7. 成片脚本
8. 镜头 / 画面结构
9. 字幕文本
10. 花字清单
11. 转场节奏
12. BGM 情绪
13. 封面图
14. 标题
15. 平台文案
16. 标签
17. 评论区引导
18. 隐私与平台风险检查
19. 只有需要真人拍摄或素材不足时，才附人工拍摄 / 补拍清单
```

禁止规则：

```text
没有真人拍摄需求时，不允许把“拍摄清单”作为最终交付物。
没有素材缺口时，不允许把“补拍建议”作为最终交付物。
不允许固定把所有短视频写成 45-60 秒。
不允许为了平台刺激而偏离第一性原理锚点。
```

---

## 九、当前阶段优先级

```text
先把 V1 / V2 / V3 的成品标准跑通。
再考虑把它们接进 Dify、n8n、剪映、Remotion 或其他自动化工作流。
```

当前不要急着做：

```text
不要马上接全自动剪辑。
不要马上接多平台分发。
不要同时做十几种视频形式。
不要把纯 AI 视频当成万能方案。
```

---

## 十、一句话标准

```text
视频不是固定时长模板。
V1 负责真实，V2 负责速度和抽象表达，V3 负责真实感与解释力结合；三者都必须从底层判断出发，按平台调性输出成品视频包。
```
