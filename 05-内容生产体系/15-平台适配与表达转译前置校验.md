# 平台适配与表达转译前置校验

> 本文件用于补充 Dify 内容工作流。  
> 所有触发点进入脚本前，必须先完成平台、用户、表达目标和语言转译判断。

---

## 一、为什么需要前置校验

过去容易出现的问题：

```text
先写脚本，再回头修平台调性。
先讲底层逻辑，再想办法变成人话。
先生成内容，再判断用户到底是谁。
```

这会导致内容看起来完整，但发布时不一定有效。

正确顺序应该是：

```text
触发点
↓
平台规则
↓
谁在看
↓
我们要表达什么
↓
怎么转译成人话
↓
再进入脚本 / 图文 / 视频执行
```

---

## 二、前置四问

每条内容都必须先问：

```text
1. 发在哪个平台？这个平台适合什么节奏？
2. 到底是谁在看？他当下是什么状态？
3. 我们到底要表达什么？不是表达什么？
4. 底层逻辑怎么转成人能听懂的话？
```

---

## 三、平台规则 / 平台调性

### 抖音 / 快手

核心任务：

```text
抓停留
抓痛点
抓情绪
促评论
```

推荐时长：

```text
15-30 秒
```

表达要求：

```text
前 3 秒必须说中问题。
不要铺垫背景。
不要慢慢讲原因。
先让用户觉得“这说的是我”。
```

适合结构：

```text
痛点句 → 反转句 → 一个判断方法 → 评论互动
```

---

### 小红书 / 视频号

核心任务：

```text
讲清楚
让人收藏
给方法
建立轻信任
```

推荐时长：

```text
40-90 秒
```

表达要求：

```text
要有共鸣，但不能只卖焦虑。
要给一个可收藏、可复用的判断方法。
最好能承接图文卡、清单、表格。
```

适合结构：

```text
痛点 → 常见误区 → 判断方法 → 对应表 / 清单 → 收藏引导
```

---

### B站

核心任务：

```text
讲透逻辑
建立信任
沉淀系列
形成个人观点
```

推荐时长：

```text
3-8 分钟
```

表达要求：

```text
可以讲深，但仍然要说人话。
先用真实问题开场，再展开逻辑链。
不要一上来讲体系、模型、母线。
```

适合结构：

```text
真实困惑 → 现象拆解 → 原因 → 方法 → 案例 → 系列延展
```

---

## 四、谁在看

不要把用户写成“泛泛的大众”。

必须写清：

```text
年龄段
状态
正在害怕什么
已经尝试过什么
他为什么会停下来听你说
```

示例：TP-001 的受众不是“AI 学习者”，而是：

```text
22-35 岁，已经看过很多 AI 工具和教程的人。
他不是完全没接触 AI，而是越看越乱。
他怕落后，但又不知道先学哪个。
他收藏了很多工具，但真正用起来的不多。
```

---

## 五、我们要表达什么

每条内容必须区分：

```text
要表达什么
不是表达什么
```

示例：TP-001

要表达：

```text
先判断任务，再选择工具。
```

不是表达：

```text
AI 工具大全。
哪个工具最强。
你必须同时学会所有工具。
学会某个工具就能逆袭赚钱。
```

---

## 六、表达转译规则

HEL 可以有底层模型，但不能把底层模型直接拿到平台上讲。

### 禁止表述

```text
认知秩序重建
系统框架搭建
工具过载机制
信息入口失序
AI 时代的判断系统迁移
```

这些词可以用于内部推理，不适合直接放进普通平台内容。

### 转译方式

把概念转成用户当下能感受到的话。

| 内部说法 | 对外转译 |
|---|---|
| 认知秩序缺失 | 你越看越乱，不知道先做哪一步 |
| 工具过载 | 工具太多，每个都想学，反而没开始 |
| 判断系统 | 先想清楚你要解决什么 |
| 任务分类 | 内容、代码、流程，你现在卡在哪一类 |
| 主形式判断 | 这条内容是先抓情绪，还是先让人收藏 |

## 七、脚本前必须输出的结果

进入脚本节点前，必须先输出：

```text
1. 平台版本：抖音 / 小红书 / 视频号 / B站
2. 推荐时长：不是固定，而是按平台和内容任务决定
3. 观看者画像：谁在看，他现在什么状态
4. 核心表达：一句话说清
5. 非目标表达：这条内容不做什么
6. 人话转译：把底层逻辑改成平台语言
7. 内容作用：共鸣 / 收藏 / 理解 / 信任 / 转发 / 跟着操作
8. 主形式：图文 / 视频 / 一题多形
```

---

## 八、一题多形规则

不是每个触发点都要同时做图文和视频。

正确规则：

```text
一个触发点只强制确定一个主形式。
只有当它同时具备传播价值和收藏价值时，才做一题多形。
```

判断：

```text
情绪强、适合抓停留 → 视频优先
结构强、适合复用 → 图文优先
情绪强 + 方法强 → 视频主发，图文承接
```

## 九、TP-001 校验样例

触发点：

```text
AI 工具越多，我反而越不知道怎么开始。
```

校验结果：

```text
平台版本：抖音 / 小红书通用短视频测试版
推荐时长：30-45 秒
观看者：已经被 AI 工具搞焦虑、怕落后、想开始但不知道先学哪个的人
核心表达：先判断任务，再选择工具
非目标表达：不做工具大全，不做底层理论课，不制造逆袭焦虑
人话转译：你不是不会用 AI，是你还没想清楚现在要解决内容、代码，还是流程
内容作用：先共鸣，再给判断入口
主形式：V2 AI 生成型视频
衍生形式：小红书 5 页收藏卡
```

## 十、一句话标准

```text
先判断平台和人，再写内容；先把底层逻辑转成人话，再进入脚本。
```
