## 一、展现形式决策链

### 1.1 决策链总图

```
真实触发点（一句话）
    ↓
【第一关】第一性原理锚点
    │  这条内容到底在解释什么底层规律？
    │  没有锚点 → 不进决策，回观察层
    ↓
【第二关】内容的核心作用是什么？
    ├── 抓住情绪/共鸣 → 短视频优先（V1 实拍 或 V3 混合）
    ├── 讲清一个机制 → 结构图文（G1/G2）或桌面推演视频
    ├── 让人收藏复用 → 小红书多图卡片（G3 步骤/G4 对比）
    ├── 展示真实现场 → V1 实拍原生型
    ├── 建立个人信任 → 真人口播 / V3 混合增强
    ├── 展示工具操作 → 屏幕录制 / 桌面推演
    └── 做深度解释 → B站长视频 / 长图文
    ↓
【第三关】首发哪个平台？
    │  抖音：15-30s，钩子要强，3秒抓人
    │  小红书：可收藏，方法论，40-90s 或图文卡
    │  视频号：克制可信，不要过度情绪
    │  B站：逻辑完整，可长可深
    ↓
【第四关】形式匹配检查
    │  这个话题天然适合什么形式？
    │  图文 → 哪个结构模板？（G1反转/G2拆解/G3步骤/G4对比）
    │  视频 → 哪个生产模式？（V1实拍/V2纯AI/V3混合）
    │  视觉风格？（S1治愈/S2决策板/S3实景标注）
    ↓
【第五关】输出成品包
       图文：5-6页 + 封面 + 标题候选 + 标签
       视频：分镜 + 提示词 + 剪辑表 + 封面 + 标题候选 + 标签
```

### 1.2 形式选择的底层约束

不是"什么好看选什么"。是"什么形式能最直接地完成这个内容的核心任务"。

**三个检查：**
1. 这个形式能不能让我的核心判断被观众接收到？（如果没有画面，这句话还成立吗？）
2. 这个形式在这个平台上，是不是观众习惯的接收方式？（在刷流中看到一张长图文，会停吗？）
3. 我的素材够不够支撑这个形式？（V1 实拍需要去现场，V2 纯AI不需要）

**形式切换的触发条件：**
- 同一个话题做了3次，数据都没起色 → 换形式
- 评论里有"能不能出个图文版本"→ 做一题多形
- 你自己觉得"这个形式讲不清楚"→ 信你的直觉，换

### 1.3 图文和视频的互转规则

图文更适合：收藏复用、逻辑展开、步骤流程、对比判断
视频更适合：情绪共鸣、真实现场、信任建立、快速传播

一题多形的条件（两条都满足才做）：
- 既有传播价值（适合视频）
- 又有收藏价值（适合图文）

不同时满足 → 只做一个主形式。

## 二、反馈解读框架

### 2.1 反馈的本质

反馈不是数字。反馈是"你的判断和观众的接收之间有多大的差距"。

```
你的判断（我想传达什么）
        ↓  差距 = 反馈
观众的接收（他们实际感受到了什么）
```

**所以解读反馈不是"这个数字好不好"，是"我的判断被准确接收了吗？如果没，是哪个环节断了？"**

### 2.2 核心指标及各自的含义

| 指标 | 它回答的问题 | 低了意味着 | 高了意味着 |
|------|------------|-----------|-----------|
| 完播率 | 你的节奏和结构能不能让人跟到最后？ | 开头没抓住 / 中间散了 / 太长了 | 结构紧凑 / 情绪推到位了 |
| 收藏率 | 你的内容有没有"舍不得丢掉"的价值？ | 判断不够独特 / 没有可操作的东西 | 给了一个能用的方法或视角 |
| 评论内容 | 你触发了观众什么反应？ | 没说中 / 没有互动入口 | 戳中了 / 观众有话想说 |
| 点赞率 | 你的情绪浓度够吗？ | 太冷/太客观/没有"对"的感觉 | 有共鸣/有态度/有"对就是这样" |
| 转发率 | 观众愿意用自己的信誉推荐你吗？ | 不够好到值得说"你看这个" | 有面子价值/有反常识/"你先看看" |
| 转粉率 | 观众想持续看你的东西吗？ | 单条好但没建立期待 | 有了"这个人说的东西我想关注" |

### 2.3 低数据量下的反馈解读

头 20 条内容，数据量不够做统计判断。这时候的反馈重点是：

**不看绝对数字，看相对变化。**
- 比上一条好还是差？
- 哪条的评论最有料？
- 哪个话题你自己说的时候最有感觉？

**低量的有效信号：**
- 评论里有具体的追问 → 有效
- 收藏率明显比别的条高 → 有效
- 你自己录的时候觉得"这条对" → 有效（信任你的直觉）
- 有一个人私信你说"这条有用" → 比 100 个点赞值

### 2.4 反馈 → 判断的转化规则

```
数据信号 → 定位问题环节 → 归因到具体决策
```

不是"完播率低→内容不好"。是：
```
完播率低
    ↓ 哪个环节？
开头3秒留存正常？→ 问题在中段 → 节奏散了/没有转折
开头3秒留存也低？→ 问题在钩子 → 换开头
```

**常见连锁反应：**
- 开头留存低 → 完播率低 → 评论少（观众根本没看到你的核心判断）
- 收藏率高 + 评论少 → 有价值但没给互动入口
- 评论多 + 收藏低 → 情绪到了但没留下东西

## 三、迭代升级机制

### 3.1 三层迭代

```
第一层：单条迭代（从一条内容到下一条件）
    改一个变量 → 看数据变化 → 确认方向
    周期：每次发布后立即做

第二层：系列迭代（同一主题/同一形式的规律提取）
    5条以上同类型内容 → 提取共性模式 → 形成可复用规则
    周期：每10条或每月

第三层：系统迭代（反馈反向更新数字生命）
    数据积累 → 检验底层假设 → 更新 CORE 文件
    周期：每季度或重大发现时
```

### 3.2 单条迭代：变量控制法

每次只改一个变量。改了钩子就不要同时改时长、改平台、改形式。否则你不知道是哪个变量起效。

**可控制的变量清单：**
- 开头钩子（第一句话）
- 内容结构（先讲什么后讲什么）
- 视频时长
- 发布平台
- 封面/标题
- 是否有明确的行动引导（结尾）
- 是否有个人经历/具体时刻

**迭代记录格式：**
```
上一条：[标题] | [平台] | [形式] | 完播___% 收藏___%
变量改动：（只改了一个什么）
这一条结果：完播___% 收藏___%
判断：改动有效/无效/不确定
```

### 3.3 系列迭代：跨条目的规律提取

同一个话题做了 5 条以上，可以开始问：
- 这类话题的完播率整体比其他话题高还是低？
- 这类话题在哪个平台上数据最好？
- 这类话题的评论有没有共同的特点？（问问题 / 分享经历 / 反驳？）

同一个形式做了 5 条以上：
- 这种形式（比如 G1 反转图文）的收藏率是不是系统性高于 G2？
- 这种形式在哪个平台上最不被接受？

**当发现规律时：** 写入对应的 CORE 文件。比如"G1 反转图文在小红书上收藏率系统性高于 G2"→ 写入 12-图文成品形式库的规则更新。

### 3.4 系统迭代：反馈反向更新数字生命

这是最终闭环。当数据验证了一个判断，这个判断不只影响"下一条怎么做"，而是影响整个系统的规则。

**触发条件（满足任一即触发）：**
- 一个假设被 5 条以上的数据持续验证
- 一个规则在 3 条以上的内容中反复失效
- 评论中出现了一个全新的、之前未覆盖的用户需求

**回流路径：**
```
数据验证判断
    ↓
更新对应的 CORE 文件
    ├── 内容判断 → 01-原创内容生成根基
    ├── 形式规则 → 11-内容形式决策器 或 12-图文成品形式库
    ├── 平台策略 → 16-平台规则与发布调性表
    ├── 导演判断 → 10-视频导演判断原则
    └── 根基级判断 → ROOT-LOCK
    ↓
更新 STATUS-MANIFEST 日期
```
