# 07｜平台运营模块

版本：V3.3
状态：ACTIVE / EXECUTION-MODULE
归属：`09-内容与视频执行中台/`

> 本模块负责把成片放到具体平台。
> 详细内容见 `03-内容生成总链路.md`。

---

## 1. 模块定位

把成片适配到具体平台，不只是发布。

---

## 2. 平台基准

| 平台 | 用户状态 | 适合内容 | 推荐时长 | 风险 |
|------|----------|----------|----------|------|
| 抖音 | 快刷、被痛点抓住才停 | 强钩子、快节奏、冲突感 | 15-30秒 | 夸大、制造焦虑 |
| 小红书 | 搜索、收藏、做决策 | 清单、对比、避坑、经验 | 3-6图/40-90秒 | 空泛、信息密度低 |
| 视频号 | 熟人传播、信任感 | 克制、可信、稳定判断 | 30-90秒 | 过度夸张、过度营销 |
| B站 | 愿意听逻辑、看过程 | 深度拆解、逻辑链完整 | 3-8分钟 | 开头慢、结构散 |

---

## 3. 平台适配检查

```text
[ ] 当前平台是谁在看？
[ ] 这个平台用户为什么会停留？
[ ] 推荐时长是否合理？
[ ] 开头强度是否适合平台？
[ ] 有没有平台风险表达？
[ ] 是否仍然从底层判断出发？
```

---

## 4. 同一触发点的平台拆分

**触发点：** AI工具越多，我反而越不知道怎么开始。

| 平台 | 表达方式 |
|------|----------|
| 抖音 | "你不是不会用，是顺序错了"（15-30秒） |
| 小红书 | "选AI工具前，先问自己3个问题"（图文/40-90秒） |
| 视频号 | "先别急着追工具"（30-90秒） |
| B站 | "工具不是问题，判断入口才是问题"（3-8分钟） |

## 案例

### 成片
```text
"为什么传统行业的人总觉得再熬两年就好了"（45秒视频）
```

### 发布决策

**1. 首发平台：小红书**
```text
原因：内容偏方法/收藏价值
形式：视频+图文卡片
```

**2. 标题：**
```text
不是市场会变好，是你的旧模式回不来了
```

**3. 封面文案：**
```text
你等的"变好"，是哪种好？
```

**4. 正文：**
```text
视频看完，先问自己3个问题：
1. 客户会变多吗？
2. 价格会回升吗？
3. 还是只是不会更差？

评论区说说你行业的情况。
```

**5. 标签：**
```text
#传统行业转型 #商业判断 #职业发展 #认知升级
```

**6. 风险检查：**
```text
✓ 无夸大收益
✓ 无制造焦虑
✓ 无医疗/法律/金融承诺
✓ 无AI内容违规（真实观察，非AI生成内容）
```

**7. 复盘指标：**
```text
收藏率：目标>5%
评论话题：目标引发讨论
转粉率：目标>2%
```
