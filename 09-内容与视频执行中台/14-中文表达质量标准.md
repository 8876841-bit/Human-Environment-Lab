## 一、表达五条件——每条脚本过一遍

写完脚本后，问自己：

| 条件 | 检查问题 | 没过怎么办 |
|------|---------|-----------|
| 内容正确 | 每一个判断，有我的真实经历支撑吗？ | 把没有经历支撑的判断删掉或标注"推断" |
| 关系合宜 | 这条内容在对谁说？以什么身份？ | 写清楚"目标观众"一行——不写不准发 |
| 风格得体 | 这个语气放在这里合适吗？ | 念出声——不顺就改 |
| 文化可感 | 有没有一个词、一个画面是"只有中国人能get到"？ | 看看有没有四字节奏/成语/共同记忆可以嵌入 |
| 传播有效 | 观众关掉之后能记住一句话吗？ | 找出那句话，放在结尾或开头 |

## 二、短视频金标准——三条自检

```
快而不乱：节奏紧凑但逻辑不断
短而不浅：时间短但判断有深度
强而不假：态度鲜明但不表演
```

脚本自检三问：
1. 开头 3 秒有钩子吗？（快）
2. 中间有没有一个非我不可的判断？（短而不浅）
3. 结尾有没有真实情绪或选择？（强而不假）

## 三、五段结构模板

人类倩倩的口播脚本推荐结构：

```
【1】冲突开场（0-5秒）
指出一个常见误区 / 一个反常识判断
不是"大家好今天聊一下……"
→ "你以为是A，其实是B"

【2】结论前置（5-15秒）
先给最重要的判断——不等展开，先给
→ "最可怕的不是……而是……"

【3】三段展开（15-35秒）
原因 / 案例 / 方法
→ 每一个判断接一个具体的例子

【4】边界说明（35-42秒）
"不是所有情况都适用"——一句话划定边界
→ "这不是说……而是说……"

【5】行动收束（42-50秒）
一个可记忆的句子 + 观众能做的下一步
→ 不喊"点赞关注"，用一句值得被截图的判断收尾
```

## 四、修辞工具箱——最常用的4个

| 手法 | 什么时候用 | 例子 |
|------|----------|------|
| 对比 | 想让人重新看待一件熟悉的事 | "不是A，而是B" |
| 排比 | 想制造节奏和记忆点 | "一起扛、一起等、一起说再看看" |
| 设问 | 想控制观众的思考路径 | "你说这是无力回天吗？" |
| 叙事 | 想把一个抽象判断落地 | "我前几天去了一个供应商那里……" |

## 五、停顿与节奏——念出声才能判断

脚本写完后，标注停顿点：

```
//    = 短停顿（半拍）
///   = 长停顿（一拍）
[慢]  = 降速
[轻]  = 降低音量
```

示例：
```
// 那个笑，让我很不舒服 ///
[慢] 不是因为他在骗我 [轻] 是他真的不觉得这有什么不对
```

## 六、六维自评分

每条内容发布前，给自己打分（1-5）：

| 维度 | 自问 | 分 |
|------|------|---|
| 内容准确 | 每一个判断有真实经历支撑吗？ | _ |
| 结构逻辑 | 有清晰开头、展开和收束吗？ | _ |
| 语用得体 | 对象、场景和语气匹配吗？ | _ |
| 修辞表现 | 有没有一个能记住的句子？ | _ |
| 非言语 | 停顿、节奏标注了吗？ | _ |
| 媒介适配 | 平台时长和形式对吗？ | _ |

**底线：** 总分低于 20 分 → 不发。某一项是 1 分 → 不发。

## 七、AI表达的四个边界

每一条发布的内容，不管是自己写的还是AI辅助的，都检查：

1. 有没有未经核实的事实被包装成确定的事？
2. 如果有AI合成（声音/画面），需要标识吗？
3. 谁在承担这段话的责任？是我还是AI？
4. 这段话有没有"AI腔"——流畅但空洞？
