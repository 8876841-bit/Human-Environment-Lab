## 二、链路原则

### 原则1：从真实观察出发

```text
正确起点：真实生活、真实现场、真实行为、真实感受
错误起点：热点、同行模板、爆款标题

热点、同行、平台数据只能作为参考材料。
```

### 原则2：内核深，外显浅

```text
内部（数字生命）：底层逻辑、第一性原理、八条母线、系统规律
外部（用户）：能听懂的问题、能代入的状态、能理解的判断

禁止把内部术语直接端上平台。
```

### 原则3：成品导向

```text
目标输出：
✓ 可发布的图文成品包
✓ 可生成的视频执行包
✓ 可剪辑的成片包
✓ 可平台改写的发布包

非目标输出：
✗ 建议/方向/灵感/拍摄清单
```

### 原则4：平台前置

```text
正确顺序：先判断平台 → 再判断受众 → 再生成脚本
错误顺序：先写脚本 → 再硬套平台调性
```

### 原则5：发布不是结束

```text
闭环：发布 → 数据回收 → 反馈分析 → 规则更新 → 下一轮更强
```

## 三、各节点职责

| 节点 | 负责人 | 输入 | 输出 |
|------|--------|------|------|
| 信息采集 | HEL | 现实/同行/评论/趋势 | 原始材料包 |
| 内容分析 | 数字生命+HEL | 原始材料 | 内容机会判断 |
| 原创判断 | 数字生命 | 触发点+材料 | 原创锚点 |
| 选题判断 | 数字生命 | 原创锚点 | 可执行选题 |
| 平台前置校验 | 数字生命 | 选题+平台 | 平台判断 |
| 内容形式决策 | 数字生命 | 平台+受众 | 主形式 |
| 内容生成 | HEL | 决策结果 | 成品执行包 |
| 视频生成 | HEL | 内容包 | 素材执行包 |
| 视频制作 | HEL | 素材包 | 成片 |
| 平台运营 | HEL | 成片 | 发布+反馈 |
| 数据分析 | 数字生命+HEL | 数据 | 复盘报告 |
| 反馈回流 | 数字生命 | 复盘 | 规则更新 |

## 四、硬性禁令

```text
1. 不能从热点直接生成内容
2. 不能从同行模板直接改写
3. 不能没有真实触发就进入脚本
4. 不能没有第一性原理锚点就进入形式决策
5. 不能没有平台前置判断就写脚本
6. 不能把所有内容默认做成视频
7. 不能把所有内容默认一题多形
8. 不能把视频生成误认为视频制作
9. 不能把发布当成结束
10. 不能只看播放量判断内容有效
```
