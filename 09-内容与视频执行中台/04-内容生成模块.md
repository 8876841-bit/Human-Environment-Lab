# 04｜内容生成模块

版本：V3.3
状态：ACTIVE / EXECUTION-MODULE
归属：`09-内容与视频执行中台/`

> 本模块负责把分析结果转化为成品执行包。
> 详细内容见 `03-内容生成总链路.md`。

---

## 1. 模块定位

把内容分析结果转化为：**标题/脚本/图文/分镜/封面**的成品执行包。

---

## 2. 生成流程

```
选题 → 第一性原理锚点 → 平台校验 → 形式决策 → 标题生成 → 脚本生成 → 分镜/封面 → 发布检查
```

---

## 3. 形式决策表

| 核心作用 | 适合形式 |
|----------|----------|
| 抓情绪/共鸣 | 短视频/口播 |
| 讲清机制 | 结构图文/桌面推演/AI生成 |
| 收藏复用 | 小红书图文卡/清单/判断表 |
| 展示真实 | 实拍/混合增强型 |
| 建立信任 | 真人口播 |
| 深度解释 | B站/长图文 |

**一题多形规则：**
```text
每个触发点只强制一个主形式
只有同时具备传播+收藏价值才做一题多形
只需要情绪 → 视频优先
只需要收藏 → 图文优先
```

---

## 4. 输出标准

每次生成输出成品执行包：

```text
【成品执行包】

1. 内容定位
2. 目标用户
3. 核心判断
4. 标题候选（×3平台版本）
5. 开头钩子（×3版本）
6. 脚本/图文正文
7. 分镜脚本
8. 封面文案
9. 视觉说明/AI提示词
10. 平台适配说明
11. 发布前检查清单
12. 复盘指标建议
```

---

## 5. 人话转译

| 内部说法 | 对外表达 |
|---------|----------|
| 熵增/密度压力 | 越住越乱、被掏空 |
| 边界化失效 | 私人空间、没有个人生活 |
| 节能化 | 顺手、不费脑子 |
| 认知卸载 | 踩坑、精神寄托 |

**去AI味检测：**
```text
[ ] 有具体细节吗？
[ ] 有个人视角吗？
[ ] 有情绪的真实吗？
```

---

## 6. 发布前检查

```text
[ ] 标题说中痛点/好奇/反转？
[ ] 开头让用户觉得"说的是我"？
[ ] 有判断，不是只给信息？
[ ] 口语化，能直接朗读？
[ ] 从真实出发，不是套模板？
[ ] 平台版本适配？
[ ] 有风险表达？
[ ] 有互动引导？
[ ] 完成隐私/伦理检查？
```

---

## 7. 禁止事项

```text
✗ 为了平台感牺牲真实
✗ 为了高级感说人话障碍
✗ 把触发点强行包装成爆款
✗ 让AI生成没有现实来源的故事
✗ 只给建议，不给可执行成品包
✗ 跨过原创判断直接生成
✗ 所有平台共用一个脚本
```

---

## 8. 验收标准

```text
□ 能生成标题/钩子/脚本
□ 能判断图文vs视频vs一题多形
□ 能生成可执行成品包
□ 能适配不同平台
□ 能通过人话检测
```

---

## 9. 一句话定义

```text
内容生成模块 = 把真实触发点经过原创判断和平台适配，
生成包含标题、脚本、图文、分镜、封面的完整成品执行包。
```

## 案例

### 选题
```text
为什么传统行业的人总觉得"再熬两年就好了"？
```

### 生成过程

**1. 第一性原理锚点：**
```text
人在旧系统下行时，会把结构性变化误判成周期低谷
→ 用"再熬两年"逃避重构
```

**2. 平台选择：** 小红书（适合图文+收藏）

**3. 标题：**
```text
候选1：等市场变好，到底等的是什么？
候选2：不是市场会变好，是你的旧模式回不来了
候选3：你说的"变好"，到底是哪种好？
```

**4. 开头钩子：**
```text
你有没有听过这句话——"再等等，过了这两年就好了"
说这话的人，他说的"好"，到底是客户变多？价格回升？还是只是不会比现在更差？
```

**5. 图文结构（G1提问反转型）：**
```text
P1：你是不是也听过这句话
P2：他们说的"变好"是什么意思
P3：你以为的好 VS 实际的好
P4：为什么这种判断在骗你
P5：怎么判断这是周期问题还是结构问题
P6：先问自己3个问题
```

**6. 成品输出：**
```text
✓ 小红书图文版（6页）
✓ 封面文案
✓ 发布文案
✓ 标签建议
✓ 复盘指标：收藏率/评论话题
```
