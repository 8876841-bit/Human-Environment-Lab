## 一、图片提示词模板

### 结构公式
```
[主体] → [场景] → [主风格] → [媒介质感] → [构图/镜头] → [光线/色彩] → [情绪] → [细节] → [负面约束]
```

### 模板（直接套用）
```
一幅[横版/竖版]插画。[主体描述]，[正在做什么]，位于[场景环境]。
[主风格关键词]，[媒介质感]。构图采用[镜头/角度/景别]。
光线：[方向][色温][强度]。色调：[主色/辅色/点缀色]。
整体[情绪氛围]。[特殊细节要求]。
不要：[违禁元素1]、[违禁元素2]。
```

### 实例对照
```
❌ 差的：「一个小人在椅子上，暖色调」

✅ 好的：「一幅16:9横版插画。一个圆润的小人，深灰小西装，站在一张空椅子旁。
        米白墙裙的等候室。下午斜阳从左窗打在室内。
        日式手绘水彩，纸纹透出。平视中景。
        光线：暖色但已开始变薄，约4000K。
        色调：米白、淡黄、木色、柔灰、点缀深蓝。
        情绪：安静，在做一个决定。
        不要：任何文字、不要夸张表情、不要饱和度太高。」
```

## 二、视频提示词模板

### 结构：视觉层 + 运动层

```
视觉层 = 主体 + 环境 + 构图 + 光线 + 风格 + 材质（固定）
运动层 = 主体动作 + 环境运动 + 镜头运动 + 速度 + 节奏（变化）
```

### 模板
```
一段[时长]的[16:9/竖版]视频，24fps。[主体]，位于[场景]。
[构图和光线描述]。风格：[具体风格]。
画面中：[什么在动——主体动作/环境运动/镜头运动]。
运动速度：[快/慢/极慢]。节奏：[流畅/停顿/断奏]。
色调：[统一色调]。
```

### 实例对照
```
❌ 差的：「可爱的小人在一间房间里」

✅ 好的：「一段6秒的16:9视频，24fps。五个圆润的小人并排坐在长椅上，
        面向前方，身体纹丝不动。等候室全景，正面平视，严格对称构图。
        下午斜阳从左侧高窗打进，光柱里有灰尘极缓慢浮起——这是画面里唯一在动的东西。
        摄影机以极慢速度从全景微推向中央小人。
        画风：Wes Anderson对称+吉卜力水彩+Hopper的光。色调暖但褪色。
        速度：极慢推近，每秒钟不到1%。」
```

## 三、风格控制速查

### 8 个控制维度（不分平台都可用）

| 维度 | 控制什么 | 示例词汇 |
|------|---------|---------|
| 主体 | 谁/什么 | 小人/等候室/空椅子/号码牌 |
| 场景 | 在哪 | 等候室/工作室/客厅/厨房 |
| 媒介 | 用什么材质 | 手绘水彩/铅笔/油画/3D渲染/纸纹 |
| 构图 | 怎么看 | 全景/中景/特写/平视/俯视/对称 |
| 光线 | 什么光 | 斜阳/柔光/硬光/逆光/顶光/下午四点 |
| 色彩 | 什么色调 | 暖/冷/低饱和/褪色/黑白/单色 |
| 情绪 | 什么感觉 | 安静/孤独/温暖/紧张/荒诞/哀而不伤 |
| 细节 | 什么特殊 | 灰尘/窗帘角/纸纹/光柱/延音/留白 |

### 跨平台关键词兼容

| 平台 | 语法特色 | 技巧 |
|------|---------|------|
| ChatGPT/DALL-E | 自然语言，自动改写 | 把风格要求融入描述句，让它自己判定 |
| Midjourney | `--ar 16:9 --s 750 --no text` | 风格词用简写——"ghibli style"不要写长描述 |
| Stable Diffusion | `(word:1.3)` `[word]` | 重要词加权重，负向提示另列 |

## 四、提示词质量自检

每条提示词发出前，扫一遍：

| # | 检查 | 没过怎么办 |
|---|------|----------|
| 1 | 主体在第一句话吗？ | 把主体拉到第一句 |
| 2 | 有风格关键词吗？ | 至少一个媒介词（水彩/摄影/3D） |
| 3 | 有光线描述吗？ | 至少一句：从哪来+什么色+什么感觉 |
| 4 | 有负面约束吗？ | 至少一个"不要" |
| 5 | 和上一条是同一系列吗？ | 对照上一张的色调/光线/构图——保持一致 |
| 6 | 有16:9/横版/竖版标注吗？ | 补上画幅 |
