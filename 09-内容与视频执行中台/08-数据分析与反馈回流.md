# 08｜数据分析与反馈回流

版本：V3.3
状态：ACTIVE / EXECUTION-MODULE
归属：`09-内容与视频执行中台/`

> 本模块负责把反馈变成训练材料。
> 详细内容见 `03-内容生成总链路.md`。

---

## 1. 模块定位

```text
发布不是结束，反馈才是训练。
```

---

## 2. 核心指标

| 指标 | 说明 | 优先级 |
|------|------|--------|
| 完播率 | 完整看完的比例 | 高 |
| 收藏 | 复用价值 | 高 |
| 评论 | 真实反馈 | 高 |
| 点赞 | 用户认可 | 高 |
| 转发 | 传播价值 | 中 |
| 转粉 | 关注转化 | 中 |

---

## 3. 诊断规则

| 数据信号 | 诊断 | 应对 |
|----------|------|------|
| 完播率低 | 开头问题/节奏散 | 重写Hook |
| 收藏率高 | 有实用价值 | 强化方法类内容 |
| 评论强 | 戳中真实情绪 | 做系列 |
| 评论有新抱怨 | 发现新痛点 | 生成新选题 |
| 转粉率高 | 建立信任 | 强化人设 |

---

```text
验证了什么判断
推翻了什么假设
暴露了什么新需求
更新了什么规则
沉淀了什么资产
```

## 案例

### 发布内容
```text
小红书："不是市场会变好，是你的旧模式回不来了"（45秒视频）
```

### 数据回收（3天后）

```text
播放：5000
完播率：42%
点赞：180
收藏：120（收藏率2.4%）
评论：35
转发：15
```

### 复盘

**1. 数据诊断：**
```text
✓ 完播率42%：中等，说明开头有机会
✓ 收藏率2.4%：偏低，内容偏情绪而非方法
✓ 评论话题：有人问"怎么判断是结构还是周期"
```

**2. 评论分析：**
```text
高价值评论（3条）：
- "我就是那个总说再等等的人"
- "怎么判断是周期低谷还是结构变化？"
- "建材行业是不是这种情况？"

→ 新选题信号：如何判断结构vs周期
→ 新需求：具体判断工具/方法
```

**3. 回流内容：**
```text
验证：情绪共鸣到位，但方法不够具体
更新：下次加判断工具/具体问题
资产：选题库+1，"如何判断结构vs周期"
规则：情绪类内容后续必须跟方法承接
```

**4. 下一轮：**
```text
选题：怎么判断你行业的问题是周期问题还是结构问题？
形式：图文清单（小红书）
优先级：A
```
