# 03｜内容分析模块

版本：V3.3
状态：ACTIVE / EXECUTION-MODULE
归属：`09-内容与视频执行中台/`

> 本模块详细内容为数字生命分析提供框架。
> 详细内容见 `03-内容生成总链路.md`。

---

## 1. 模块定位

判断：这个触发点是否值得进入生成链路。

---

## 2. 分析链路

```
原始材料（同行内容/评论/趋势/观察）
    ↓
数字生命分析
    ↓
内容机会判断 + 原创判断锚点
    ↓
选题判断（等级A/B/C/D）
    ↓
进入生成 / 暂存 / 废弃
```

---

## 3. 分析对象

### 3.1 同行内容分析

```text
分析：定位/表达/结构/有效性/差异化角度
禁止：直接抄选题、模仿结构、只看表面
```

### 3.2 爆款结构拆解

```text
分析：钩子/情绪路径/公式/核心观点/系列化可能
禁止：只抄标题、忽略背景时机
```

### 3.3 用户评论区分析

```text
分析：抱怨/追问/误解/认同/真实需求/认知缺口
禁止：只看互动数量、把情绪当需求
```

### 3.4 平台规则分析

```text
分析：推荐机制/停留逻辑/节奏要求/审核边界/AI标识
平台调性基准：
- 抖音：快/强/直接
- 小红书：具体/可收藏
- 视频号：克制/可信
- B站：深度/逻辑
```

### 3.5 内容角度判断

```text
标准：需求×行为×环境×系统
必须关联母线：空间秩序/材料感官/工艺机制/案例探家/AI认知秩序/真实生活转型/商业服务/意义与文明
```

### 3.6 选题价值判断

```text
等级：
A：强触发+强结构+强平台表达 → 优先制作
B：有触发，但需打磨
C：内部研究/等证据
D：暂不执行
```

---

## 4. 输出标准

每次分析必须输出：

```text
1. 真实触发点
2. 关联母线
3. 用户真实感受
4. 平台适配建议
5. 内容价值判断
6. 选题等级（A/B/C/D）
7. 形式建议
8. 证据缺口
9. 是否值得进入生成
10. 风险点
```

---

## 5. 分析检查清单

```text
[ ] 有真实来源？
[ ] 属于哪条母线？
[ ] 回答了"需求×行为×环境×系统"哪几项？
[ ] 用户为什么会停留？
[ ] 适合哪个平台？
[ ] 有差异化角度？
[ ] 证据充分？
[ ] 有风险表达？
[ ] 值得进入生成？
```

---

## 6. 禁止事项

```text
✗ 只看别人什么火
✗ 把热点直接当选题
✗ 脱离真实观察
✗ 只用平台数据解释内容价值
✗ 把评论只当互动指标
✗ 凭感觉判断平台规则
✗ 把同行内容当成正确标准
```

---

## 7. 验收标准

```text
模块验收：
□ 能判断"值得做"和"不值得做"
□ 能识别原创角度
□ 能过滤热点搬运
□ 能给出选题等级
□ 能识别平台适配
```

---

## 8. 一句话定义

```text
内容分析模块 = 从同行、评论、趋势、观察中提炼真实需求，
过滤无效选题，确保进入生成的内容都有原创根基。
```

---

## 案例

### 触发点
```text
建材人觉得"过两年市场会变好"
```

### 分析过程
```text
1. 同行分析：大部分内容是政策解读/悲观预测/市场数据
2. 评论分析：有人说"等等看"，有人问"什么样的好"
3. 原创角度：把"变好"拆解——客户变多？价格回升？只是不会更差？
4. 母线关联：真实生活转型/商业服务
5. 用户感受：不是真的乐观，是逃避重构的借口
```

### 结论
```text
选题：为什么传统行业的人总觉得"再熬两年就好了"？
等级：B（有触发，但证据不足）
下一步：收集5个建材人原话验证
```
