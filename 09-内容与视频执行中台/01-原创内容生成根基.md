## 2. 调用的原始根基

### 2.1 总母线

```text
通过环境观察人：
人在宇宙熵增的大背景下，持续创造局部秩序。
```

调用说明：

内容不是单纯讲装修、AI、工具、商业、视频技巧或平台运营。

内容真正观察的是：

```text
人在具体环境中如何建立、维持、扩张秩序；
以及秩序如何再次失效、变形或被重新组织。
```

---

### 2.2 原创选题公式

```text
需求 × 行为 × 环境 × 系统 = 原创选题
```

调用说明：

每次进入内容生成前，数字生命必须先判断：

```text
人在追求什么？        → 需求
人产生了什么行为？    → 行为
环境如何影响行为？    → 环境
这个行为发生在哪个系统里？ → 系统
```

如果一个选题只剩热点、标题、形式、爆款模板，而看不到这四项，它不能直接进入 HEL 生成。

### 2.4 真实观察优先


原创源头必须优先来自真实观察、真实困惑、真实反馈、真实案例和真实行动。

### 2.5 AI 与人的分工

```text
AI / 数字生命给骨架。
有形的我给灵魂。
```

调用说明：

数字生命负责结构、逻辑、拆解、连接、推演、生成、批量化和工具调用。

有形的我负责真实经历、现场感受、审美判断、核心态度、价值边界、最终选择和现实后果。

**拍摄现场的分工细化（来自 2026-06-17 深度分析）：**

```text
AI准备 = 可能性地图（方向 + 核心判断 + 共鸣点）
人发挥 = 现场导航（选哪个方向、用什么语气、加入什么具体细节和真实情绪）
```

不是台词，是地图。人带地图去现场，根据实际情况决定走哪条路、在哪里停下来。

**拍摄前准备节点操作：**
1. 输入案例基本信息（户型、业主情况、特殊需求、已有判断）
2. AI输出：今天可说的3-5个方向、每个方向的核心观点、可能引发共鸣的点
3. 人带这张"地图"去现场
4. 到了现场，看实际触发哪个方向就讲哪个，不需要按顺序、不需要全讲

**内容生成的活人感注入（来自 2026-06-17 深度分析）：**

生成内容之前，调取对应话题的活人感随想 → 提取一个真实的具体时刻 → 注入内容开头或关键节点。

注入节点：
- 一个具体的时刻（时间+地点+真实画面）
- 一个你还不确定的困惑
- 一个你有立场且知道有人会不认同的判断
- 一个你做过的错误判断

极简操作：每一条内容里至少有一个画面——一个你在真实世界里亲眼看到、亲耳听到、亲身感受到的东西。用那个画面做内容的锚。

### 2.6 反馈闭环

```text
观察 → 选题 → 脚本 → 画面 → 剪辑 → 发布 → 数据 → 复盘 → 再观察
```

调用说明：

平台反馈、用户反馈、评论反馈、咨询反馈、数据反馈，都要反向更新数字生命的判断，而不是只优化表层技巧。

### 2.7 内容价值标准（来自 2026-06-17 深度分析）

**高级内容的定义：解析 + 建立判断力。不是转发，不是点评。**

三级区别：
```text
低级 = 给出内容（"看这个"）
中级 = 给出内容 + 你的判断（"看这个，好在X"）
高级 = 给出内容 + 你的判断 + 教会对方判断的方法（"好在X、Y、Z。以后你看的时候，也看这三个点"）
```

高级感不来自形式的复杂，来自**判断密度的提升**——你说的每个点，都是对方自己看不出来、听完觉得"原来是这样"的。

调用说明：
- "夸夸设计"纳入正式内容形式：一张图/一段视频 + 声音 + 2-3个具体解析点 + 结尾判断力小结
- 每条内容的最终判断标准：观众看完后，对行业里某件事的判断力有没有提升？不只是知道了什么，而是学会了自己怎么判断。

### 2.8 行业判断工具：周期 vs 结构变化（来自 2026-06-17 深度分析）

调用说明：

区分方法：**底层逻辑变了吗？**
- 没变 → 周期变化，会回来
- 变了 → 结构变化，不会回来

建材行业是结构变化。遇到"等X年就好了"的判断，先检验底层逻辑是否已变。凡是结构变化，不能等，只能适应或推动。

### 2.9 感知开关与内容传播原则（来自 2026-06-18 深度分析）

**核心规律：呈现方式决定感知类别。**

```text
具体呈现（一张脸、一个名字、一个具体时刻）
→ 触发感受模式 → 道德判断、情绪反应、行动意愿

统计呈现（一个数字、一个趋势、一个类别）
→ 触发认知模式 → 分析判断、知识获取、认知距离
```

**调用说明——内容生成时的选择：**

想让观众"感受到"一个问题 → 给一个具体的人、具体的时刻、具体的一句话。  
想让观众"理解到"一个规律 → 给趋势、给数据、给结构。

**讲行业问题的原则：**
- 不讲"这个行业存在普遍问题"
- 讲"上周二下午，我站在那个客户的厨房里，她拿着报价单问我，这8000块是什么"

**造势原理：**
势 = 同一方向上具体化感受的持续叠加。用具体造势，不用抽象造势。一百条"讲一个人"的内容叠在一起，大于一条"讲很多人"的内容。

**校验问题（生成每条内容时自问）：**
- 这条内容里，有一个具体的人吗？有一个具体的时刻吗？
- 如果没有，它可能只有认知价值，没有感受价值——这是你想要的吗？

### 2.10 认知双路径（来自 2026-06-18 深度分析）

**上行找规律，下行做决策。两条都走才是完整思考。**

上行路径（从具体到普遍）：微观 → 宏观 → 客观  
下行路径（从普遍到具体）：第一性原理 → 底层逻辑 → 具体决策

操作原则：每次形成一个判断时，两个方向都走过。只上行不下行 → 有洞察没行动。只下行不上行 → 有行动没根基。
