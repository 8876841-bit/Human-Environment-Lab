# 13｜图文形式统一决策表

版本：V1.0
状态：CORE
来源：合并 25-图文形式库 + 12-图文成品形式库 + 08-小红书多图模板

> 一条触发点 → 判断母线和信任类型 → 匹配结构和视觉 → 锁定平台页数 → 输出成品包。  
> 不再需要翻三个文件。一张表走完。

---

## 一、决策链路

```
真实触发点
    ↓
【第1步】属于哪条母线？要给观众建立什么信任？
    → 查表A：母线 × 信任类型 → 图文形式
    ↓
【第2步】用什么结构讲？用什么视觉风格？
    → 查表B：图文形式 → 结构模板（G1-G4）+ 视觉模板（S1-S3）
    ↓
【第3步】首发哪个平台？几页？什么节奏？
    → 查表C：平台 → 页数 + 节奏 + 封面规则
    ↓
输出：图文成品包
```

## 四、表C｜平台 → 页数 + 节奏 + 封面规则

| 平台 | 常见页数 | 阅读节奏 | 封面要求 |
|------|---------|---------|---------|
| 小红书 | 5-7页 | 逐页滑动，每页一个重点 | 大字提问 + 高颜值画面 |
| 抖音图文 | 3-5页 | 快速翻页，每页3秒 | 强钩子 + 冲突感 |
| 视频号图文 | 3-5页 | 克制，可配长文字 | 稳重封面 + 可信感 |
| B站专栏 | 不限 | 深度阅读，逻辑完整 | 信息密度高的封面 |

**跨平台规则：** 小红书定主版本 → 抖音精简到3-5页（去细节，留钩子和判断）→ 视频号保留克制版本 → B站可选长图文版本。

## 五、结构模板速查（G1-G4）

| 结构 | 一句话 | 适用场景 |
|------|--------|---------|
| G1 提问反转 | "你以为是A，其实是B" | 有反常识判断时 |
| G2 场景拆解 | "你看这个场景，它说明了什么" | 有真实场景或案例时 |
| G3 步骤流程 | "第一步→第二步→第三步" | 有可操作的方法时 |
| G4 前后对比 | "以前这样 vs 现在这样" | 有对照、有改变时 |

## 六、视觉模板速查（S1-S3）

| 视觉 | 一句话 | 风险提示 |
|------|--------|---------|
| S1 治愈插画 | 手绘水彩，温暖低饱和，单女主 | 不能过度唯美 |
| S2 中性决策板 | 白底深灰字，墨绿强调，一页一个判断 | 不能像冰冷PPT |
| S3 实景标注 | 实拍图+标注，不改变真实比例 | 不做过度美化 |

```
       次发抖音：精简到4页
```
