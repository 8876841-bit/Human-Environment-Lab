# 06｜视频制作模块

## 1. 模块定位

视频制作模块负责把内容和视频生成方案转成可剪辑、可检查、可发布的成片执行方案。

它不是只负责剪辑。

它负责：

```text
剪辑节奏
镜头排序
字幕设计
转场逻辑
特效控制
音效与 BGM
卡点设计
成片质检
发布版本检查
```

---

## 2. 成片检查

每条视频发布前必须检查：

```text
前三秒是否清楚
核心判断是否出现太晚
镜头是否服务内容
字幕是否增加理解
音乐是否压过信息
画面是否过度包装
结尾是否有反馈入口
平台版本是否适配
```

---

## 3. 输出包

```text
1. 剪辑结构
2. 镜头顺序
3. 字幕规则
4. 转场说明
5. 音效 / BGM 说明
6. 成片节奏建议
7. 平台版本差异
8. 发布前质检清单
```

---

## 4. 禁止事项

```text
不要为了剪辑感牺牲信息清楚。
不要为了高级感牺牲用户理解。
不要无意义堆特效。
不要让剪辑变成内容的遮羞布。
```
