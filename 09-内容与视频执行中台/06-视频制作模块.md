# 06｜视频制作模块

版本：V3.3
状态：ACTIVE / EXECUTION-MODULE
归属：`09-内容与视频执行中台/`

> 本模块负责把素材做成成片。
> 详细内容见 `03-内容生成总链路.md`。

---

## 1. 模块定位

把素材变成可发布的成片。

**核心区分：**
```text
视频生成 = 生产素材和镜头
视频制作（当前）= 把素材做成成片
```

---

## 2. 制作流程

```
素材接收 → 素材筛选 → 镜头排序 → 粗剪 → 精剪 → 质检 → 发布
```

---

## 3. 制作检查

```text
[ ] 素材是否完整对齐分镜？
[ ] 前3秒是否抓住注意力？
[ ] 核心信息是否出现太晚？
[ ] 音乐是否压过信息？
[ ] 画面是否过度包装？
[ ] 字幕是否清晰无错字？
[ ] 时长是否合适？
[ ] 比例是否正确？
```

---

## 4. 成片执行包

每次视频制作输出：

```text
【成片执行包】

1. 成片文件
2. 各平台版本（比例/时长）
3. 字幕文件（SRT/ASS）
4. 封面图
5. 标题候选
6. 平台文案
7. 标签
8. 发布时间建议
9. 质检报告
```

---

## 5. 禁止事项

```text
✗ 为了剪辑感牺牲信息清楚
✗ 无意义堆特效
✗ 让剪辑变成内容的遮羞布
✗ 过度包装掩盖内容问题
```

---

## 6. 验收标准

```text
□ 能把素材剪辑成完整成片
□ 能控制节奏服务于内容
□ 能完成各平台版本适配
□ 能通过质检检查
```

---

## 7. 一句话定义

```text
视频制作模块 = 把视频生成模块提供的素材包，
经过剪辑、字幕、音效、BGM，输出各平台可发布的成片。
```

---

## 案例

### 素材
```text
V2生成的8个镜头 + 旁白 + BGM方向
```

### 制作过程

**1. 素材筛选：**
```text
检查8个镜头：
✓ 镜头1-3（痛点段）使用
✓ 镜头4-5（转折段）使用
✓ 镜头6-7（治愈段）使用
✓ 镜头8（收束）使用
全部素材对齐，无需替换
```

**2. 节奏设计：**
```text
0-15s：痛点段 → 快切、短镜头、压抑钢琴
15-25s：转折 → 镜头定格、BGM切换
25-35s：治愈 → 慢切、长镜头、温暖钢琴
35-45s：收束 → 轻切、留白、互动问题
```

**3. 字幕设计：**
```text
花字1（8s）："再等等就好"
花字2（18s）："你以为的好"
花字3（25s）："实际的好"
花字4（38s）："先问自己3个问题"
```

**4. 成片输出：**
```text
✓ 45秒成片.mp4
✓ 字幕.srt
✓ 封面图
✓ 小红书版本（1:1）
✓ 抖音版本（9:16）
```
