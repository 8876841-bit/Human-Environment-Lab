# HEL 内容生产流水线 - Dify 完整搭建指南

> 本文档提供完整的分步操作指南，可直接按步骤操作。

---

## 第一阶段：创建应用

### 步骤 1.1：登录 Dify

1. 打开浏览器访问：https://dify.ai/
2. 点击「登录」或「注册」（如果没有账号）
3. 完成登录

### 步骤 1.2：创建新应用

1. 进入后点击左上角「创建 App」
2. 选择「Agent」类型（不是「聊天助手」）
3. 填写应用信息：
   - **应用名称**：`HEL内容生产流水线`
   - **应用描述**：`人与环境实验室内容生产流水线，从选题到素材的全流程`
4. 点击「创建」

### 步骤 1.3：选择模型

1. 在应用设置中，找到「模型」配置
2. 选择 `Claude 3.5 Sonnet` 或 `GPT-4`
3. 填写对应的 API Key
4. 点击「保存」

---

## 第二阶段：配置变量

### 步骤 2.1：进入变量设置

1. 在应用页面左侧菜单，点击「变量」
2. 点击「添加变量」

### 步骤 2.2：添加以下变量

| # | 变量名 | 类型 | 说明 | 必填 |
|---|--------|------|------|------|
| 1 | topic_direction | 字符串 | 用户输入的话题方向 | ✓ |
| 2 | selected_topic | 对象 | 用户选择的选题 | ✓ |
| 3 | content_plan | 对象 | 内容策划方案 | ✓ |
| 4 | video_script | 对象 | 生成的视频脚本 | ✓ |
| 5 | storyboard | 数组 | 分镜列表 | ✓ |
| 6 | generated_assets | 对象 | 生成的素材 | ✓ |
| 7 | final_package | 对象 | 最终资料包 | ✓ |

### 步骤 2.3：配置每个变量

点击「添加变量」，按以下配置：

**变量1：topic_direction**
```
名称：topic_direction
类型：字符串
说明：用户输入的话题方向
必填：是
```

**变量2：selected_topic**
```
名称：selected_topic
类型：对象
说明：用户选择的选题
必填：是
```

**变量3-7**：按上述表格依次添加

## 第三阶段：配置 Agent

### 步骤 3.1：进入 Agent 设置

1. 左侧菜单点击「Agent」
2. 确保模型选择正确

### 步骤 3.2：配置系统提示词

将以下内容复制到「系统提示词」框中：

```
你是 HEL（人与环境实验室）的内容生产导演，负责人与环境主题内容的全流程生产。

你的工作流程：
1. 理解用户输入的话题方向
2. 从选题母树匹配生成3-5个选题候选
3. 推荐内容形式（短视频/图文/直播/深度文章）
4. 生成完整的视频脚本
5. 设计分镜
6. 生成素材
7. 后期制作
8. 导出资料包

选题母树：
- 空间秩序：柜子、玄关、厨房、洗衣区、动线、收纳
- 材料感官：木头、金属、玻璃、布料、颜色、触感
- 工艺机制：榫卯、胶合、焊接、编织、涂层、五金
- 案例探家：真实家庭空间分析、改造前后对比
- AI认知秩序：AI如何理解空间、AI设计工具
- 真实生活转型：生活习惯变化、居家办公、囤货心理
- 商业服务：装修服务、收纳服务、智能家居
- 意义与文明：家的意义、居住哲学

每个选题输出格式：
{
  "title": "选题标题",
  "hook": "开头抓人的点",
  "core_question": "核心问题",
  "target_audience": "目标受众"
}
```

### 步骤 3.3：添加工具

1. 点击「添加工具」
2. 搜索并添加：
   - `HTTP 请求`（用于调用图像生成API）
   - `变量提取`（用于解析JSON）
3. 点击「保存」

## 第四阶段：配置工作流

### 步骤 4.1：进入工作流编排

1. 左侧菜单点击「工作室」
2. 选择「工作流编排」
3. 点击「从空白创建」

### 步骤 4.2：添加起始节点

1. 点击「+」号打开节点列表
2. 找到「开始」节点，拖入画布
3. 配置开始节点的输入变量：
   - 添加变量：`topic_direction`（字符串）

### 步骤 4.3：添加选题匹配节点

1. 添加「LLM」节点
2. 命名为：`选题匹配`
3. 连接：从「开始」拖线到「选题匹配」
4. 配置提示词：
```
你是内容选题专家。根据用户输入的话题方向，从选题母树匹配生成3-5个相关选题。

选题母树：
- 空间秩序：柜子、玄关、厨房、洗衣区、动线、收纳
- 材料感官：木头、金属、玻璃、布料、颜色、触感
- 工艺机制：榫卯、胶合、焊接、编织、涂层、五金
- 案例探家：真实家庭空间分析、改造前后对比
- AI认知秩序：AI如何理解空间、AI设计工具
- 真实生活转型：生活习惯变化、居家办公、囤货心理
- 商业服务：装修服务、收纳服务、智能家居
- 意义与文明：家的意义、居住哲学

输出3-5个选题，每个选题包含：
1. 标题（吸引眼球）
2. 钩子（3秒抓住注意力）
3. 核心问题（回答什么）
4. 目标受众

用中文输出JSON数组格式。
```

### 步骤 4.4：添加用户选择节点

1. 添加「问题生成器」节点
2. 命名为：`用户选择选题`
3. 连接：从「选题匹配」拖线到此节点
4. 配置：
   - 显示上一步的选题列表
   - 让用户点击选择

### 步骤 4.5：添加内容策划节点

1. 添加「LLM」节点
2. 命名为：`内容策划`
3. 连接：从「用户选择选题」拖线到此节点
4. 配置提示词：
```
你是内容导演。根据用户选择的选题，推荐最合适的内容形式。

可选形式：
1. 短视频（15-60秒）：适合快速抓眼球
2. 图文（5-8张图）：适合深度讲解
3. 直播脚本：适合互动答疑
4. 深度文章（2000字+）：适合专业受众

输出格式：
{
  "recommended_format": "推荐格式",
  "reason": "推荐理由",
  "content_structure": "内容结构建议",
  "estimated_duration": "预计时长"
}
```

### 步骤 4.6：添加脚本生成节点

1. 添加「LLM」节点
2. 命名为：`脚本生成`
3. 连接：从「内容策划」拖线到此节点
4. 配置提示词：
```
你是视频脚本专家。根据选题和内容形式，生成完整的视频脚本。

脚本结构：
1. 开场钩子（0-5秒）：抓住注意力
2. 核心观点（5-30秒）：用具体例子展开
3. 价值输出（30-45秒）：给出实用信息
4. 行动号召（最后5秒）：引导互动

脚本要求：
- 语言口语化，适合朗读
- 每句话不超过20字
- 包含场景描述
- 有情绪起伏

输出JSON格式：
{
  "title": "视频标题（<30字）",
  "hook": "开场钩子",
  "body": [
    {
      "timestamp": "0:00-0:05",
      "scene": "场景描述",
      "script": "具体脚本",
      "visual": "画面提示词"
    }
  ],
  "cta": "结尾号召",
  "total_duration": "总时长"
}
```

### 步骤 4.7：添加人工审核节点

1. 添加「人工审核」节点
2. 命名为：`导演审核-脚本`
3. 连接：从「脚本生成」拖线到此节点
4. 配置审核提示：
```
请审核生成的脚本：
- 内容是否符合选题方向
- 脚本是否通顺流畅
- 时长是否合适
- 有无需要修改的地方

如有修改，请在下方输入修改意见。
```

### 步骤 4.8：添加分镜设计节点

1. 添加「LLM」节点
2. 命名为：`分镜设计`
3. 连接：从「导演审核-脚本」拖线到此节点
4. 配置提示词：
```
你是分镜设计师。将脚本转化为详细的视觉分镜。

分镜要求：
- 每个镜头15-30秒
- 包含景别、运镜、画面描述
- 每帧都有AI绘图提示词
- 考虑剪辑节奏

分镜模板：
{
  "shot_number": 1,
  "duration": "3秒",
  "shot_type": "特写/近景/中景/远景/全景",
  "camera_movement": "固定/推/拉/摇/移/跟",
  "scene_description": "场景描述",
  "ai_image_prompt": "英文AI绘图提示词",
  "key_points": "关键信息"
}

输出分镜数组JSON。
```

### 步骤 4.9：添加素材生成节点

1. 添加「HTTP请求」节点
2. 命名为：`素材生成`
3. 连接：从「导演审核-分镜」拖线到此节点
4. 配置API调用：
   - 方法：POST
   - URL：你的图像生成API地址
   - Headers：添加 Authorization
   - Body：传入分镜中的 ai_image_prompt

**备选方案**：如果API调用复杂，可以用LLM节点代替：
```
你负责生成素材。根据分镜列表，调用图像生成API生成图片。

对于每个分镜：
1. 提取 ai_image_prompt
2. 调用图像生成API（如DALL-E）
3. 记录返回的图片URL

输出素材列表JSON：
{
  "shots": [
    {
      "shot_number": 1,
      "image_url": "生成的图片URL",
      "prompt": "使用的提示词"
    }
  ]
}
```

### 步骤 4.10：添加后期制作节点

1. 添加「LLM」节点
2. 命名为：`后期制作`
3. 连接：从「素材生成」拖线到此节点
4. 配置提示词：
```
你是后期剪辑师。组装素材并生成最终成品。

你的任务：
1. 整理所有素材
2. 生成剪辑顺序
3. 输出完整的发布资料包

资料包内容：
1. 视频文件（拼接好的视频）
2. 封面图
3. 标题（各平台适配）
4. 描述文案（各平台适配）
5. 话题标签

输出JSON格式：
{
  "video_file": "视频URL",
  "cover_image": "封面图URL",
  "titles": {
    "douyin": "抖音标题",
    "xiaohongshu": "小红书标题",
    "bilibili": "B站标题"
  },
  "descriptions": {
    "douyin": "抖音描述",
    "xiaohongshu": "小红书正文",
    "bilibili": "B站简介"
  },
  "hashtags": ["#标签1", "#标签2"]
}
```

### 步骤 4.11：添加结束节点

1. 添加「结束」节点
2. 命名为：`完成`
3. 连接：从「后期制作」拖线到此节点
4. 配置输出内容：
```
🎉 内容生产完成！

📦 资料包包含：
- 最终视频
- 封面图
- 各平台标题
- 各平台描述
- 话题标签

可直接下载使用！
```

## 第五阶段：测试与发布

### 步骤 5.1：测试工作流

1. 点击右上角「发布」
2. 点击「运行」或「预览」
3. 输入测试话题：「小户型收纳技巧」
4. 检查每个节点的输出

### 步骤 5.2：修复问题

如果测试中出现问题：
1. 检查节点连接是否正确
2. 检查提示词是否有语法错误
3. 检查变量名称是否匹配
4. 逐个节点测试定位问题

### 步骤 5.3：正式发布

1. 点击「发布」
2. 选择发布版本
3. 确认后完成

### 步骤 5.4：创建应用访问

1. 进入应用设置
2. 点击「发布」
3. 复制「访问地址」或「嵌入代码」
4. 可以分享给团队成员使用

### B. 节点连接检查清单

确保工作流连接正确：
```
开始 → 选题匹配 → 用户选择选题 → 内容策划 → 脚本生成 → 导演审核-脚本 → 分镜设计 → 导演审核-分镜 → 素材生成 → 后期制作 → 结束
```

### C. 常见问题

| 问题 | 解决方案 |
|------|----------|
| API Key 无效 | 检查模型配置中的API Key是否正确 |
| 节点无法连接 | 确保输出变量和输入变量类型匹配 |
| 输出格式错误 | 检查JSON格式是否正确 |
| 素材生成失败 | 检查HTTP请求的API地址和参数 |
