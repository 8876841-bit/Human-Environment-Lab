# HEL 内容生长中枢 - Dify MVP v1 搭建指南

> 简化版第一版：核心流程 + 最少节点，快速跑通全流程。

---

## 一、MVP 目标

搭建一个最小可用流水线：
```
用户输入话题 → 生成选题 → 用户选择 → 生成脚本 → 用户审核 → 交付资料包
```

核心验证点：
1. 选题匹配是否准确
2. 脚本生成是否可用
3. 用户审核流程是否顺畅

---

## 二、Dify 账号准备

### 2.1 注册/登录

1. 打开 [https://dify.ai/](https://dify.ai/)
2. 点击「登录」或「注册」
3. 完成认证

### 2.2 创建应用

1. 点击左上角「创建 App」
2. 选择「聊天助手」或「Agent」（建议选「Agent」，后续扩展到工作流更方便）
3. 填写：
   - **应用名称**：`HEL内容生长中枢`
   - **应用描述**：`人与环境实验室内容生产核心，从选题到交付的完整流水线`
4. 点击「创建」

### 2.3 配置模型

1. 进入应用后，点击左侧「设置」
2. 选择模型供应商：
   - **推荐：Claude 3.5 Sonnet**（质量高）
   - **备选：DeepSeek Chat**（便宜）
   - **备选：GPT-4o**（稳定）
3. 填入 API Key
4. 点击「保存」

---

## 三、配置变量

在「变量」页面，点击「添加变量」，依次添加：

| # | 变量名 | 类型 | 说明 | 必填 |
|---|--------|------|------|------|
| 1 | `topic_direction` | 字符串 | 用户输入的话题方向 | ✓ |
| 2 | `selected_topic` | 对象 | 用户选择的选题 | ✓ |
| 3 | `content_plan` | 对象 | 内容策划方案 | ✓ |
| 4 | `video_script` | 对象 | 生成的视频脚本 | ✓ |
| 5 | `final_package` | 对象 | 最终资料包 | ✓ |

### 添加方法

1. 点击「添加变量」
2. 填写名称（如 `topic_direction`）
3. 选择类型（字符串/对象/数组）
4. 填写说明
5. 开启「必填」
6. 点击保存

---

## 四、配置 Agent 提示词

在「Agent」页面，配置系统提示词：

### 4.1 系统提示词

复制以下内容到「系统提示词」框：

```
你是 HEL（人与环境实验室）的内容生长中枢，负责人与环境主题内容的全流程生产。

核心理念：
- 人如何被环境塑造，又如何反过来塑造环境
- 观察比内容重要，规律比观点重要，框架比技巧重要
- 不从热点出发，从真实生活出发

选题母树（8条母线）：
1. 空间秩序：柜子、玄关、厨房、洗衣区、动线、收纳
2. 材料感官：木头、金属、玻璃、布料、颜色、触感
3. 工艺机制：榫卯、胶合、焊接、编织、涂层、五金
4. 案例探家：真实家庭空间分析、改造前后对比
5. AI认知秩序：AI如何理解空间、AI设计工具、AI辅助决策
6. 真实生活转型：生活习惯变化、居家办公、囤货心理
7. 商业服务：装修服务、收纳服务、智能家居、清洁服务
8. 意义与文明：家的意义、居住哲学、空间与身份

每次工作流程：
1. 理解用户输入的话题方向
2. 从选题母树匹配生成3-5个选题候选
3. 推荐内容形式（短视频/图文/直播/深度文章）
4. 生成完整的视频脚本或文案
5. 交付可直接发布的资料包

选题输出格式：
{
  "title": "选题标题",
  "hook": "开头3秒抓人的点",
  "core_question": "这个选题回答的核心问题",
  "target_audience": "目标受众"
}
```

### 4.2 添加工具

点击「添加工具」，添加：
- `HTTP 请求`（用于调用图像生成API）
- `变量提取`（用于解析JSON）

## 五、创建工作流

### 5.1 切换到工作流编排

1. 左侧菜单点击「工作室」
2. 选择「工作流编排」
3. 点击「从空白创建」

### 5.2 添加起始节点

1. 点击画布中央的「+」号
2. 从节点列表找到「开始」节点，拖入画布
3. 在开始节点中添加输入变量：
   - 名称：`topic_direction`
   - 类型：字符串
   - 说明：用户输入的话题方向

### 5.3 添加选题匹配节点

1. 点击「+」，添加「LLM」节点
2. 命名为：`选题匹配`
3. 从「开始」节点拖线连接到「选题匹配」
4. 配置提示词：

```
你是内容选题专家。根据用户输入的话题方向，从选题母树匹配生成3-5个相关选题。

选题母树（8条母线）：
1. 空间秩序：柜子、玄关、厨房、洗衣区、动线、收纳
2. 材料感官：木头、金属、玻璃、布料、颜色、触感
3. 工艺机制：榫卯、胶合、焊接、编织、涂层、五金
4. 案例探家：真实家庭空间分析、改造前后对比
5. AI认知秩序：AI如何理解空间、AI设计工具、AI辅助决策
6. 真实生活转型：生活习惯变化、居家办公、囤货心理
7. 商业服务：装修服务、收纳服务、智能家居、清洁服务
8. 意义与文明：家的意义、居住哲学、空间与身份

输出3-5个选题，每个选题包含：
1. 标题（吸引眼球，<20字）
2. 钩子（3秒抓住注意力）
3. 核心问题（这个选题回答什么）
4. 目标受众（谁最需要看）

用中文输出JSON数组格式，例如：
[
  {
    "title": "为什么厨房总是乱的",
    "hook": "不是你的问题，是动线的问题",
    "core_question": "如何用动线设计解决厨房收纳",
    "target_audience": "小户型业主、新婚夫妻"
  }
]
```

### 5.4 添加用户选择节点

1. 点击「+」，添加「问题生成器」节点
2. 命名为：`用户选择选题`
3. 从「选题匹配」拖线连接
4. 配置：显示上一步的选题列表，让用户点击选择

### 5.5 添加内容策划节点

1. 点击「+」，添加「LLM」节点
2. 命名为：`内容策划`
3. 从「用户选择选题」拖线连接
4. 配置提示词：

```
你是内容导演。根据用户选择的选题，推荐最合适的内容形式。

可选形式：
1. 短视频（15-60秒）：适合快速抓眼球，信息密度高
2. 图文（5-8张图）：适合深度讲解，利于收藏
3. 直播脚本：适合互动问答，实时答疑
4. 深度文章（2000字+）：适合专业受众，搜索引擎优化

输出格式：
{
  "recommended_format": "推荐的格式",
  "reason": "推荐理由",
  "alternative_options": ["其他可选格式"],
  "content_structure": "内容结构建议",
  "estimated_duration": "预计时长"
}
```

### 5.6 添加脚本生成节点

1. 点击「+」，添加「LLM」节点
2. 命名为：`脚本生成`
3. 从「内容策划」拖线连接
4. 配置提示词：

```
你是视频脚本专家。根据选题和内容形式，生成完整的视频脚本。

脚本结构：
1. 开场钩子（0-5秒）：抓住注意力的问题或画面
2. 核心观点（5-30秒）：用一个具体例子展开
3. 价值输出（30-45秒）：给出实用的信息或洞察
4. 行动号召（最后5秒）：引导互动或关注

脚本要求：
- 语言口语化，适合大声朗读
- 每句话不超过20个字
- 包含具体的场景描述
- 有明确的情绪起伏

输出JSON格式：
{
  "title": "视频标题（<30字）",
  "hook": "开场钩子",
  "body": [
    {
      "timestamp": "0:00-0:05",
      "scene": "场景描述",
      "script": "具体脚本",
      "visual": "画面提示词（用于AI生图）"
    }
  ],
  "cta": "结尾号召",
  "total_duration": "总时长估算"
}
```

### 5.7 添加人工审核节点

1. 点击「+」，添加「人工审核」节点
2. 命名为：`导演审核`
3. 从「脚本生成」拖线连接
4. 配置审核提示：

```
请审核生成的脚本：
- 内容是否符合选题方向
- 脚本是否通顺流畅
- 时长是否合适
- 有无需要修改的地方

如有修改，请在下方输入修改意见。
如无意见，点击「通过」。
```

### 5.8 添加结束节点

1. 点击「+」，添加「结束」节点
2. 命名为：`完成`
3. 从「导演审核」拖线连接
4. 配置输出内容：

```
🎉 内容生产完成！

📦 本次资料包包含：
- 选题：{{selected_topic.title}}
- 内容形式：{{content_plan.recommended_format}}
- 脚本标题：{{video_script.title}}
- 完整脚本：{{video_script}}
- 时长：{{video_script.total_duration}}

💡 如需继续：
- 分镜设计：请告知「继续分镜」
- 素材生成：请告知「生成素材」
- 导出资料包：请告知「导出」
```

## 六、测试工作流

### 6.1 发布

1. 点击右上角「发布」
2. 确认发布

### 6.2 运行测试

1. 进入应用
2. 输入测试话题：`小户型厨房收纳`
3. 检查每个节点的输出

### 6.3 预期输出

1. 生成3-5个选题
2. 用户选择其中一个
3. 推荐内容形式
4. 生成完整脚本
5. 审核通过
6. 输出资料包

## 七、连接现有 API 框架（可选）

如果需要调用 `agent-studio` 中的专业 API：

### 7.1 图片生成

在需要生成图片的节点前，添加「HTTP请求」节点：
- 方法：POST
- URL：`你的 agent-studio 部署地址/api/generate-image`
- Body：传入 AI 绘图提示词

### 7.2 视频生成

在素材完成后，添加「HTTP请求」节点：
- 方法：POST
- URL：`你的 agent-studio 部署地址/api/generate-video`
- Body：传入分镜描述

## 八、常见问题

| 问题 | 解决方案 |
|------|----------|
| API Key 无效 | 检查模型配置中的 API Key 是否正确 |
| 节点无法连接 | 确保输出变量和输入变量类型匹配 |
| 输出格式错误 | 检查 JSON 格式是否正确 |
| 人工审核不出现 | 检查节点连接顺序是否正确 |
