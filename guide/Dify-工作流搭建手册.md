## 二、前置准备

### 2.1 登录 Dify

1. 打开 [https://dify.ai/](https://dify.ai/)
2. 登录你的账号
3. 进入主界面

### 2.2 创建工作流

1. 点击左侧菜单 **「工作室」**
2. 选择 **「工作流编排」**
3. 点击 **「从空白创建」**
4. 填写：
   - **名称**：`HEL内容生长中枢`
   - **描述**：`人与环境实验室内容生产流水线，从选题到交付的完整流程`
5. 点击「创建」

## 三、节点配置详解

### 节点1：开始（Start）

**作用**：接收用户输入的话题方向

**配置步骤**：

1. 点击画布中央的「+」号
2. 选择「开始」节点（已在画布中央）
3. 添加输入变量，点击「添加变量」：

| 变量名 | 类型 | 说明 | 必填 |
|--------|------|------|------|
| `topic_direction` | 字符串 | 用户输入的话题方向 | ✓ |

**配置完成后的变量面板**：
```
topic_direction
├── 类型：字符串
├── 说明：用户输入的话题方向
└── 必填：是
```

---

### 节点2：选题匹配（LLM）

**作用**：从选题母树匹配生成3-5个选题候选

**配置步骤**：

1. 点击「+」，添加「LLM」节点
2. 将节点命名为：`选题匹配`
3. 从「开始」节点拖线连接到「选题匹配」
4. 配置模型：选择 `Claude` 或 `GPT-4o`
5. 配置提示词（复制下方内容）：

```
你是 HEL（人与环境实验室）的内容选题专家。

核心理念：
- 观察比内容重要，规律比观点重要，框架比技巧重要
- 不从热点出发，从真实生活出发
- 人如何被环境塑造，又如何反过来塑造环境

选题母树（8条母线）：
1. 空间秩序：柜子、玄关、厨房、洗衣区、动线、收纳
2. 材料感官：木头、金属、玻璃、布料、颜色、触感
3. 工艺机制：榫卯、胶合、焊接、编织、涂层、五金
4. 案例探家：真实家庭空间分析、改造前后对比
5. AI认知秩序：AI如何理解空间、AI设计工具、AI辅助决策
6. 真实生活转型：生活习惯变化、居家办公、囤货心理
7. 商业服务：装修服务、收纳服务、智能家居、清洁服务
8. 意义与文明：家的意义、居住哲学、空间与身份

根据用户输入的话题方向「{{topic_direction}}」，从选题母树匹配生成3-5个相关选题。

输出要求：
1. 每个选题必须有独特视角，不能泛泛而谈
2. 标题要吸引眼球，不超过20字
3. 钩子要有冲突感或好奇心，3秒内抓住注意力
4. 标注该选题属于哪条母线

用中文输出JSON数组格式：
[
  {
    "title": "选题标题（<20字）",
    "hook": "3秒钩子（有冲突感）",
    "core_question": "这个选题回答的核心问题",
    "target_audience": "目标受众",
    "parent_line": "所属母线编号和名称"
  }
]
```

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `topics` | 数组[对象] | 选题候选列表 |

---

### 节点3：选题展示（LLM）

**作用**：将选题格式化为用户可点击选择的卡片

**配置步骤**：

1. 点击「+」，添加「LLM」节点
2. 将节点命名为：`选题展示`
3. 从「选题匹配」拖线连接到「选题展示」
4. 配置模型：选择 `Claude` 或 `GPT-4o`
5. 配置提示词：

```
你是内容展示专家。将选题列表格式化为用户友好的展示格式。

输入的选题列表：{{topics}}

你的任务：
1. 将每个选题格式化为清晰的卡片格式
2. 每个卡片包含：编号、标题、钩子、核心问题、目标受众
3. 在最后给出选择提示："请回复数字选择选题（1-5）"
4. 语言要口语化、自然

输出格式示例：
📌 **选题 1**
标题：为什么厨房总是乱的
钩子：不是你的问题，是动线的问题
核心问题：如何用动线设计解决厨房收纳
目标受众：小户型业主、新婚夫妻
所属母线：1-空间秩序

📌 **选题 2**
...

请回复数字选择选题（1-5）：
```

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `topics_display` | 字符串 | 格式化后的选题展示 |

---

### 节点4：用户选择（LLM）

**作用**：理解用户选择，返回选中的选题对象

**配置步骤**：

1. 点击「+」，添加「LLM」节点
2. 将节点命名为：`用户选择`
3. 从「选题展示」拖线连接到「用户选择」
4. 配置模型：选择 `Claude` 或 `GPT-4o`
5. 配置提示词：

```
你是用户意图理解专家。

用户输入：{{topic_direction}}
选题列表：{{topics}}

用户选择了一个数字（1-5），请返回对应的完整选题对象。

要求：
1. 严格匹配用户选择的数字
2. 返回完整的选题JSON对象
3. 不要添加任何解释说明

输出JSON格式：
{
  "title": "选题标题",
  "hook": "3秒钩子",
  "core_question": "核心问题",
  "target_audience": "目标受众",
  "parent_line": "所属母线"
}
```

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `selected_topic` | 对象 | 用户选中的选题 |

### 节点5：内容策划（LLM）

**作用**：根据选题推荐内容形式和结构

**配置步骤**：

1. 点击「+」，添加「LLM」节点
2. 将节点命名为：`内容策划`
3. 从「用户选择」拖线连接到「内容策划」
4. 配置模型：选择 `Claude` 或 `GPT-4o`
5. 配置提示词：

```
你是内容策划专家。根据选题推荐最合适的内容形式。

选题：{{selected_topic}}

可选内容形式：
1. 短视频（15-60秒）：适合快速抓眼球，信息密度高，情绪冲突强
2. 图文（5-8张图）：适合深度讲解，利于收藏，颜值要求高
3. 直播脚本：适合互动答疑，需要有话题延展性
4. 深度文章（2000字+）：适合专业受众，搜索引擎优化

推荐原则：
- 短视频优先（流量最大）
- 根据选题特性选择形式
- 如果选题有深度延展空间，可以推荐多形式

输出JSON格式：
{
  "recommended_format": "推荐的格式",
  "format_reason": "推荐理由（为什么这个形式最适合）",
  "alternative_options": ["其他可选格式"],
  "content_structure": "内容结构建议（开头/中间/结尾怎么安排）",
  "estimated_duration": "预计时长",
  "platform_recommendation": "推荐平台（抖音/小红书/B站）"
}
```

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `content_plan` | 对象 | 内容策划方案 |

---

### 节点6：脚本生成（LLM）

**作用**：生成完整的视频脚本或图文文案

**配置步骤**：

1. 点击「+」，添加「LLM」节点
2. 将节点命名为：`脚本生成`
3. 从「内容策划」拖线连接到「脚本生成」
4. 配置模型：选择 `Claude` 或 `GPT-4o`
5. 配置提示词：

```
你是视频脚本专家。根据选题和内容形式，生成完整的脚本。

选题：{{selected_topic}}
内容形式：{{content_plan.recommended_format}}
内容结构：{{content_plan.content_structure}}
推荐平台：{{content_plan.platform_recommendation}}

脚本要求：
1. 语言必须口语化，适合大声朗读，禁止书面语
2. 每句话不超过20个字
3. 包含具体的场景描述和细节
4. 有明确的情绪起伏（开头抓人、中间有料、结尾有感）
5. 必须有具体例子，不能泛泛而谈
6. 开头要有"去AI味"的具体细节

去AI味检查清单：
- ❌ "很多人都遇到过这个问题" → ✅ "我上次去朋友家..."
- ❌ "这告诉我们一个道理" → ✅ "那一刻我突然意识到..."
- ❌ "我们应该..." → ✅ "我习惯..."

脚本结构（短视频）：
1. 开场钩子（0-5秒）：用具体场景或冲突问题抓住注意力
2. 核心展开（5-30秒）：用一个真实案例展开核心观点
3. 价值输出（30-45秒）：给出实用的信息或洞察
4. 行动号召（最后5秒）：引导互动或关注

脚本结构（图文）：
1. 封面文字：吸引眼球的标题
2. 引言：引发共鸣的场景描述
3. 正文：3-5个要点，每个要点有具体案例
4. 结语：总结+互动引导

输出JSON格式（短视频）：
{
  "title": "视频标题（<30字）",
  "format": "短视频",
  "sections": [
    {
      "timestamp": "0:00-0:05",
      "scene": "场景描述",
      "script": "具体脚本内容",
      "visual_prompt": "画面提示词（用于AI生图）"
    }
  ],
  "cta": "结尾号召（引导关注/评论）",
  "total_duration": "总时长估算"
}

输出JSON格式（图文）：
{
  "title": "图文标题",
  "format": "图文",
  "cover_text": "封面文字",
  "sections": [
    {
      "heading": "小标题",
      "content": "正文内容",
      "image_prompt": "配图提示词"
    }
  ],
  "cta": "互动引导"
}
```

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `script` | 对象 | 生成的脚本 |
| `script_review_checklist` | 字符串 | 审核检查清单（给人工审核用） |

---

### 节点7：人工审核（Approval）

**作用**：人工审核脚本质量，决定是否通过

**配置步骤**：

1. 点击「+」，添加「人工审核」节点
2. 将节点命名为：`脚本审核`
3. 从「脚本生成」拖线连接到「脚本审核」
4. 配置审核内容：

```
📋 脚本审核清单

请检查以下内容：

1. **选题匹配度**
   - 脚本是否紧扣选题方向？
   - 有没有跑题或泛泛而谈？

2. **去AI味检查**
   - 有没有"很多人都..."、"这告诉我们..."等泛泛表达？
   - 有没有具体的个人案例或细节？
   - 情绪是否真实？

3. **脚本质量**
   - 语言是否口语化？
   - 时长是否合适？
   - 结构是否清晰？

4. **平台适配**
   - 内容形式是否适合目标平台？
   - 开头是否能抓住注意力？

---

📝 脚本预览：

标题：{{script.title}}
格式：{{script.format}}
时长：{{script.total_duration}}

{% for section in script.sections %}
【{{section.timestamp}}】
场景：{{section.scene}}
脚本：{{section.script}}
{% endfor %}

结尾号召：{{script.cta}}
```

**审核选项配置**：

配置两个审核选项：
- **通过**：继续到下一步
- **需修改**：输入修改意见，返回脚本生成节点

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `approval_result` | 字符串 | 审核结果（通过/需修改） |
| `revision_notes` | 字符串 | 修改意见（如需修改） |

---

### 节点8：条件分支（Condition）

**作用**：根据审核结果决定流程

**配置步骤**：

1. 点击「+」，添加「条件分支」节点
2. 将节点命名为：`审核判断`
3. 从「脚本审核」拖线连接

**配置条件**：

添加两个分支条件：

| 分支名 | 条件 |
|--------|------|
| `通过` | `approval_result` 等于 `通过` |
| `需修改` | `approval_result` 等于 `需修改` |

**连接方式**：

- 「通过」分支 → 连接「资料包组装」节点
- 「需修改」分支 → 连接「脚本生成」节点（形成循环）

---

### 节点9：资料包组装（LLM）

**作用**：将所有内容整理成完整资料包

**配置步骤**：

1. 点击「+」，添加「LLM」节点
2. 将节点命名为：`资料包组装`
3. 从「审核判断」的「通过」分支拖线连接
4. 配置模型：选择 `Claude` 或 `GPT-4o`
5. 配置提示词：

```
你是资料整理专家。将内容整理成完整的资料包。

选题：{{selected_topic}}
内容形式：{{content_plan.recommended_format}}
平台：{{content_plan.platform_recommendation}}
脚本：{{script}}

输出要求：
1. 整理成结构清晰的资料包
2. 包含所有必要的信息
3. 格式要便于直接使用

资料包结构：
---
📦 HEL 内容资料包

【基本信息】
选题：{{selected_topic.title}}
所属母线：{{selected_topic.parent_line}}
目标受众：{{selected_topic.target_audience}}

【内容形式】
格式：{{content_plan.recommended_format}}
平台：{{content_plan.platform_recommendation}}
时长：{{script.total_duration}}

【脚本正文】
{{script}}

【使用说明】
- 如需修改脚本，请回复「修改脚本+具体意见」
- 如需生成配图，请回复「生成配图」
- 如需导出，请回复「导出资料包」
---
```

**输出变量配置**：

点击「添加输出变量」，添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `final_package` | 字符串 | 完整资料包 |
| `package_summary` | 字符串 | 资料包摘要 |

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| 节点无法连接 | 确保输出变量类型和输入变量类型匹配 |
| 输出格式错误 | 检查JSON格式是否正确，引号是否匹配 |
| 人工审核不出现 | 检查「审核判断」节点连接是否正确 |
| 脚本生成太泛 | 在提示词中加强"去AI味"要求 |
| 选题不匹配 | 检查选题母树的描述是否够清晰 |
