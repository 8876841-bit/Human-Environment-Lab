# HEL 内容生产流水线 - Dify 工作流设计

## 整体架构

```
用户输入话题
    ↓
┌─────────────────────────────────────────────────────────────┐
│ 节点1：选题匹配                                              │
│ - 输入：话题方向（1-2句话描述）                               │
│ - 匹配选题母树，生成3-5个候选选题                              │
│ - 输出：选题列表供用户选择                                    │
└─────────────────────────────────────────────────────────────┘
    ↓ 用户选择选题
┌─────────────────────────────────────────────────────────────┐
│ 节点2：内容策划                                              │
│ - 根据选题分析推荐展示形式                                    │
│ - 输出：短视频 / 图文 / 直播脚本 / 深度文章                    │
└─────────────────────────────────────────────────────────────┘
    ↓ 用户确认形式
┌─────────────────────────────────────────────────────────────┐
│ 节点3：脚本生成                                              │
│ - 生成完整脚本/文案                                          │
│ - 输出：分镜脚本 + 时长估算                                   │
└─────────────────────────────────────────────────────────────┘
    ↓ 导演审核（人工）
┌─────────────────────────────────────────────────────────────┐
│ 节点4：分镜设计                                              │
│ - 将脚本拆分为具体镜头                                       │
│ - 输出：分镜列表（镜头描述 + 画面提示词）                      │
└─────────────────────────────────────────────────────────────┘
    ↓ 导演审核（人工）
┌─────────────────────────────────────────────────────────────┐
│ 节点5：素材生成                                              │
│ - 根据分镜生成图片/视频素材                                   │
│ - 输出：素材文件列表                                         │
└─────────────────────────────────────────────────────────────┘
    ↓ 导演审核（人工）
┌─────────────────────────────────────────────────────────────┐
│ 节点6：后期制作                                              │
│ - 组装素材，生成最终成品                                      │
│ - 输出：视频文件 + 封面 + 标题 + 描述                         │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│ 节点7：导出资料包                                            │
│ - 打包所有素材和文案                                          │
│ - 输出：可直接发布的运营资料包                                │
└─────────────────────────────────────────────────────────────┘
```

## Dify 节点详细设计

### 节点1：选题匹配 (Topic Match)

**类型**：LLM Agent

**系统提示词**：
```
你是一个内容选题专家，擅长从"人与环境"的角度挖掘选题。

你的任务是：
1. 理解用户输入的话题方向
2. 从选题母树中匹配最相关的选题
3. 生成3-5个具体的选题候选

选题母树结构：
- 空间秩序：柜子、玄关、厨房、洗衣区、动线、收纳
- 材料感官：木头、金属、玻璃、布料、颜色、触感
- 工艺机制：榫卯、胶合、焊接、编织、涂层、五金
- 案例探家：真实家庭空间分析、改造前后对比
- AI认知秩序：AI如何理解空间、AI设计工具、AI辅助决策
- 真实生活转型：生活习惯变化、居家办公、囤货心理
- 商业服务：装修服务、收纳服务、智能家居、清洁服务
- 意义与文明：家的意义、居住哲学、空间与身份

每个选题输出格式：
{
  "title": "选题标题",
  "hook": "开头3秒抓人的点",
  "core_question": "这个选题回答的核心问题",
  "target_audience": "目标受众",
  "platform": "最适合的平台"
}
```

**输入变量**：
- `topic_direction`: 用户输入的话题方向

**输出变量**：
- `topic_options`: JSON数组，包含3-5个选题候选

---

### 节点2：内容策划 (Content Planning)

**类型**：LLM Agent

**系统提示词**：
```
你是一个内容导演，擅长根据选题决定最佳的内容形式。

你的任务：
1. 分析选题特点
2. 推荐最合适的内容形式
3. 给出形式选择（用户确认后继续）

可选内容形式：
1. 短视频（15-60秒）：适合快速抓眼球，信息密度高
2. 图文（5-8张图）：适合深度讲解，利于收藏
3. 直播脚本：适合互动问答，实时答疑
4. 深度文章（2000字+）：适合专业受众，搜索引擎优化

输出格式：
{
  "recommended_format": "推荐的格式",
  "reason": "推荐理由",
  "alternative_options": ["其他可选格式"],
  "content_structure": "内容结构建议",
  "estimated_duration": "预计时长"
}
```

**输入变量**：
- `selected_topic`: 用户选择的选题（JSON对象）
- `topic_direction`: 原始话题方向

**输出变量**：
- `content_plan`: 内容策划方案

**用户交互**：
- 显示推荐格式和备选选项
- 用户点击确认后进入下一步

---

### 节点3：脚本生成 (Script Generation)

**类型**：LLM Agent

**系统提示词**：
```
你是一个视频脚本专家，擅长写抓眼球的内容脚本。

根据选题和内容形式，生成完整的视频脚本。

脚本母版：
1. 开场钩子（0-5秒）：抓住注意力的问题或画面
2. 核心观点（5-30秒）：用一个具体例子展开
3. 价值输出（30-45秒）：给出实用的信息或洞察
4. 行动号召（最后5秒）：引导互动或关注

脚本要求：
- 语言口语化，适合大声朗读
- 每句话不超过20个字
- 包含具体的场景描述
- 有明确的情绪起伏

输出格式：
{
  "title": "视频标题（<30字）",
  "hook": "开场钩子",
  "body": [
    {
      "timestamp": "0:00-0:05",
      "scene": "场景描述",
      "script": "具体脚本",
      "visual": "画面提示词（用于AI生图）"
    },
    ...
  ],
  "cta": "结尾号召",
  "total_duration": "总时长估算"
}
```

**输入变量**：
- `selected_topic`: 用户选择的选题
- `content_plan`: 内容策划方案

**输出变量**：
- `video_script`: 完整的视频脚本（JSON）

---

### 节点4：分镜设计 (Storyboard Design)

**类型**：LLM Agent

**系统提示词**：
```
你是一个分镜设计师，擅长将脚本转化为具体的视觉分镜。

根据视频脚本，生成详细的分镜列表。

分镜要求：
- 每个镜头15-30秒
- 包含景别、运镜、画面描述
- 每帧都有AI绘图提示词
- 考虑剪辑节奏

分镜模板：
{
  "shot_number": 1,
  "duration": "3秒",
  "shot_type": "特写/近景/中景/远景/全景",
  "camera_movement": "固定/推/拉/摇/移/跟",
  "scene_description": "具体场景描述",
  "ai_image_prompt": "用于AI生图的英文提示词",
  "key_points": "这帧要传达的关键信息"
}

输出：分镜数组
```

**输入变量**：
- `video_script`: 视频脚本

**输出变量**：
- `storyboard`: 分镜列表（JSON数组）

---

### 节点5：素材生成 (Asset Generation)

**类型**：HTTP Request / LLM Agent

**功能**：
- 根据分镜中的 AI 图像提示词生成图片
- 支持的图像API：
  - OpenAI DALL-E 3
  - 通义万相
  - Midjourney API

**输入变量**：
- `storyboard`: 分镜列表

**处理逻辑**：
```
遍历每个分镜：
1. 提取 ai_image_prompt
2. 调用图像生成API
3. 保存生成的图片URL
4. 组装素材列表
```

**输出变量**：
- `generated_assets`: 生成的素材列表
  ```json
  {
    "shots": [
      {
        "shot_number": 1,
        "image_url": "https://...",
        "prompt_used": "..."
      }
    ]
  }
  ```

---

### 节点6：后期制作 (Post Production)

**类型**：LLM Agent + HTTP Request

**系统提示词**：
```
你是一个后期剪辑师，擅长组装素材并生成最终成品。

你的任务：
1. 整理所有素材
2. 生成剪辑顺序
3. 输出完整的发布资料包

资料包内容：
1. 视频文件（拼接好的视频）
2. 封面图
3. 标题（各平台适配）
4. 描述文案（各平台适配）
5. 话题标签
```

**输入变量**：
- `storyboard`: 分镜列表
- `generated_assets`: 生成的素材
- `video_script`: 原脚本

**输出变量**：
- `final_package`: 最终资料包
  ```json
  {
    "video_file": "视频URL",
    "cover_image": "封面图URL",
    "titles": {
      "douyin": "抖音标题",
      "xiaohongshu": "小红书标题",
      "bilibili": "B站标题"
    },
    "descriptions": {
      "douyin": "抖音描述",
      "xiaohongshu": "小红书正文",
      "bilibili": "B站简介"
    },
    "hashtags": ["#标签1", "#标签2", ...]
  }
  ```

---

### 节点7：导出资料包 (Export Package)

**类型**：Code Agent

**功能**：
- 打包所有素材和文案
- 生成可直接使用的运营资料

**输出格式**：
```
export/
├── video.mp4          # 最终视频
├── cover.jpg          # 封面图
├── assets/            # 原始素材
│   ├── shot_001.jpg
│   ├── shot_002.jpg
│   └── ...
├── copy/              # 文案资料
│   ├── titles.json    # 各平台标题
│   ├── descriptions.json  # 各平台描述
│   └── hashtags.txt   # 话题标签
└── summary.md         # 本次内容总结
```

## Dify 工作流配置清单

### 1. 创建 App

1. 登录 Dify Cloud：https://dify.ai/
2. 点击「创建 App」
3. 选择「空白应用」或「从模板创建」
4. 应用名称：`HEL内容生产流水线`
5. 类型：选择「聊天助手」或「Agent」

### 2. 配置变量

在「变量」页面添加：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| topic_direction | 字符串 | 用户输入的话题方向 |
| selected_topic | 对象 | 用户选择的选题 |
| content_plan | 对象 | 内容策划方案 |
| video_script | 对象 | 生成的视频脚本 |
| storyboard | 数组 | 分镜列表 |
| generated_assets | 对象 | 生成的素材 |
| final_package | 对象 | 最终资料包 |

### 3. 配置 Agent

在「Agent」页面：

1. **模型选择**：Claude 3.5 Sonnet 或 GPT-4
2. **添加工具**：
   - HTTP 请求（用于调用图像生成API）
   - 变量提取
   - 模板转换

### 4. 配置工作流

在「工作流编排」页面：

1. 添加起始节点（用户输入）
2. 添加 LLM 节点（选题匹配）
3. 添加「问题生成器」节点（用户选择）
4. 添加 LLM 节点（内容策划）
5. 添加 LLM 节点（脚本生成）
6. 添加「人工审核」节点
7. 添加 LLM 节点（分镜设计）
8. 添加「人工审核」节点
9. 添加 HTTP 请求节点（素材生成）
10. 添加「人工审核」节点
11. 添加 LLM 节点（后期制作）
12. 添加结束节点

### 5. 测试工作流

1. 点击「发布」
2. 在「运行」页面测试
3. 输入测试话题：「小户型收纳」
4. 检查每个节点的输出
