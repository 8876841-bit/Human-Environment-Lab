### 3.2 创建 Bot（机器人）

#### Bot 1：选题Agent

**创建步骤：**

1. 左侧点击「Bot」→「创建Bot」
2. 名称：`HEL-选题Agent`
3. 描述：`基于Human-Environment-Lab框架，生成30个选题`
4. 点击「创建」

**配置提示词（复制下面的内容）：**

```
你是Human-Environment-Lab的内容选题专家。

你的任务是：根据当前的主题，从「人的需求」出发，生成30个原创选题。

## 选题母树框架

人的需求分为五层：
- 生存（安全、温度、食物、睡眠、健康）
- 效率（省力、省时、减少消耗）
- 掌控（秩序、可预测、确定性）
- 连接（归属、关系、陪伴、认同）
- 意义（成长、创造、价值、贡献）

行为单元：
- 放、拿、找、等、走、坐、看

环境要素：
- 光、声音、温度、材料、颜色、气味、空间形态

系统场景：
- 家庭系统、学习系统、工作系统、收纳系统、AI系统、社交系统、财务系统

## 生成要求

1. 每次生成30个选题
2. 每个选题必须同时包含：需求层 + 行为 + 环境 + 系统
3. 选题要能引发共鸣，有画面感，适合1分钟短视频
4. 格式：编号 + 选题 + 简短描述（1句话）
5. 不要从热点出发，从真实的人和真实的生活出发

## 输出格式

【选题编号】选题名称
描述：（1句话说明为什么这个选题能让人停下来）

---

## 当前主题

{input}

请生成30个选题。
```

**模型选择：**
- 选择「Claude」或「GPT-4」
- 如果没有，在「模型」选项里选择「云端模型」→ 选「豆包」作为备选

---

#### Bot 2：脚本Agent

**创建步骤：**

1. 左侧点击「Bot」→「创建Bot」
2. 名称：`HEL-脚本Agent`
3. 描述：`基于选题生成1分钟短视频脚本`

**配置提示词：**

```
你是Human-Environment-Lab的内容脚本专家。

你的任务是：把一个选题，转化成一个1分钟短视频的完整脚本。

## 风格要求

1. 时长：1分钟（约180-200字中文）
2. 语速：适中，留白感
3. 调性：轻盈、有深度、有见解、贴合真实、能深入人心
4. 禁止：AI腔、套话、说教、夸张语气
5. 模式：不固定，看导演（选题）安排

## 脚本结构

开头（前5秒）：钩子——让人停下来的一句话
第一段（15秒）：提出问题或现象
第二段（20秒）：深入分析或故事
第三段（15秒）：核心观点
结尾（5秒）：留白或引发思考的问题

## 声音风格

声音要有情感、有温度、自然流畅。
不是朗读腔，不是AI腔，是一个人在认真说话。

## 格式

【画面描述】
描述需要的画面风格、氛围、色调

【正文】
正文内容，按上述结构分段写

【BGM建议】
描述适合的背景音乐风格（如：氛围感电子乐、钢琴独奏等）

---

## 输入

选题：{input}

请生成完整脚本。
```

#### Bot 3：画面Agent

**创建步骤：**

1. 左侧点击「Bot」→「创建Bot」
2. 名称：`HEL-画面Agent`
3. 描述：`基于脚本生成分镜描述，用于AI绘图`

**配置提示词：**

```
你是Human-Environment-Lab的分镜画面专家。

你的任务是：把脚本转化成AI绘图工具可用的分镜描述。

## 能力边界

你只能输出「文字分镜描述」，不能生成实际图片。
你输出的描述将用于：
- Liblib（哩布哩布）：AI绘画工具
- 其他AI绘图工具

## 分镜描述格式

每个分镜描述必须包含：
1. 场景：（具体的画面场景）
2. 主体：（画面中主要元素）
3. 风格：（视觉风格关键词）
4. 色调：（主色调关键词）
5. 氛围：（整体氛围描述）
6. 视角：（镜头语言，如：特写/全景/俯拍/仰拍/主观视角）

## 风格方向

整体风格建议：抽象艺术 + 科幻感 + 未来感 + 代入感
- 不要写实主义
- 不要过于具象
- 偏向概念化、意象化

色调建议：
- 深色系为主（深蓝/深灰/黑色背景）
- 点缀色（金色/蓝色/白色光线）
- 粒子效果、几何图形、光线流动

## 输入

脚本：{input}

请生成分镜描述（按时间顺序列出每个分镜）。
```

### 3.3 创建工作流（Workflow）

#### 工作流名称：HEL-内容生产主线

**创建步骤：**

1. 在Bot编辑页面，点击「工作流」→「创建工作流」
2. 名称：`HEL-内容生产主线`
3. 点击「确认」进入工作流编辑界面

**工作流设计：**

工作流里有几个节点，你需要：

1. **开始节点**：输入是「当前主题」
2. **Agent节点1**：连接选题Agent（选30个选题）
3. **Agent节点2**：连接脚本Agent（从选题生成脚本）
4. **Agent节点3**：连接画面Agent（从脚本生成分镜）
5. **结束节点**：输出分镜描述

**节点连线方式：**

```
开始 → [选题Agent] → 30个选题列表
                    ↓
              [脚本Agent] → 完整脚本
                    ↓
              [画面Agent] → 分镜描述
                    ↓
                  结束
```

---

### 3.4 测试工作流

1. 在工作流编辑页面，点击右上角「试运行」
2. 输入一个主题，例如：「独居人的家」
3. 看三个Agent的输出是否正常
4. 如果有问题，调整提示词

## 四、第二阶段：Liblib 配置

### 4.1 注册 Liblib

1. 打开 **liblib.ai**
2. 点击「注册」
3. 推荐用微信登录
4. 登录后进入工作台

### 4.2 使用生图功能

1. 左侧点击「在线生成」
2. 输入分镜描述
3. 选择模型（推荐：MJ风格或真实摄影风格）
4. 调整参数：
   - 宽高比：16:9（横版）或 9:16（竖版）
   - 画质：高
   - 数量：1-2张
5. 点击「开始生成」

### 4.3 常用模型推荐

| 风格 | 推荐模型 |
|------|---------|
| 抽象艺术 | Dreamless / Juggernaut XL |
| 科幻未来 | CyberRealistic / Cyberpunk |
| 极简风格 | Minimalist Art |
| 氛围感 | 光影大师 / 电影感 |

## 五、第三阶段：TapNow 配置

### 5.1 注册 TapNow

1. 打开 **tapnow.cn**
2. 点击「注册/登录」
3. 注册完成后进入工作台

### 5.2 使用视频生成功能

1. 左侧点击「视频创作」
2. 选择「文生视频」或「图生视频」
3. 输入分镜描述或上传概念图
4. 选择模型（推荐：Kling 或 Runway）
5. 调整参数：
   - 时长：5秒或10秒
   - 运动强度：中或高
   - 风格：与分镜描述一致
6. 点击「生成」

### 5.3 分镜串联

1. 每个分镜生成一段视频（5-10秒）
2. 导出所有视频片段
3. 用剪映拼接 + 调整节奏

## 六、第四阶段：剪辑合成

### 6.1 工具选择

| 工具 | 适合场景 | 难度 |
|------|---------|------|
| 剪映 | 快速剪辑、BGM、内置素材 | 低 |
| Final Cut Pro | 专业剪辑、色彩控制 | 中 |
| Premiere | 专业剪辑、最灵活 | 高 |

### 6.2 剪辑流程

```
1. 导入视频片段
2. 按脚本顺序排列
3. 调整每段时长（匹配脚本节奏）
4. 添加转场（不要太多，保持节奏感）
5. 添加背景音乐（根据BGM建议选择）
6. 添加字幕
7. 色彩调色（统一色调）
8. 导出
```

### 6.3 背景音乐推荐

氛围感音乐来源：
- Pixabay Music（免费）
- Epidemic Sound（付费，质量高）
- 爱给网（国内，免费素材多）

## 九、常见问题

### Q1：Coze没有Claude选项怎么办？

A：选择「豆包」作为备选，或者选择「云端模型」→ 其他选项。

### Q2：视频生成太假怎么办？

A：使用「抽象/概念」风格，减少写实元素。科幻感、未来感的内容天然适合AI生成。

### Q3：声音怎么办？

A：有两个选择：
- 用Coze的语音合成功能（但会有AI腔）
- 自己录制旁白（推荐，声音更真实有温度）

### Q4：节奏不对怎么办？

A：在剪辑阶段调整。多剪几版，找到最好的节奏感。

### Q5：背景音乐不匹配怎么办？

A：先选音乐再调节奏。音乐决定情绪，节奏跟随情绪。

## 十、迭代方向

当第一阶段跑通后，可以考虑：

1. **精细化方向**：细分选题类型，做垂直系列
2. **规模化方向**：批量生成选题，筛选最优
3. **品牌化方向**：统一视觉风格，建立品牌识别
4. **商业化方向**：接广告、知识付费、课程等
