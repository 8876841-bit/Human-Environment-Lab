# HEL 内容世界观 - 账号矩阵设计

> 本文档记录 HEL 项目账号矩阵设计的完整讨论过程和最终方案。

---

## 一、核心理念

### 底层主题
> 人如何被环境塑造，又如何反过来塑造环境

### 核心主线
```
人 → 行为 → 环境 → 系统 → 未来
```

### 核心公式
```
需求 × 行为 × 环境 × 系统 = 原创选题
```

### 核心理念
- 观察比内容重要
- 规律比观点重要
- 框架比技巧重要
- 不从热点出发，从真实生活出发

---

## 二、框架设计

### 内容生产流水线
```
用户灵感/想法
    ↓
【1】选题生成 → 话题库 → 用户选1-2个
    ↓
【2】脚本生成 → 用户审核OK
    ↓
【3】形式决策 → 总负责判断
    ↓
【4】按形式精细生产
    ↓
【5】成品交付
```

### 形式决策维度
| 形式 | 说明 |
|------|------|
| 图文 | 5-8张图，适合深度讲解 |
| 口播 | 真人出镜，适合建立信任 |
| 知识分享 | 干货输出，适合专业受众 |
| 漫画 | 逐帧生成首图、细节图、尾图 |
| 动画 | 适合抽象概念可视化 |
| 互动视频 | 增强参与感 |

### 精细生产要求
- **漫画**：首图、细节图、尾图 + 标题 + 文案 + 标签
- **短视频**：口播 + 画面穿插 + 转场 + 节奏 + BGM
- 每种形式都有专业细致的把控

## 三、生长系统设计

### 核心理念
> 与用户共同成长的内容智能体

### 生长维度
| 维度 | 说明 |
|------|------|
| 选题库生长 | 每次生成的话题库沉淀到母树 |
| 脚本模板生长 | 好用的脚本结构沉淀成模板 |
| 形式决策学习 | 决策经验沉淀成决策知识库 |
| 生产流程生长 | 每种形式的生产经验不断积累 |
| 反馈闭环 | 成品数据好 → 反向优化选题方向 |

### 生长方式
- **半自动化**：AI提出建议，用户确认后才沉淀
- **数据反馈**：平台自动抓取数据 + 手动输入结合
- **手动输入**：用户可以随时说"记录下来"

### 成长可见性
- 需要一个"生长仪表板"
- 展示学到了什么/沉淀了什么/这次哪里进步了

## 四、账号矩阵设计

### 三层结构
| 层次 | 内容方向 | 目标人群 |
|------|----------|----------|
| **实用层** | 空间、收纳、柜子、材料 | 需要解决具体问题的人 |
| **认知层** | AI工具、效率、工作流 | 在适应变化的人 |
| **哲学层** | 意义、真实生活、存在感 | 在想为什么活着的人 |

### 金字塔账号架构
```
                    ┌─────────────────┐
                    │   核心主账号     │
                    │  （综合叙事）    │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         ▼                   ▼                   ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│   实用层账号     │ │   认知层账号     │ │   哲学层账号     │
│  （引流入口）    │ │  （建立信任）    │ │  （深度连接）    │
└────────┬────────┘ └────────┬────────┘ └────────┬────────┘
         │                   │                   │
         └───────────────────┴───────────────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │   形式账号       │
                    │（按需生长出来）   │
                    └─────────────────┘
```

### 各账号详细设计

#### 主账号
| 属性 | 内容 |
|------|------|
| **定位** | 综合叙事，建立世界观 |
| **内容角度** | 所有角度在一个故事里 |
| **内容形式** | 长视频/播客/深度文章 |
| **平台** | B站/公众号/播客 |
| **作用** | 建立世界观，沉淀核心粉丝 |
| **内容特点** | 空间、AI、意义在一个叙事里 |

#### 实用层账号
| 属性 | 内容 |
|------|------|
| **定位** | 解决具体问题 |
| **内容角度** | 空间、收纳、柜子、动线、材料、工艺 |
| **内容形式** | 短视频/图文 |
| **平台** | 抖音/小红书 |
| **作用** | 吸引泛流量，筛选潜在用户 |
| **内容特点** | 具体可操作的方法、案例 |

#### 认知层账号
| 属性 | 内容 |
|------|------|
| **定位** | 理解变化逻辑 |
| **内容角度** | AI工具、生活方式变化、效率提升 |
| **内容形式** | 图文/知识分享视频 |
| **平台** | 小红书/公众号 |
| **作用** | 建立专业认知，吸引同行 |
| **内容特点** | 用AI但不卷AI，用工具但不工具人 |

#### 哲学层账号
| 属性 | 内容 |
|------|------|
| **定位** | 追问存在意义 |
| **内容角度** | 家的意义、居住哲学、真实感、存在感 |
| **内容形式** | 深度内容/漫画/动画 |
| **平台** | B站/播客 |
| **作用** | 深度连接，筛选高价值用户 |
| **内容特点** | "我还在"的真实感 |

#### 形式账号（按需生长）
| 属性 | 内容 |
|------|------|
| **定位** | 拓展内容形式 |
| **内容角度** | 当某个角度需要新形式时生长出来 |
| **内容形式** | 动画号、漫画号等 |
| **平台** | 根据形式选择 |
| **作用** | 覆盖更多内容场景 |
| **生长条件** | 某个角度需要新形式时 |

## 五、账号联动机制

### 流量流动
```
实用层账号（引流）
    ↓ 吸引关注
    ↓ "想深入了解？看主账号"
认知层账号（建立信任）
    ↓ 提供更深内容
    ↓ "想听完整故事？看主账号"
哲学层账号（深度连接）
    ↓ 追问意义
    ↓ "欢迎来到我们的世界"
主账号（沉淀转化）
    ↓ 建立世界观
    ↓ 最终转化
```

### 联动方式
| 联动场景 | 操作方式 |
|----------|----------|
| 实用→主账号 | "这个案例的完整故事，点击主页"
| 认知→主账号 | "想了解这套方法论，点击主页"
| 哲学→主账号 | "欢迎来到我们的世界，点击主页"
| 形式账号→主账号 | "背后的故事，点击主页"

### 商业闭环
```
流量入口（实用层账号）
    ↓ 吸引关注
信任建立（认知层账号）
    ↓ 建立专业认知
价值转化（哲学层账号）
    ↓ 筛选高价值用户
商业闭环（服务/产品/社群）
```

## 六、执行原则

### 内容原则
1. 不蹭热点，从真实生活出发
2. 每个内容回答四个问题：
   - 人在追求什么？
   - 人产生了什么行为？
   - 环境如何影响这个行为？
   - 这个行为发生在哪个系统里？

### 账号原则
1. 主账号：建立世界观，不急于变现
2. 角度账号：垂直深耕，吸引精准人群
3. 形式账号：按需生长，不提前布局
4. 联动：自然引流，不生硬

### 生长原则
1. 每次反馈都是学习机会
2. 好经验要沉淀，不好经验也要记录
3. 半自动化：AI建议 + 用户确认
4. 成长要可见：定期回顾"学到了什么"
