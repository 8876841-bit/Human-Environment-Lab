# 04-账号矩阵 目录说明

> 状态：`LEGACY / LONG-TERM`（历史方案 / 中长期设想）

本目录保存 HEL 的账号矩阵设计方案。

它仍然有参考价值，但**当前阶段不执行“8 条母线对应 8 个账号”的铺开策略**。

---

## 当前主线策略

当前阶段以 `05-内容生产体系/03-表达形式与运营机制.md` 中的账号策略为准：

```text
第一阶段：大一统主账号 + 专栏合集
第二阶段：按平台调性切片分发
第三阶段：垂直账号裂变
```

---

## 为什么暂不铺 8 个账号？

```text
1. 每个账号都需要稳定内容供给。
2. 当前真实 OBS 和发布数据还不足。
3. 同时铺开会稀释精力和数据反馈。
4. 应先验证哪条母线、哪种形式、哪个平台反馈最好。
```

---

## 使用原则

```text
当前执行：先做一个主账号，跑通内容生产与复盘。
长期参考：当某条母线被数据验证后，再考虑独立账号。
```
