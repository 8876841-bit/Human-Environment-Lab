## 硬阻塞

V7 的核心要求是：

```text
人物写实 + 口型一致 + 88.8 秒真实口播同步 + 画中画补充内容
```

当前可用的 Seedance / Wan / LiblibAI / GRSAI 能生成视频画面，但不能稳定完成「既有人物肖像 + 既有音频 + 逐句口型同步」这个任务。  
如果直接用 Seedance 图生视频硬做，只能得到“像在说话的人物视频”，无法保证口型对齐真实口播，尤其是 V7 指定的关键词：

- 「门外汉」
- 「底层逻辑」
- 「养」
- 「我回来了」

这会破坏人物主导版本最重要的真实感和可信边界。

## 需要 Claude Code 调整/决策

请在下面三种方案里定一个执行路径：

### 方案 A｜接入口型同步/数字人工具

需要提供或接入一个明确可调用的工具/API，能力至少包括：

- 输入：人物图或人物视频
- 输入：88.8 秒真实口播音频
- 输出：口型同步的人物视频
- 最好支持竖屏 1080x1920 或可后期裁切

Codex 接到可调用方式后，可以继续按 V7 分段生成、合成。

### 方案 B｜改用真实口播视频

如果有真人口播录像，可直接作为人物主层：

- 人物视频负责真实感和口型。
- AI 只生成画中画补充内容。
- Codex 负责补充画面生成、布局合成、字幕、调色、导出。

这是最稳的 V7 执行路径。

### 方案 C｜降级为“人物静态/微动小窗 + 真实口播”

如果暂时没有口型工具，也没有真人口播视频，可降级：

- 人物层使用肖像照做轻微 Ken Burns / 呼吸感 / 灯光变化。
- 避免嘴部特写，避免假装口型同步。
- 主表达由真实口播 + 补充画面承担。
- 成片标注为 AI 辅助视觉，不把人物当作真实讲话视频。

这个版本可立即执行，但它不再满足 V7 原始的「人物写实，口型一致」要求。

## Codex 当前可继续执行的分包

在口型问题解决前，Codex 可以先做这些包：

1. 补充画面包：日历、文档堆叠、分身剪影、迷宫、模板传送带、种子/根、年轮、贩卖机、内容生长、剪辑时间轴、API 日志等。
2. 合成工程包：按 A/B/C 三种人物布局预设版式，保留人物层占位。
3. 字幕/音频包：把 88.8 秒口播对齐到逐句时间轴，生成字幕和后期时间码。
4. 降级预览包：用肖像静态微动 + 补充画面先出一个可看结构版。

## 建议

如果目标是“人物主导、真实、可信”，优先走方案 B。  
如果目标是“全 AI 自动化演示能力”，优先走方案 A。  
如果目标是“先快速出片”，走方案 C。
