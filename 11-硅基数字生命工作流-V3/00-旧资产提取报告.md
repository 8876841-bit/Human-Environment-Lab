# 00-旧资产提取报告

> 目的：从旧 V2 / V4.1 内容生产工作流中提取有效能力，但不继承旧结构。

---

## 一、提取原则

```text
不迁移旧结构。
不复制旧 Agent 职责。
不默认进入内容生产。
只提取可服务 V3 的能力、规则、样例和边界。
```

V3 的主线不是：

```text
选题 → 脚本 → 视觉 / 视频 → 发布 → 复盘
```

而是：

```text
碳基真实输入
→ 硅基数字处理
→ Lab 交付判断
→ 物理世界表达 / 传播 / 工具 / 产品 / 服务 / 行动 / 暂不表达
→ 现实反馈
→ 数字生命与 Lab 双重迭代
```

---

## 二、从脚本 Agent 提取什么

旧脚本 Agent 的价值不在“生成脚本”，而在以下能力：

```text
把复杂判断说成人话
把深层逻辑转成可听懂表达
控制口语节奏
识别 Hook、共鸣、转折、行动之间的表达顺序
保留金句和关键表达
```

不继承：

```text
默认生成 60-120 秒短视频脚本
默认服务抖音 / 小红书 / B站发布
默认制造爆款 Hook
默认把所有触发点做成内容
```

V3 中迁移为：

```text
表达传播 Agent 的能力子模块：深判断 → 人话表达。
```

---

## 三、从视觉 Agent 提取什么

旧视觉 Agent 的价值不在固定风格，而在以下能力：

```text
把抽象判断转成画面
控制信息层级
控制证据感和情绪感
根据表达目的选择画面结构
避免视觉过度包装导致失真
```

不继承：

```text
默认小红书图文漫画
默认治愈系日式水彩风
默认固定人物设定
默认封面 / 多图发布导向
```

V3 中迁移为：

```text
表达传播 Agent 的能力子模块：研究结果 → 可感知呈现。
```

---

## 四、从视频 Agent 提取什么

旧视频 Agent 的价值不在视频量产，而在以下能力：

```text
镜头证据意识
节奏控制
旁白与画面匹配
B-roll 与现实材料对应
不同表达形式的交付差异
```

不继承：

```text
默认情绪空镜 + TTS
默认桌面推演
默认伪访谈
默认视频化输出
默认进入剪辑方案
```

V3 中迁移为：

```text
表达传播 Agent 的能力子模块：当 Lab 判断适合视频表达时，生成物理世界可执行的视频方案。
```

---

## 五、从复盘 Agent 提取什么

旧复盘 Agent 是最值得保留的部分，但复盘对象要升级。

可提取能力：

```text
反馈分类
误解识别
有效表达识别
评论中新触发点提取
下一轮迭代建议
```

需要升级：

```text
从平台数据复盘
升级为现实反馈复盘。
```

V3 复盘不只看：

```text
完播率
点赞
收藏
评论
```

还必须看：

```text
现实是否产生反馈
人是否被触动
判断是否被验证
有没有出现反例
是否需要修正规则
数字生命有没有更新
Lab 运行方式有没有变化
```

---

## 六、从 knowledge_docs 提取什么

只提取三类资料：

```text
稳定规则
高质量表达样例
被验证过的判断
```

谨慎使用：

```text
平台技巧
爆款模板
旧账号定位
固定视觉风格
行业默认入口
```

这些可以作为参考，但不能进入 V3 内核。

---

## 七、迁移结论

旧资产不是废弃，而是降级：

```text
旧 Agent = V2 内容生产能力样本
旧 knowledge_docs = V2 表达与传播参考库
新 V3 工作流 = 硅基数字生命主线
```

任何旧资产进入 V3 前，都必须先回答：

```text
它是在服务碳基真实与硅基能力的循环，
还是在把系统重新推回内容生产惯性？
```
