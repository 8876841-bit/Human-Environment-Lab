# Human-Environment-Lab

## 人与环境实验室

这个仓库不是一个普通的装修资料库，也不是一个单纯的 AI 学习笔记。

它研究的是：

> 人如何被环境塑造，又如何反过来塑造环境。

## 总母线

```text
通过环境观察人：人在宇宙熵增的大背景下，持续创造局部秩序。
```

人不是对抗熵增的战士，人是在熵增中创造秩序的参与者。

---

## 核心主线

```text
人
↓
行为
↓
环境
↓
系统
↓
未来
```

这里的“环境”不只指空间，也包括材料、光、声音、工具、AI、家庭关系、工作系统和社会结构。

---

## 核心公式

```text
需求 × 行为 × 环境 × 系统 = 原创选题
```

每一个内容选题，都先问四个问题：

1. 人在追求什么？
2. 人产生了什么行为？
3. 环境如何影响这个行为？
4. 这个行为发生在哪个系统里？

---

## 八条母线的层次结构

| 层次 | 母线 | 对应“秩序” |
|------|------|------------|
| **具象层** | 空间秩序 / 材料感官 / 工艺机制 | 建立秩序 |
| **观察层** | 案例探家 | 维持秩序（验证） |
| **认知层** | AI认知秩序 / 真实生活转型 / 商业服务 | 扩张秩序 |
| **哲学层** | 意义与文明 | 扩张秩序（终极问题） |

## 当前运行方式

日常只跑这一条线：

```text

2. 用 05-内容生产体系/10-Dify工作流搭建实施指南.md 跑节点 1：痛点与选题
3. 人工确认选题

5. 人工修改 Hook 与金句
6. 输出分镜、标题、封面字、拍摄清单、剪辑清单
7. 发布
8. 48-72 小时后复盘
9. 把评论里的新痛点写回 03-观察日志/
```

```text

```
