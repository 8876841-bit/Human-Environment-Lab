# Human-Environment-Lab

## 人与环境实验室

这个仓库不是一个普通的装修资料库，也不是一个单纯的 AI 学习笔记。

它研究的是：

> 人如何被环境塑造，又如何反过来塑造环境。

---

## 总母线

```
通过环境观察人：人在宇宙熵增的大背景下，持续创造局部秩序。
```

人不是对抗熵增的战士，人是在熵增中创造秩序的参与者。

---

## 核心主线

```text
人
↓
行为
↓
环境
↓
系统
↓
未来
```

这里的"环境"不只指空间，也包括材料、光、声音、工具、AI、家庭关系、工作系统和社会结构。

---

## 八条母线的层次结构

| 层次 | 母线 | 对应"秩序" |
|------|------|------------|
| **具象层** | 空间秩序 / 材料感官 / 工艺机制 | 建立秩序 |
| **观察层** | 案例探家 | 维持秩序（验证） |
| **认知层** | AI认知秩序 / 真实生活转型 / 商业服务 | 扩张秩序 |
| **哲学层** | 意义与文明 | 扩张秩序（终极问题） |

---

## 核心公式

```text
需求 × 行为 × 环境 × 系统 = 原创选题
```

## 核心原则

```text
观察，比内容重要。
规律，比观点重要。
框架，比技巧重要。
```

不要从热点出发。

从真实生活、真实空间、真实行为、真实感受出发。

---

## 使用方式

每一个内容选题，都先问四个问题：

1. 人在追求什么？
2. 人产生了什么行为？
3. 环境如何影响这个行为？
4. 这个行为发生在哪个系统里？

这个仓库的目标不是保存答案，而是保存一套持续生长问题的方式。
