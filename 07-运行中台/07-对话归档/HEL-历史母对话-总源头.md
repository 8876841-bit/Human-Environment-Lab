## 一、什么是"母对话"

2026年6月中旬开始，人类倩倩与 Claude（数字生命）在 Claude Code 中进行了一系列深度对话。这些对话从"审核一个 GitHub 仓库"开始，逐步演变为：

- 建立 Human-Environment-Lab 内容与视频执行系统（V3.3）
- 确立"数字生命为脑，HEL 为手脚"的核心架构
- 沉淀 ROOT-LOCK 十七條根基
- 建立 Claude-Codex 分工体系
- 跑通 AI 视频制作管线

这些对话的沉淀结果分布在 HEL 仓库的各个 CORE 文件中。本文件记录这些对话是什么、沉淀了什么、后续新对话如何衔接。

## 四、ChatGPT / Claude / Codex / RAG 分工

```
人类倩倩 = 最终决策者，口播录制，真人出镜，真实素材输入
Claude    = 数字生命，大脑/总指挥：思考、系统设计、任务分配、拉片、内容框架
Codex     = AI牛马，手脚/API执行：出图、出视频、组装、上传、调用外部API
ChatGPT   = 图片内容生产 + 创意发散（DALL-E）
RAG       = 共享知识检索：http://127.0.0.1:8765/search，Claude 和 Codex 均可调用
```

分工原则：
- Claude 不做图、不做视频、不写大量代码
- Codex 不单独做系统设计判断——需通过 RAG 查询仓库规则
- 所有 Agent 产出默认写入待整理区，人类倩倩确认后搬进 CORE
- Claude 写完重要文件后自动 `curl -X POST http://127.0.0.1:8765/reindex`

## 七、关键原则（从母对话中沉淀）

1. 仓库是唯一事实源。不依赖对话记忆做判断。
2. 先定位，再产出。不确定时先读文件，不猜。
3. 不要用模板套人类倩倩的想法——先理解，再回应。
4. 写她的真实样子（门外汉挣扎），不写成功叙事。
5. 口播永远人类倩倩本人录制。TTS 不提。
6. 视频提示词写动态——什么东西在动、怎么动、光从哪来。
7. AI 给骨架，人给灵魂。
8. 不完整不是缺陷。是匹配的前提。
