# 03-对话收口模板

> 本文件用于每次重要对话结束时收口。  
> 目的不是把对话写漂亮，而是明确：这次解决了什么，没解决什么，下一步去哪里。

---

## 什么时候必须收口

出现以下任一情况，必须使用本模板：

```text
1. 已形成清楚判断。
2. 已明确下一步现实动作。
3. 已发现证据不足。
4. 已拆出新分支。
5. 已经可以写入仓库。
6. 已经开始重复绕圈。
7. 方向开始偏移当前主题。
```

---


## 收口硬规则

```text
1. 不写“感觉聊得不错”这类空话。
2. 必须写清楚下一步。
3. 必须区分：已解决 / 未解决 / 临时假设 / 现实验证。
4. 出现新方向，不在本文件展开，进入分支停车场。
5. 如果本次没有任何下一步，说明这次对话应该暂停。
```
