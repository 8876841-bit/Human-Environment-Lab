# 04-分支停车场

> 本文件用于停放对话中长出来的新方向。  
> 原则：发现分支，不等于立刻追分支。

---

## 为什么需要分支停车场

Human-Environment-Lab 的问题容易互相连接。

一个真实触发点可能同时长出：

```text
系统结构问题
现实验证问题
表达传播问题
工具实现问题
商业模式问题
个人选择问题
```

如果所有方向都在一个对话里展开，就会乱线。

分支停车场的作用是：

```text
先保存。
不丢失。
不抢主线。
到时间再启动。
```

---

## 什么时候进入停车场

出现以下情况，进入停车场：

```text
1. 当前主题外长出一个新问题。
2. 新问题很重要，但不是当前最小下一步。
3. 需要新的现实材料才能继续。
4. 会把当前对话带离主线。
5. 暂时没有行动条件。
6. 当前系统文件还没准备好承接它。
```

```text
分支编号：BR-YYYYMMDD-001
日期：

它属于哪一类：系统 / 现实验证 / 表达传播 / 工具 / 产品 / 服务 / 个人选择 / 其他
为什么暂时不追：
重新启动条件：
预计归属文件：

```

## 停车场硬规则

```text
1. 停车场不是垃圾桶。
2. 进入停车场的分支必须写明重新启动条件。
3. 没有重新启动条件的分支，等于空想。
4. 停放超过一个月且没有新证据，转为废弃或归档。
5. 当前主线没有完成前，不允许随意启动多个分支。
```
