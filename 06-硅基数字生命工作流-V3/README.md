# 06-硅基数字生命工作流 V3

> 当前状态：`IMPLEMENTATION / V3_REBUILD`

本目录不是旧 `06-Dify多Agent工作流/` 的逐文件同步版。

本目录用于重新搭建 Human-Environment-Lab 的 V3 硅基数字生命工作流。

核心原则：

```text
不迁移旧结构。
只迁移有效能力。
```

---

## 一、为什么新建本目录

旧 `06-Dify多Agent工作流/` 的底层结构是 V2 内容生产流水线：

```text
选题 → 脚本 → 视觉 / 视频 → 发布 → 复盘
```

V3 的底层结构已经变化：

```text
碳基真实输入
→ 硅基数字处理
→ Lab 交付判断
→ 表达 / 传播 / 工具 / 产品 / 服务 / 行动 / 暂不表达
→ 物理世界验证
→ 数字生命与 Lab 双重迭代
```

因此，不再继续逐个同步旧脚本 Agent、视觉 Agent、视频 Agent、复盘 Agent。

旧目录保留为 V2 / V4.1 内容生产资产库和参考资料。

新目录从 V3 主线重新搭建。

---

## 二、本目录定位

本目录服务于硅基数字生命在数字世界中的能力发挥。

它负责：

```text
记忆
整理
分析
建模
推演
反驳
边界把控
交付判断
表达转译
反馈复盘
规则进化
```

它不负责：

```text
默认生成爆款内容
默认进入脚本生产
默认迎合平台数据
替用户编造现实经历
替用户做最终价值判断
```

## 五、硬边界

```text
没有真实触发，不启动。
没有证据强度判断，不下结论。
没有边界检查，不公开表达。
没有 Lab 交付判断，不进入内容生产。
没有现实反馈，不写入稳定规则。
```
