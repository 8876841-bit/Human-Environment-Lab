## 一、模块定位

### 1.1 在 HEL 系统中的位置

```
┌─────────────────────────────────────────────────────────────────┐
│                         HEL 内容生长中枢                          │
├─────────────────┬───────────────────────────────────────────────┤
│                 │                                               │
│   内部模块      │              外部输入模块                       │
│   ─────────    │              ─────────────                      │
│                 │                                               │
│  • 选题母树     │  • n8n 多平台内容采集引擎 ← 本文档              │
│  • 脚本母版     │                                               │
│  • 内容引擎     │     作用：为内部Agent提供新鲜素材              │
│                 │                                               │
│   Dify Workflow │                                               │
│   + 子 Agent    │                                               │
│                 │                                               │
└─────────────────┴───────────────────────────────────────────────┘
```

### 1.2 解决的问题

| 问题 | 解决方案 |
|------|----------|
| 内部逻辑偏向内生/底层原理 | 引入外部新鲜案例 |
| 缺乏真实用户反馈 | 采集评论区痛点/需求 |
| 内容缺少趋势感 | 采集平台热门内容 |
| 素材库匮乏 | 批量采集图片/视频 |

### 1.3 核心价值

- **平衡「内生逻辑 + 外来输入」**
- 为**策划Agent**提供趋势参考
- 为**脚本Agent**提供真实案例素材
- 为**资料Agent**补充视觉素材

## 三、核心功能

### 3.1 输入方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 关键词搜索 | 输入关键词采集 | 日常素材收集 |
| 链接采集 | 输入单个帖子/视频链接 | 针对性采集 |
| 账号URL采集 | 输入账号主页URL | 竞品分析 |
| 定时任务 | 定时采集热门趋势 | 趋势监控 |

### 3.2 关键词示例

```
# 国内关键词
全屋定制 猫咪空间
小户型 收纳技巧
原木风 客厅设计
厨房动线 装修
独居人士 冰箱

# 国际关键词
modern cat villa interior
minimalist home design
cat-friendly furniture
natural wood interior
small apartment organization
```

### 3.3 输出内容

| 输出项 | 说明 |
|--------|------|
| **图片/视频URL列表** | 带元数据（平台、点赞、评论数） |
| **本地分类存储** | 自动按日期/分类存储到文件夹 |
| **相关性打分** | AI 筛选 + 去重 |
| **推送通知** | 推送到 Feishu / Dify Knowledge |
| **采集报告** | 趋势总结 + 灵感提炼 |

## 六、注意事项

### 6.1 版权风险

| 风险 | 说明 | 应对措施 |
|------|------|----------|
| 平台服务条款 | 多数平台禁止爬取 | 仅用于灵感参考，不直接商用 |
| 原作者版权 | 图片/视频版权归属原作者 | 采集后标注来源，商用需授权 |
| 肖像权 | 拍到人脸可能涉及肖像权 | 优先采集不含人脸的素材 |

**⚠️ 重要提醒**：本模块采集的内容仅限「灵感参考」使用，不可直接商用。

### 6.2 技术维护成本

| 平台 | 反爬策略 | 维护频率 |
|------|----------|----------|
| 抖音 | 频繁更新 | 高 |
| 小红书 | 频繁更新 | 高 |
| Instagram | 中等 | 中 |
| Pinterest | 较稳定 | 低 |

**建议**：优先使用 Apify 方案，利用其现成维护好的 scraper，减少自维护成本。

### 6.3 数据质量控制

| 问题 | 解决方案 |
|------|----------|
| 重复内容 | Item Lists 去重 + 图片 hash 去重 |
| 低质量内容 | LLM 节点 AI 筛选相关性 |
| 水印干扰 | 可选：去水印工具（需评估合法性） |

## 十、附录：n8n 节点配置模板

### 10.1 Webhook 触发器配置

```json
{
  "method": "POST",
  "path": "inspiration-collector",
  "authentication": "none",
  "variables": {
    "keyword": "={{ $json.body.keyword }}",
    "platform": "={{ $json.body.platform }}",
    "limit": "={{ $json.body.limit || 20 }}"
  }
}
```

### 10.2 关键词预处理 Function

```javascript
// 预处理输入的关键词
const keyword = $input.first().json.keyword;
const platform = $input.first().json.platform;

// 标准化关键词
const normalized = keyword.trim().toLowerCase();

// 国际关键词映射
const intlKeywords = {
  'cat': 'cat OR kitty OR feline',
  'wood': 'wood OR timber OR natural material',
  'minimalist': 'minimalist OR minimal OR simple design'
};

// 返回处理结果
return [{
  json: {
    keyword: normalized,
    intlKeyword: intlKeywords[normalized] || normalized,
    platform: platform,
    timestamp: new Date().toISOString()
  }
}];
```
